Privacy Policy

Updated 6 November 2026. Extension version 2.0.0. Publisher: Vektor T13 Technologies B.V. Contact: info@detect.expert. Website: https://detect.expert.

This policy describes the Detect.Expert extension for Chrome and Firefox, not other services linked from our website. The extension helps you inspect and test how your browser looks to websites. It processes data locally to inspect browser API activity, display bounded technical previews and record user-started inspection sessions. Only when you turn the matching feature on, it also applies API denials, replaces the values that selected APIs return (Antidetect), routes browser traffic through a proxy you configure (Proxy), reads and changes cookies you ask it to handle, walks a tab through a list of addresses you enter (Autosurfer), shows browser data you ask to see (Browser Debug), reads the mode of one Cloudflare zone you connect, looks up the exit IP of your proxies with a geolocation provider you connect (Proxy Manager Geolocation API), and runs the optional Firewall module. Local processing is data handling, even though the developer does not receive the reports.

What Changed Since The Previous Version

This update describes everything version 2.0.0 stores or sends: Antidetect settings, profile library, trash and a private local key; the Proxy workspace, its check history and the optional companion program; the Cookies, Autosurfer, Browser Debug, Cloudflare and Proxy Manager Geolocation API tools; the Firewall module; the saved Pro report archive and three databases on disk; the site-icon cache; and the connections the extension can make when you use these features. Network Connections

What the extension does not do: no account, analytics, telemetry or crash reporting; no remote code, remote rule lists or updates (all executable code and recognition rules are in the installed package, and Antidetect assembles its page scripts on your device from packaged functions and your own selections); no automatic upload of reports, settings or browsing data to the publisher or anyone else. The Content Security Policy of the extension pages allows script connections only to api.cloudflare.com and to the hosts of four geolocation providers (geolite.info, geoip.maxmind.com, api.ipgeolocation.io, api.ipdata.co, ip-api.com and pro.ip-api.com), which only the Proxy Manager Geolocation API uses.

What it does without a command from you: one thing. For pages within the observation scope, the extension asks the page to load once more the icon address that Chrome already reports for the tab, in order to keep a small local copy for the report (see Storage And Retention). The request leaves from the page context to the host of the icon, without a referrer; icons delivered as data addresses need no request.

What it does only when you use a feature:

  • Cloudflare (Precursor modes): after you press Connect with an API token you entered, GET requests to api.cloudflare.com for that one zone (its details and its Precursor mode), repeated about once a minute while the connection stays active. The token is sent only to that address as a bearer token, without cookies or a referrer.
  • Proxy Manager Geolocation API: after you turn it on and add a key, GET requests to the provider you chose with the public exit IP of a proxy that a manual check found, and your key (details under Optional Features And Their Data); there is no timer and no request when the list opens.
  • Proxy: once you turn it on, the browser sends its traffic (all of it, or only the domains you list) to the proxy or VPN server you configured. The optional companion connects only to the servers in your profiles, while you connect or check a profile.
  • Proxy check: only when you press a check button, one HTTP(S) GET goes through the selected proxy to an address you can edit (the default is api.ipify.org). The companion makes it; browser cookies are not sent and redirects are not followed.
  • Autosurfer and the native profile session (Chrome): a tab or window that the extension opened navigates to the addresses you entered and to same-site links found on those pages.
  • Links in the Contacts section and header, and letters prepared by the Firewall module (mailto), open or start only when you click them.

Websites, Chrome and your email provider make their own requests; this policy does not cover them.

Observation Settings

Ordinary local observation starts automatically after installation on sites for which the browser grants access. The enabled state and scope are stored locally. You may narrow or disable the scope, pause a document, clear results, or use Turn off and clear in settings. Previously saved disabling and scope choices are retained. Pro recording and API blocking require their own activation.

Installations without a saved observation choice receive the same enabled default. Previously opened pages receive document-start sensors on their next reload. Reload pages after changes to API blocking; existing or frozen page wrappers may need a reload for complete removal. A failed local write or deletion leaves observation unavailable and requires a retry.

What Is Processed

During startup, while the worker loads observation settings, a bounded memory buffer can temporarily hold reduced resource/header metadata: browser ownership IDs, shortened domains, fixed rule/header/hint names and bounded counts. It never holds raw URLs, cookies, arbitrary header values or exact previews. It holds up to 256 startup events and up to 128 header owners, with redacted responses waiting up to two seconds. The buffer is processed after the enabled state is loaded or the first-install default is successfully saved. A saved disabled or invalid state, an unfinished settings change or a storage error discards it. Enabling observation later does not restore discarded events.

  • Browsing/resource metadata: browser-provided tab, frame and document identity, permitted domains, navigation and request activity, selected response-header names and Client Hint names. Full addresses are used transiently for authorization and recognition, not stored as unrestricted browsing logs. The registrable domain of a visited site in scope is kept with its icon for up to seven days (see Storage And Retention).
  • Supported API operations, phases, bounded counts, coarse activity and coverage information. Dedicated collectors do not collect keystrokes, form or clipboard contents, pointer-coordinate values, general request/response bodies, Authorization, passwords, private keys, audio samples or media streams.
  • Beacons of known analytics and advertising services (Google Analytics and Ads, Meta, TikTok, Yandex, LinkedIn): for these exact endpoints the extension parses the request address and body transiently in memory. Only the event type, a bounded numeric value and currency, and whether certain identifiers or consent states are present are kept (in the inspector and in a Pro recording); raw addresses, bodies, identifiers, e-mail addresses, phone numbers, hashes and order details are discarded.
  • Canvas/WebGL images already read by a page and selected exact API-returned technical characteristics, including display/browser/GPU capabilities and selected WebRTC codec, SDP-derived and stats fields. Full SDP, ICE passwords/candidates/client or peer IPs, device IDs and arbitrary objects are excluded from these technical previews.
  • Full WebRTC certificate fingerprints and the outgoing X-Client-Data header when Chrome exposes it, plus decoded experiment IDs. These may be identifying technical information, not proof of a unique device/user or a CAPTCHA cause.
  • A separate local WebRTC history of configured ICE-server hostnames or server IP addresses, ports and connection states. These are server endpoints, not a geolocation measurement or proof of contact.
  • On your explicit Pro recording command: visits, sanitized page titles and URL templates, permitted resource metadata and analysis results. Website images and page titles may contain personal or sensitive information, including communications or health/financial information incidentally displayed by a page. The extension does not classify visual content as safe or anonymize it.

The optional features below process the additional data described there, only after you turn them on or start them.

Optional Features And Their Data

API denials. Off by default. Your choices, the preset and rules for up to 128 exact site names are kept locally. Selected calls may be refused or APIs made unavailable, which changes site behavior and may break functionality; reload pages after changes.

Antidetect. Off by default. When on, it replaces what selected browser APIs return to web pages, and the User-Agent, Accept-Language and client-hint headers of browser requests, with values you choose or build from built-in offline tables (nothing is looked up online); it can also remove some device, viewport and network request headers. Requests made by the extension itself are excluded. Websites see the replaced values, which is the purpose of the feature; no anonymity or undetectability is promised, and sites may detect the changes. The extension keeps your configuration, per-site exceptions, a library of up to 128 profiles (name, tags, note and values), a seven-day trash of deleted profiles, and a record that restores the previous state after a temporary profile. When you first apply a value that needs it, it also creates a random 256-bit local key, from which it derives repeatable per-profile variations of Canvas, Audio, WebGL, Math and Network Information results, and a random seed for stable WebRTC device identifiers. These keys are never exported, sent or shown, and no interface action deletes them; uninstalling the extension removes them. The Options page may read parameters of this browser (memory size, GPU strings through one temporary WebGL context, WebGPU adapter details) into page memory to suggest values; nothing is stored or sent. A chosen WebRTC policy can be applied to the whole browser after you grant the optional privacy permission. Exports are files you create after a preview; they contain your selections, not the keys.

Proxy. Off by default. The extension stores profile names, server addresses and ports, routing choices and an optional country note that you type (it is not detected). Logins, passwords, VLESS addresses and OpenVPN configurations are not stored by the extension: they exist in the memory of the Options page while you edit and in the companion's encrypted file. While Proxy is on, the operator of your server can see the destinations of your traffic and any unencrypted content; if the proxy or the companion fails, traffic is blocked instead of going directly. With the optional privacy permission, Proxy may also change the browser's WebRTC and network-prediction settings while it is active and restores them afterwards. A check history (time, result, response time, DNS and TLS flags, HTTP status and the exit IP of the proxy as the check site saw it; never the checked address or your login) keeps up to 30 entries per profile for 30 days, can be switched off and can be cleared. The Copy JSON button puts the full set of profiles, including logins and keys, on the system clipboard only on your command and with the optional clipboardWrite permission; the extension does not clear the clipboard, and other programs can read it.

Optional Windows companion. A separate program, needed only for profiles with a login, VLESS or OpenVPN. It is installed for the current Windows user without administrator rights and registers a Native Messaging host for the extension; the browser starts it only when needed. It keeps your profiles in a file encrypted with Windows DPAPI in the roaming application-data folder of your Windows account (Detect.Expert/Proxy), listens only on the loopback interface, does not download or update its engines, and connects only to the servers in your profiles and, through the selected proxy, to the check address you enter. Its uninstall script removes the registrations but keeps the encrypted file: delete your profiles in the extension first (it asks the companion to delete them) or delete the file yourself.

Cookies and site tools. The optional cookies permission is requested by a click. Once access exists, the Cookies workspace reads the metadata of the cookies of every browser store by itself (name, domain, path, flags, expiry; no values in the list) and lists them by domain; without access nothing is read. You can edit, delete, import and export cookies of the stores you select; a value is read only when you press show, edit or export. Cookie values stay in the memory of that Options tab and are erased when you leave the tab, hide or close the page, or revoke the permission; they are not written to storage, logs or reports. Files you export (JSON, Netscape text or password-encrypted JSON) contain cookie values and are saved by you; an unencrypted file contains usable session credentials. In the detector, Clear cookies of this site deletes the cookies of the selected tab's registered domain after your click; a single cookie value can be shown in a live panel after your click; the tracking-cookie restore test removes one persistent cookie you choose, watches for ten seconds whether it returns and restores the original unless the site set a new value (the value is held in memory only for that test).

Autosurfer (Chrome only). After you press Start, a tab in a new window walks through your list of addresses (up to 200) and same-site links, scrolls the page and moves the pointer through Chrome's debugger interface, and Chrome shows its debugging banner. It does not click, type, fill forms or solve CAPTCHAs. Your address list and the last report (visited origins, times, status codes, and CPU and memory aggregates if you allow system metrics) stay in an extension database on disk until you change or clear them. Pointer positions and discovered links are used only for the current visit. The sites of your list set and read their own cookies in your browser profile just as when you visit them yourself. When the run finishes, or on Stop or Clear, the extension closes the window it created (tabs you opened in it yourself stay); a site that cannot be reached is skipped and recorded as an interrupted visit.

Browser Debug. Each data set asks for its own optional permission when you click it (history, bookmarks, downloads, cookies, tabs, sessions, top sites, reading list, extensions, privacy settings, site permissions, system information, account profile). The data is shown in the memory of the Options tab only and is not stored by the extension; cookie rows show no values. Some sections can change browser data on your explicit command, for example add a history entry, edit or delete a bookmark, erase a download-list entry, delete a cookie, pin or mute a tab, enable or disable another extension, or change a boolean privacy setting or a site permission for one origin. An export is created after a preview, strips user info, query and fragment from web addresses and redacts the account value.

Cloudflare zone (Precursor modes). You enter an API token yourself. It is kept in extension memory and in browser session storage (trusted extension contexts only) until you disconnect, clear data or close the browser; it is never written to disk storage, reports, logs or exports. The zone ID and name, the last mode read and a history of mode changes (up to 128) are kept in local storage until you clear them. Optional notices use the notifications permission, which you grant by a button.

Proxy Manager Geolocation API. Off by default. Once you turn it on and add a key, the Proxy manager shows country, city, organisation and flags (proxy, VPN, Tor, hosting) for the exit IP of your proxies. For that, the extension pages send the provider you chose (MaxMind GeoLite or GeoIP, ipgeolocation.io, ipdata or ip-api.com) a GET request with the public exit IP that a manual proxy check found and your key (MaxMind: account ID and licence key), without cookies, a referrer or redirects; private and reserved addresses are never sent. The provider also sees the address your request comes from (your IP or the exit IP of the active route) and may, over time, learn which proxies you check. Requests are made right after a manual check (can be switched off), on a button, and when you test a key; there is no timer and no request when the list opens. The free ip-api.com endpoint works over plain unencrypted HTTP only and is used only after your separate confirmation; with a key, HTTPS is used. If a provider fails, the same address can go to the next provider you enabled (can be switched off). By default keys stay in browser session storage and vanish when the browser closes; with the "Remember keys on this computer" box ticked they are kept unencrypted in local storage. The result cache (up to 200 records, 30 days) is kept there too and cleared by a button. Keys never reach exports, reports, logs or synchronization. Provider data is approximate and is not an assessment of the safety of a proxy or a site.

Firewall module (Chrome only). Off by default; you enable it after a consent screen, and an organization policy can only forbid it. According to the features you select, it blocks or allows network requests by rules, adds the Sec-GPC header, and compares what you type into e-mail, phone and name fields with the bodies of outgoing requests of that tab: the value is read inside the isolated context of the page after trusted input, only key fingerprints of its variants reach the memory of the extension's service worker (15 minutes), and request bodies are scanned in memory (up to 64 KiB per request, extracted tokens kept for at most 10 seconds). Passwords, fields that were ever passwords, payment fields and one-time codes are never read. The typed value and anything derived from it are not written to storage, logs, exports or messages. The module keeps, in a database on disk that the extension does not encrypt, your site exceptions and decisions, an optional history of domains and days (separate checkbox; 7, 30 or 90 days), and a journal of the data-request letters you prepared (up to 100 entries, kept 30 to 730 days depending on status).

Site icons. To show the icon next to the name of a visited site in reports, the extension keeps a 32 by 32 PNG copy and the registrable domain of up to 64 sites seen within the observation scope, each for up to seven days.

Interface. Your choices of language, theme and Light or Pro view, the layout of the proxy list and your position in the interface tour are kept locally.

Storage And Retention

Memory-only previews: Canvas/WebGL images and X-Client-Data values do not enter browser storage, ordinary reports, Pro/PDF, diagnostics or JSON exports. Selected technical API and WebRTC results remain memory-only in Light mode; during a user-started Pro recording, their distinct values and selected technical call parameters are retained in the local Pro report and PDF. Canvas capture is bounded to the first 60 seconds per sensor; accepted previews can remain longer. The gallery is bounded to 256 images and 12 MiB of encoded characters per document, with four worker-owned documents and ten-minute idle expiry. Limits on encoded text are not exact browser RAM measurements.

API values are limited to 256 rows/64 KiB per realm until reset, pause or realm destruction. Google headers are limited to eight hosts in eight documents, 4096 characters per header and ten minutes per host; their worker cache is lost on restart. Canvas/API previews can sometimes recover from the same live authorized document after a worker restart without a new page read. Frozen contexts may defer physical memory cleanup.

Browser session storage: temporary reports and internal identity/watermark metadata are bounded to 4 MiB overall, with inactive-document expiry after ten minutes. Separate ICE-server history is limited to eight documents and 32 KiB per document, expiring after ten minutes without updates. The image channel stores only a small ownership registry, not pixels. A sleeping worker performs expiry cleanup on subsequent activity, not at a guaranteed exact instant. Session storage is browser memory and is cleared when the browser closes or the extension reloads. It also holds the Pro recording, the Cloudflare token, the Geolocation API keys (unless you chose to remember them), the Autosurfer checkpoint, session WebRTC seeds and the Firewall module's evidence (up to 1 MiB, ten-minute expiry).

Pro session: recording lasts at most ten minutes and is limited to 3 MiB. A stopped recording can remain after that capture window until replaced, cleared or the browser/extension session ends. Images and Google header values are excluded. Selected technical API results and call parameters are included, with up to 256 variants / 64 KiB per document. During an explicitly started Pro recording, names and values from outgoing Cookie headers of authorized recorded requests are also stored locally and included in the report and PDF. The recording also includes the values of a fixed list of 38 technical request headers that the browser sent (for example User-Agent, Accept-Language and client hints; never Authorization or Set-Cookie). This collection does not read the browser's cookie jar or unrelated request headers. Cookie values are excluded from ordinary Light reports and redacted JSON exports.

Saved Pro reports: if you press Save on a stopped Pro report, a copy is written to an extension database on disk (IndexedDB), up to 20 reports and 8 MiB of JSON. It has the same fields as the Pro report, which can include page titles, URL templates and outgoing Cookie values. It stays until you delete it from the history list; the global clear and Turn off and clear delete it as well, even with all extension pages closed.

Local settings: observation state, scope and previous scope mode, selected site rules, language, theme, Light/Pro view, API-denial settings, the Antidetect and Proxy data described above, the saved Cloudflare zone and its history, the Firewall module's settings, the Geolocation API settings and result cache (and its keys only if you ticked "Remember keys on this computer") and the site-icon cache remain in chrome.storage.local until changed, removed or uninstalled; items with their own limit (trash, check history, site icons, temporary profile) expire as stated. This is a set of unencrypted files in your browser profile. Chrome storage.sync is not used. Clear, pause, revocation, frame/document replacement, expiry and memory limits invalidate applicable previews. The switch below the logo stops observation and restores the previous scope when enabled again. It retains a stopped Pro report.

Databases on disk: saved Pro reports, the Firewall module's data and the Autosurfer list and report, as described above, are stored in extension databases (IndexedDB) that the extension does not encrypt. Page storage: the theme, the proxy list layout, the dismissed Geolocation API notice and the tour progress use the local storage of the extension's own pages. Outside the extension: files you export, the clipboard and the companion's encrypted file are not removed by the extension.

Browser Permissions

Declared at installation: activeTab, scripting, storage, webRequest, webNavigation, sidePanel, alarms, declarativeNetRequestWithHostAccess, userScripts, proxy and debugger, and access to http, https, ws and wss pages. They support observation, the optional features above, the Proxy workspace, and the Autosurfer window and native profile session that you start (Chrome shows its debugging banner while the debugger is attached). Requested by a click and revocable: history, bookmarks, downloads, cookies, tabs, sessions, topSites, readingList, management, privacy, contentSettings, system.cpu, system.memory, system.storage, system.display, identity, identity.email (Browser Debug and the cookie tools), nativeMessaging (the Proxy companion), clipboardWrite (Copy JSON) and notifications (Cloudflare notices). The Firefox build omits the Chrome-only parts (Firewall module, Autosurfer, native profile session) and offers some of these permissions as optional only. The extension does not run in private windows.

Sharing, Exports And External Links

The extension has no account, analytics, telemetry, remote code, remote rule downloads or automatic report uploads. It does not send inspection data to the publisher or other parties. The connections it makes when you use a feature, and the one automatic icon request, are listed under Network Connections. All executable code and recognition rules are packaged. Websites continue to make their own requests independently.

You may save a redacted JSON report after a preview; its host is excluded by default. Pro PDF uses the browser's local print interface and includes the recorded fields displayed in its preview, including outgoing cookie values. The other features create files only on your command: the Antidetect configuration and library (without the private keys), Proxy profile metadata (without logins and keys), cookie files, Browser Debug snapshots, Autosurfer reports and Firewall exports. Minimal diagnostics contain only extension/browser versions and background availability. You control saved files and manual sharing. Support receives only information you separately choose to send to info@detect.expert. Do not send passwords, cookie files, private images or identifiers without a specific need and deliberate selection.

Header links open ordinary external websites only when clicked, without appending reports and with referrer/opener protection. Those websites and your email provider handle the visit or message under their own policies. This policy does not claim that a visited website has no logs or cookies.

Limited Use And Security

Detect.Expert uses accessed data only for its disclosed features: local inspection and recording, and the optional tools described above, each started or enabled by you, in compliance with the Chrome Web Store User Data Policy, including Limited Use. Data is not sold or used for advertising, unrelated profiling, creditworthiness, lending or model training. The developer does not automatically read local reports; support review is limited to information you expressly provide for that request.

Bounded data stays in extension contexts, with browser-derived ownership and access checks, except what you direct elsewhere: a proxy or VPN server you configure, the Cloudflare API, a geolocation provider you configure, files you export and the clipboard. Page-controlled observations are not authenticated evidence. Optional API denials and Antidetect are off by default, require separate confirmation and may break sites. No anonymity, invisibility, complete coverage or overall safety verdict is promised. The extension does not encrypt browser-local storage: the files of chrome.storage.local and of the extension databases in your profile are readable by anyone with access to your operating-system account. The companion's file uses Windows DPAPI. Secure your browser profile and operating-system account.

Deletion And Changes

Use Light clear, Pro clear or session clear for their respective data; the saved Pro report history has its own delete control. Withdraw consent in settings (Turn off and clear) to stop observation and clear the session, the Pro archive, the site-icon cache and the Cloudflare connection; disable scope or uninstall to stop future operation. Feature data is removed with the feature's own controls: Antidetect profiles and trash, Proxy profiles and check history, the Autosurfer list and report, the Firewall purge, Disconnect for Cloudflare, and the "Forget all keys" and "Clear cache" buttons of the Geolocation API. Reload pages to remove installed wrappers. Uninstall removes extension storage, but cannot remove downloaded files, clipboard content, the companion with its encrypted profile file, or independently sent support messages. Turn Proxy off before removing the extension. Material changes to data practices will be prominently disclosed before changed processing starts and consent renewed where required. Contact the publisher about this policy at info@detect.expert.

Сетевые соединения

Чего расширение не делает: нет аккаунта, аналитики, телеметрии и отчётов о сбоях; нет удалённого кода, удалённых списков правил и обновлений (весь исполняемый код и правила распознавания находятся в установленном пакете, а скрипты страниц Антидетект собирает на вашем устройстве из упакованных функций и ваших значений); нет автоматической отправки отчётов, настроек и сведений о посещениях издателю или кому-либо ещё. Content Security Policy страниц расширения разрешает их скриптам сетевые соединения только с api.cloudflare.com и с хостами четырёх провайдеров геолокации (geolite.info, geoip.maxmind.com, api.ipgeolocation.io, api.ipdata.co, ip-api.com и pro.ip-api.com); последние использует только Proxy Manager Geolocation API.

Что оно делает без вашей команды: одно действие. Для страниц из области наблюдения расширение просит страницу ещё раз загрузить адрес значка, который Chrome уже сообщил для вкладки, чтобы хранить небольшую локальную копию для отчёта (см. «Хранение и сроки»). Запрос уходит из контекста страницы на хост значка, без referrer; значки в виде data-адресов запроса не требуют.

Что оно делает только при использовании функции:

  • Cloudflare (режимы Precursor): после «Connect» с введённым вами API-токеном — запросы GET к api.cloudflare.com для этой одной зоны (её сведения и режим Precursor), повторяются примерно раз в минуту, пока соединение активно. Токен уходит только на этот адрес как bearer-токен, без cookies и без referrer.
  • Proxy Manager Geolocation API: после включения и ввода ключа — запросы GET выбранному вами провайдеру с публичным внешним IP прокси, найденным ручной проверкой, и вашим ключом (подробности в разделе «Необязательные функции и их данные»); таймера нет, при открытии списка запросов нет.
  • Proxy: после включения трафик браузера (весь или только для перечисленных вами доменов) идёт на сервер прокси или VPN, который вы настроили. Необязательный companion соединяется только с серверами ваших профилей, пока вы подключаетесь или проверяете профиль.
  • Проверка прокси: только по нажатию кнопки проверки один HTTP(S)-запрос GET идёт через выбранный прокси на адрес, который можно изменить (по умолчанию api.ipify.org). Запрос делает companion; cookies браузера не передаются, перенаправления не выполняются.
  • Автосерфер и нативная сессия профиля (Chrome): открытая расширением вкладка или окно переходит по введённым вами адресам и ссылкам того же сайта, найденным на этих страницах.
  • Ссылки в разделе «Контакты» и шапке, а также письма модуля «Защита» (mailto) открываются или запускаются только по вашему нажатию.

Сайты, Chrome и ваш почтовый провайдер делают собственные запросы; эта политика на них не распространяется.

Настройки наблюдения

Обычное локальное наблюдение включается автоматически после установки на сайтах, к которым браузер предоставил доступ. Состояние наблюдения и область сохраняются локально. Область можно сузить или выключить, документ — приостановить, результаты — очистить. Кнопка «Выключить и очистить» находится в настройках. Сохранённое отключение и ранее выбранная область сохраняются. Запись Pro и блокировка API включаются отдельно.

Установки без сохранённого состояния наблюдения получают тот же включённый режим по умолчанию. Уже открытые страницы получают сенсоры document_start при следующей загрузке. После изменения блокировки API перезагрузите страницы; для полного удаления старых обёрток, особенно в замороженном контексте, может потребоваться перезагрузка. Ошибка сохранения или удаления оставляет наблюдение недоступным до повторной попытки.

Обрабатываемые данные

При запуске, пока фоновый процесс загружает настройки наблюдения, ограниченный буфер памяти временно удерживает сокращённые метаданные ресурсов и заголовков: браузерные идентификаторы владельца, сокращённые домены, фиксированные имена правил, заголовков и hints, счётчики. Полные URL, cookies, произвольные значения заголовков и точные предпросмотры в него не входят. Лимит — 256 событий и 128 владельцев заголовков; очищенный ответ ждёт commit до двух секунд. Буфер обрабатывается после загрузки включённого состояния или успешного сохранения режима новой установки. Сохранённое отключение, неверное состояние, незавершённое изменение настроек или ошибка хранения удаляют буфер. Последующее включение наблюдения не восстанавливает удалённые события.

  • Метаданные посещений и ресурсов: browser tab/frame/document identity, доступные домены, навигация и запросы, выбранные имена response headers и Client Hints. Полные адреса кратковременно нужны для проверки доступа и распознавания, но не сохраняются как неограниченный журнал. Регистрируемый домен посещённого сайта из области наблюдения хранится вместе со значком до семи суток (см. «Хранение и сроки»).
  • Поддерживаемые операции API, фазы, ограниченные счётчики, грубые интервалы активности и покрытие. Специальные сборщики не получают нажатия клавиш, содержимое форм/clipboard, значения координат указателя, тела запросов/ответов общего вида, Authorization, пароли, private keys, аудиосемплы или медиапотоки.
  • Маячки известных аналитических и рекламных сервисов (Google Analytics и Ads, Meta, TikTok, Яндекс, LinkedIn): для этих точных адресов расширение кратковременно разбирает адрес запроса и его тело в памяти. Сохраняются только тип события, ограниченное числовое значение и валюта, а также признак наличия отдельных идентификаторов и состояний согласия (в инспекторе и в записи Pro); исходные адреса, тела, идентификаторы, адреса e-mail, номера телефонов, хэши и сведения о заказе отбрасываются.
  • Изображения Canvas/WebGL, уже прочитанные страницей, и выбранные точные технические результаты API: характеристики дисплея/браузера/GPU, WebRTC codec, отдельные SDP-derived и stats fields. Полный SDP, ICE passwords/candidates/IP клиента или peer, device IDs и произвольные объекты исключены из технических предпросмотров.
  • Полный fingerprint WebRTC-сертификата и доступный через Chrome исходящий X-Client-Data с ID экспериментов. Это потенциально идентифицирующие технические сведения, но не доказанный уникальный ID устройства/пользователя или причина CAPTCHA.
  • Отдельная история WebRTC: hostname или IP настроенных ICE-серверов, порты и состояния соединений. Это адреса серверов, не измерение геолокации пользователя и не доказательство обращения к серверу.
  • Только после вашей команды Pro: посещения, очищенные названия страниц и URL-шаблоны, разрешённые сетевые метаданные и результаты анализа. Изображения и названия страниц могут содержать личные или чувствительные сведения, в том числе случайно отображённые сообщения, медицинские или финансовые данные. Расширение не объявляет визуальное содержимое безопасным или анонимным.

Необязательные функции ниже обрабатывают описанные там дополнительные данные, только когда вы их включили или запустили.

Необязательные функции и их данные

Запреты API. Выключены по умолчанию. Локально хранятся ваш выбор, пресет и правила для не более чем 128 точных имён сайтов. Выбранные вызовы могут отклоняться или API становиться недоступным; это меняет поведение сайта и может нарушить его работу. После изменений перезагрузите страницы.

Антидетект. Выключен по умолчанию. После включения подменяет значения, которые выбранные API браузера возвращают страницам, и заголовки User-Agent, Accept-Language и client hints в запросах браузера на значения, выбранные вами или построенные по встроенным офлайн-таблицам (в сети ничего не ищется); часть заголовков устройства, окна и сети может удаляться. Запросы самого расширения исключены. Сайты видят подменённые значения, в этом смысл функции; анонимность и необнаруживаемость не обещаются, сайты могут заметить изменения. Расширение хранит вашу конфигурацию, исключения для сайтов, библиотеку до 128 профилей (название, теги, заметка и значения), корзину удалённых профилей на семь суток и запись для возврата прежнего состояния после временного профиля. При первом применении значения, которому он нужен, оно также создаёт случайный 256-битный локальный ключ, из которого выводит повторяемые для профиля вариации результатов Canvas, звука, WebGL, Math и Network Information, и случайное зерно для стабильных идентификаторов устройств WebRTC. Эти ключи никогда не экспортируются, не отправляются и не показываются, ни одно действие в интерфейсе их не удаляет; они исчезают при удалении расширения. Страница Options может прочитать параметры этого браузера (объём памяти, строки GPU через один временный контекст WebGL, сведения адаптера WebGPU) в память страницы для подсказок; ничего не сохраняется и не отправляется. Выбранная политика WebRTC может применяться ко всему браузеру после optional-разрешения privacy. Экспорт — файлы, которые вы создаёте после предпросмотра; в них ваши выборы, а не ключи.

Proxy. Выключен по умолчанию. Расширение хранит названия профилей, адреса и порты серверов, настройки маршрутизации и необязательную заметку о стране, которую вы вводите сами (она не определяется). Логины, пароли, адреса VLESS и конфигурации OpenVPN расширение не хранит: они есть в памяти страницы Options, пока вы редактируете, и в зашифрованном файле companion. Пока Proxy включён, оператор вашего сервера видит адреса назначения вашего трафика и любое незашифрованное содержимое; при сбое прокси или companion трафик блокируется, а не идёт напрямую. С optional-разрешением privacy Proxy может также менять настройки WebRTC и предсказания сети в браузере, пока активен, и возвращает их после отключения. История проверок (время, результат, время ответа, признаки DNS и TLS, HTTP-статус и внешний IP прокси, каким его увидел сайт проверки; никогда не проверяемый адрес и не ваш логин) хранит до 30 записей на профиль в течение 30 суток, может быть выключена и очищена. Кнопка Copy JSON кладёт полный набор профилей, включая логины и ключи, в системный буфер обмена только по вашей команде и с optional-разрешением clipboardWrite; расширение не очищает буфер обмена, содержимое могут прочитать другие программы.

Необязательный companion для Windows. Отдельная программа, нужная только для профилей с логином, VLESS или OpenVPN. Она устанавливается для текущего пользователя Windows без прав администратора и регистрирует Native Messaging host для расширения; браузер запускает её только при необходимости. Она хранит ваши профили в файле, зашифрованном Windows DPAPI, в каталоге данных приложений (roaming) вашей учётной записи Windows (Detect.Expert/Proxy), слушает только loopback-интерфейс, не скачивает и не обновляет свои движки и соединяется только с серверами ваших профилей и, через выбранный прокси, с введённым вами адресом проверки. Скрипт удаления снимает регистрации, но оставляет зашифрованный файл: сначала удалите профили в расширении (оно попросит companion удалить их) или удалите файл сами.

Cookies и инструменты сайта. Optional-разрешение cookies запрашивается нажатием. Когда доступ есть, раздел Cookies сам читает метаданные cookies всех хранилищ браузера (имя, домен, путь, флаги, срок; значений в списке нет) и показывает их по доменам; без доступа ничего не читается. Можно изменять, удалять, импортировать и экспортировать cookies выбранных хранилищ; значение читается только по вашей команде (показать, изменить, экспорт). Значения cookies остаются в памяти этой вкладки Options и стираются при уходе со вкладки, скрытии или закрытии страницы, отзыве разрешения; в хранилища, журналы и отчёты они не записываются. Файлы экспорта (JSON, текст Netscape или JSON, зашифрованный паролем) содержат значения cookies и сохраняются вами; незашифрованный файл содержит пригодные для использования учётные данные сеанса. В детекторе «Очистить cookies сайта» удаляет cookies зарегистрированного домена выбранной вкладки после вашего нажатия; значение одной cookie можно показать в живой панели после нажатия; тест восстановления tracking-cookie удаляет одну выбранную вами постоянную cookie, десять секунд следит, вернётся ли она, и восстанавливает исходную, если сайт не записал новое значение (значение держится в памяти только на время теста).

Автосерфер (только Chrome). После Start вкладка в новом окне проходит по вашему списку адресов (до 200) и ссылкам того же сайта, прокручивает страницу и наводит указатель через интерфейс отладчика Chrome; Chrome показывает баннер отладки. Он не нажимает, не вводит текст, не заполняет формы и не решает CAPTCHA. Ваш список адресов и последний отчёт (посещённые origin, время, коды статусов и агрегаты CPU и памяти, если вы разрешили системные метрики) хранятся в базе расширения на диске, пока вы их не измените или не очистите. Положения указателя и найденные ссылки используются только в текущем переходе. Сайты вашего списка устанавливают и читают свои cookies в профиле браузера так же, как при ручном посещении. По завершении, Stop или Clear расширение закрывает созданное им окно (вкладки, открытые вами в нём самим, остаются); недоступный сайт пропускается и записывается как прерванное посещение.

Browser Debug. Каждый набор данных запрашивает свои optional-разрешения при нажатии (история, закладки, загрузки, cookies, вкладки, сеансы, топ-сайты, список чтения, расширения, настройки приватности, разрешения сайтов, системные сведения, профиль аккаунта). Данные показываются только в памяти вкладки Options и расширением не сохраняются; строки cookies значений не показывают. Некоторые разделы могут менять данные браузера по вашей явной команде, например добавить запись истории, изменить или удалить закладку, стереть запись списка загрузок, удалить cookie, закрепить или заглушить вкладку, включить или выключить другое расширение, изменить булеву настройку приватности или разрешение сайта для одного origin. Экспорт создаётся после предпросмотра, убирает userinfo, query и fragment из веб-адресов и скрывает значение аккаунта.

Зона Cloudflare (режимы Precursor). API-токен вы вводите сами. Он хранится в памяти расширения и в сессионном хранилище браузера (только доверенные контексты расширения), пока вы не отключитесь, не очистите данные или не закроете браузер; на диск, в отчёты, журналы и экспорт он не попадает. ID и имя зоны, последний прочитанный режим и история смены режимов (до 128 записей) хранятся в локальном хранилище, пока вы их не очистите. Необязательные уведомления используют разрешение notifications, которое вы выдаёте кнопкой.

Proxy Manager Geolocation API. Выключен по умолчанию. После включения и ввода ключа менеджер прокси показывает страну, город, организацию и признаки (прокси, VPN, Tor, хостинг) для внешнего IP ваших прокси. Для этого страницы расширения отправляют выбранному вами провайдеру (MaxMind GeoLite или GeoIP, ipgeolocation.io, ipdata или ip-api.com) запрос GET с публичным внешним IP, найденным ручной проверкой прокси, и вашим ключом (MaxMind — номером аккаунта и лицензионным ключом), без cookies, referrer и перенаправлений; частные и зарезервированные адреса не отправляются. Провайдер видит и адрес, с которого пришёл запрос (ваш IP или выходной IP активного маршрута), и со временем может узнать, какие прокси вы проверяете. Запросы идут сразу после ручной проверки (можно выключить), по кнопке и при проверке ключа; таймеров и запросов при открытии списка нет. Бесплатная точка ip-api.com работает только по незашифрованному HTTP и включается вашим отдельным подтверждением; с ключом используется HTTPS. Если провайдер не ответил, тот же адрес может уйти следующему включённому вами провайдеру (можно выключить). По умолчанию ключи лежат только в сессионном хранилище браузера и исчезают при закрытии браузера; с галочкой «Запомнить ключи на этом компьютере» они хранятся в локальном хранилище без шифрования. Кэш результатов (до 200 записей, 30 суток) лежит там же и очищается кнопкой. Ключи не попадают в экспорт, отчёты, журналы и синхронизацию. Данные провайдеров приблизительны; они не оценивают безопасность прокси или сайта.

Модуль «Защита» (Firewall, только Chrome). Выключен по умолчанию; вы включаете его после экрана согласия, а политика организации может его только запретить. В зависимости от выбранных вами функций он блокирует или разрешает сетевые запросы по правилам, добавляет заголовок Sec-GPC и сопоставляет то, что вы вводите в поля e-mail, телефона и имени, с телами исходящих запросов этой вкладки: значение читается в изолированном контексте страницы после доверенного ввода, в память service worker расширения попадают только ключевые отпечатки его вариантов (15 минут), а тела запросов сканируются в памяти (до 64 KiB на запрос, найденные токены хранятся не дольше 10 секунд). Пароли, поля, бывшие паролями, платёжные поля и одноразовые коды не читаются никогда. Введённое значение и всё, что из него получено, не записывается в хранилища, журналы, экспорт и сообщения. Модуль хранит в базе на диске, которую расширение не шифрует, исключения сайтов и решения, необязательную историю доменов и дней (отдельная галочка; 7, 30 или 90 суток) и журнал подготовленных вами писем-запросов о данных (до 100 записей, от 30 до 730 суток в зависимости от статуса).

Значки сайтов. Чтобы показать значок рядом с названием посещённого сайта в отчётах, расширение хранит копию PNG 32 на 32 и регистрируемый домен до 64 сайтов, замеченных в области наблюдения, каждый до семи суток.

Интерфейс. Локально хранятся выбранные вами язык, тема и вид Light или Pro, раскладка списка прокси и шаг экскурсии по интерфейсу.

Хранение и сроки

Предпросмотры в памяти: изображения и X-Client-Data не входят в хранилище браузера, обычные отчёты, Pro/PDF, diagnostics или JSON-экспорт. Выбранные технические результаты API и WebRTC в Light остаются в памяти; во время запущенной пользователем записи Pro разные значения и выбранные технические параметры вызовов сохраняются в локальном Pro-отчёте и PDF. Canvas захватывается в первые 60 секунд сенсора; принятые изображения могут отображаться дольше. Галерея: до 256 изображений и 12 MiB закодированных символов на документ, до четырёх документов в SW с десятиминутным idle TTL. Это лимиты текста, не точное измерение RAM браузера.

До 256 строк/64 KiB значений API на realm живут до reset, pause или уничтожения realm. Google headers ограничены восемью хостами в восьми документах, 4096 символами/header и десятью минутами на host; перезапуск SW теряет их кэш. Canvas/API могут восстанавливаться из того же живого разрешённого документа после SW restart без нового чтения страницы. Замороженный realm может задержать физическое освобождение памяти.

Сессия браузера: временные отчёты и служебные identity/watermarks ограничены 4 MiB; неактивные документы истекают через десять минут. ICE-история: до восьми документов по 32 KiB, до десяти минут без обновления. Канал изображений хранит только небольшой реестр владельцев, без пикселей. Спящий SW очищает просроченное при следующей активности, не в гарантированную миллисекунду. Сессионное хранилище — память браузера: оно очищается при закрытии браузера или перезагрузке расширения. Там же лежат запись Pro, токен Cloudflare, ключи Geolocation API (если не включено «Запомнить ключи»), чекпойнт Автосерфера, сессионные зёрна WebRTC и доказательства модуля «Защита» (до 1 MiB, срок десять минут).

Pro: запись длится до десяти минут и ограничена 3 MiB. Остановленная запись может сохраняться дольше окна захвата, до замены, очистки или завершения сессии браузера/расширения. Изображения и значения заголовков Google в неё не входят. Выбранные технические результаты API и параметры вызовов включены: до 256 вариантов / 64 KiB на документ. Во время явно запущенной записи Pro имена и значения из исходящих заголовков Cookie разрешённых записываемых запросов также сохраняются локально и входят в отчёт и PDF. В запись также входят значения фиксированного списка из 38 технических заголовков запросов, которые отправил браузер (например User-Agent, Accept-Language и client hints; Authorization и Set-Cookie — никогда). Этот сбор не читает хранилище cookies браузера и посторонние заголовки запросов. Значения cookies не входят в обычные отчёты Light и очищенный JSON-экспорт.

Сохранённые Pro-отчёты: если вы нажали Save у остановленного Pro-отчёта, копия записывается в базу расширения на диске (IndexedDB): до 20 отчётов и 8 MiB JSON. В ней те же поля, что в Pro-отчёте, то есть могут быть названия страниц, URL-шаблоны и значения исходящих Cookie. Копия хранится, пока вы не удалите её в списке истории; общая очистка и «Выключить и очистить» тоже удаляют её, даже когда все страницы расширения закрыты.

Настройки: состояние наблюдения, область и её предыдущий режим, правила сайтов, язык, тема, вид Light/Pro, настройки запретов API, описанные выше данные Антидетекта и Proxy, сохранённая зона Cloudflare и её история, настройки модуля «Защита», настройки и кэш результатов Geolocation API (а её ключи — только если вы включили «Запомнить ключи на этом компьютере») и кэш значков сайтов хранятся в chrome.storage.local до изменения, удаления или деинсталляции; у элементов со своим лимитом (корзина, история проверок, значки, временный профиль) срок указан выше. Это незашифрованные файлы в профиле вашего браузера. storage.sync не используется. Очистка, пауза, отзыв доступа, замена документа/фрейма, TTL и лимиты аннулируют применимые предпросмотры. Тумблер под логотипом останавливает наблюдение и возвращает прежнюю область при включении. Остановленный Pro-отчёт сохраняется.

Базы на диске: сохранённые Pro-отчёты, данные модуля «Защита» и список с отчётом Автосерфера, как описано выше, лежат в базах расширения (IndexedDB), которые расширение не шифрует. Хранилище страниц: тема, раскладка списка прокси, скрытое уведомление Geolocation API и шаг экскурсии используют localStorage собственных страниц расширения. Вне расширения: файлы экспорта, буфер обмена и зашифрованный файл companion расширение не удаляет.

Разрешения браузера

Объявлены при установке: activeTab, scripting, storage, webRequest, webNavigation, sidePanel, alarms, declarativeNetRequestWithHostAccess, userScripts, proxy и debugger, а также доступ к страницам http, https, ws и wss. Они нужны для наблюдения, необязательных функций выше, раздела Proxy, а также окна Автосерфера и нативной сессии профиля, которые вы запускаете (пока отладчик подключён, Chrome показывает баннер отладки). Запрашиваются нажатием и отзываются: history, bookmarks, downloads, cookies, tabs, sessions, topSites, readingList, management, privacy, contentSettings, system.cpu, system.memory, system.storage, system.display, identity, identity.email (Browser Debug и инструменты cookies), nativeMessaging (companion для Proxy), clipboardWrite (Copy JSON) и notifications (уведомления Cloudflare). В сборке Firefox нет частей, существующих только в Chrome (модуль «Защита», Автосерфер, нативная сессия профиля), а часть этих разрешений предлагается только как необязательные. Расширение не работает в приватных окнах.

Передача и экспорт

Нет аккаунта расширения, аналитики, телеметрии, удалённого кода/списков и автоматической загрузки отчётов. Данные инспекции не отправляются издателю или третьим лицам. Соединения, которые расширение устанавливает при использовании функции, и единственный автоматический запрос значка перечислены в разделе «Сетевые соединения». Весь исполняемый код и правила включены в пакет. Собственные запросы сайтов продолжаются независимо.

JSON сохраняется после redacted preview; host отчёта по умолчанию исключён. Pro PDF использует локальную печать браузера и содержит показанные в предпросмотре поля записи, включая значения отправленных cookies. Остальные функции создают файлы только по вашей команде: конфигурация и библиотека Антидетекта (без приватных ключей), метаданные профилей Proxy (без логинов и ключей), файлы cookies, снимки Browser Debug, отчёты Автосерфера и экспорт модуля «Защита». Минимальная диагностика включает только версии расширения/браузера и доступность SW. Файлами и ручной передачей управляете вы. Поддержка получает лишь сведения, которые вы отдельно отправили на info@detect.expert. Не отправляйте пароли, файлы cookies, личные изображения или идентификаторы без необходимости и осознанного выбора.

Ссылки шапки открывают внешние сайты только по нажатию, без добавления отчётов и с защитой referrer/opener. Посещение и отправку письма обрабатывают соответствующие сайты и почтовый провайдер по своим правилам. Эта политика не обещает отсутствие логов или cookies у посещённого сайта.

Limited Use и безопасность

Detect.Expert использует данные только для описанных функций: локальная инспекция и запись, а также необязательные инструменты выше, каждый из которых запускаете или включаете вы, — в соответствии с Chrome Web Store User Data Policy, включая Limited Use. Данные не продаются, не используются для рекламы, постороннего профилирования, кредитоспособности/кредитования или обучения моделей. Разработчик автоматически не читает ваши отчёты; поддержка рассматривает лишь конкретные сведения, которые вы явно предоставили.

Данные ограничены и изолированы в контекстах расширения с browser-derived проверками владельца и доступа, кроме того, что вы сами направляете в другое место: прокси- или VPN-сервер, который вы настроили, API Cloudflare, провайдер геолокации, которого вы подключили, экспортируемые вами файлы и буфер обмена. Page-controlled наблюдение не является удостоверенным доказательством. Запреты API и Антидетект выключены по умолчанию, требуют отдельного включения и могут ломать сайт. Анонимность, невидимость, полное покрытие и общий вердикт безопасности не обещаются. Расширение не шифрует локальные хранилища браузера: файлы chrome.storage.local и баз расширения в вашем профиле может прочитать любой, у кого есть доступ к вашей учётной записи ОС. Файл companion использует Windows DPAPI. Защищайте профиль браузера и учётную запись ОС.

Удаление и изменения

Используйте отдельную очистку Light, Pro или всей сессии; у сохранённой истории Pro-отчётов есть собственное удаление. Отзыв согласия в настройках («Выключить и очистить») останавливает наблюдение и очищает сессию, архив Pro, кэш значков и подключение Cloudflare; выключение scope или удаление расширения прекращает будущую работу. Данные функций удаляются их собственными средствами: профили и корзина Антидетекта, профили и история проверок Proxy, список и отчёт Автосерфера, очистка модуля «Защита», Disconnect для Cloudflare, кнопки «Удалить все ключи» и «Очистить кэш» Geolocation API. Перезагрузка страниц удаляет обёртки. Деинсталляция удаляет хранилища расширения, но не скачанные файлы, содержимое буфера обмена, companion с его зашифрованным файлом профилей и ранее отправленные поддержке сообщения. Перед удалением расширения выключите Proxy. Существенные изменения обработки будут явно раскрыты до её начала; где требуется, согласие будет запрошено заново. Контакт по политике: info@detect.expert.
