detect.expert - region data notice

apps/production-extension/fingerprint-region-data.js is an offline table "country -> language, time zone, coordinates"
(247 regions, 418 time zones). It is generated by scripts/production/gen-region-data.mjs from the two sources below.
The extension contains the derived values only (language tags, English region names, time zone ids, city labels,
coordinates); it reads no other source and makes no request to these sources at run time.

1. IANA Time Zone Database (tz database), release 2026f - public domain
   Files used: zone.tab, zone1970.tab, iso3166.tab (each file states "This file is in the public domain"; no license
   text is required). Dated 2026-10-28 on the IANA server. Official archive tzdata2026f.tar.gz, sha256
   01b4a91cec5167ed48c11e8ab78f2048cead78ce94b0cafcad0ae8c5a3044d3d; the files are byte-identical to the archive members.
   sha256 of the files as published:
     zone.tab      e2e8e31c4e10f44576c79345e76060591dbb3eef6ce14e006afc8a373caa9593
     zone1970.tab  5f23781702bf51408ff1581daa109ab3b9257fb433b1554e579d92172892c0cf
     iso3166.tab   837c80785080c8433fd9d4ea87e78f161ac7a40389301c5153d4f90198baeb2a
   Source tree copy (build input only, not shipped): packages/catalog/data/tzdata.
