# detect.expert — политика обработки данных / Privacy policy

Версия / Version: 2026-11-06 · production 2.0.0 · REQ-005/010/013, ADR-007, ADR-020-protect, ADR-035/041/069/070/071/075/076/097/108/109.
Основание: [инвентарь данных](docs/data-inventory.md) — сверка с исходным кодом production-расширения 2026-11-06 (источники указаны там по файлам и строкам). Контакт: Vektor T13, через репозиторий проекта.

## Русский

detect.expert — информационный анализатор браузерных проверок с несколькими необязательными инструментами: запреты API, Antidetect (выбранные значения), Proxy, работа с cookies, Автосерфер, Browser Debug, чтение зоны Cloudflare, Proxy Manager Geolocation API и модуль «Защита». Обработка происходит локально в браузере. Аккаунт не нужен; аналитики, telemetry и сервера разработчика нет. Расширение не отправляет отчёты, настройки и историю разработчику или организации и не скачивает код или правила. Запросы самой открытой страницы и служебные соединения Chrome не являются соединениями расширения.

### Что изменилось с редакции 2026-09-13

Прежняя редакция описывала только наблюдение: в `chrome.storage.local` один ключ `scope`, исходящих соединений нет, дисковой истории нет. Для версии 2.0.0 это неверно. Теперь описаны: Antidetect (значения, библиотека профилей, корзина, приватный ключ шума); Proxy (метаданные профилей, история проверок, необязательная программа-companion с защищённым хранилищем); инструменты cookies, Автосерфер, Browser Debug, чтение зоны Cloudflare и модуль «Защита»; архив Pro-отчётов и три базы IndexedDB на диске; кэш значков сайтов; настройки интерфейса; соединения, которые возможны по команде пользователя. Прежние утверждения «исходящих соединений нет» и «хранится только `scope`» заменены точным перечнем.

### Исходящие соединения

Чего нет: аккаунта, аналитики, telemetry, отчётов о сбоях, удалённого кода (весь исполняемый код и правила распознавания находятся в пакете; скрипты Antidetect собираются на вашем устройстве из упакованных функций и выбранных значений), удалённых списков и обновлений правил, автоматической выгрузки отчётов, настроек или истории. Content Security Policy страниц расширения разрешает их скриптам соединения только с перечисленными адресами: `connect-src https://api.cloudflare.com https://geolite.info https://geoip.maxmind.com https://api.ipgeolocation.io https://api.ipdata.co http://ip-api.com https://pro.ip-api.com` (Cloudflare и хосты четырёх провайдеров геолокации; последние нужны только функции Proxy Manager Geolocation API).

Без вашей команды расширение само инициирует одно обращение к сети: для показа значка посещённого сайта оно просит страницу из области наблюдения ещё раз загрузить значок, адрес которого Chrome уже сообщил для вкладки (без referrer; значки `data:` запроса не делают). Всё остальное — только при использовании функции:

- Cloudflare: после «Connect» с токеном, который вы ввели, запросы `GET` к `api.cloudflare.com` (данные одной зоны и её режим Precursor), далее примерно раз в минуту, пока соединение активно.
- Proxy Manager Geolocation API: после включения и ввода ключа — запросы `GET` выбранному вами провайдеру с публичным внешним IP прокси, найденным ручной проверкой, и вашим ключом (подробности — в разделе о функциях); таймера нет, при открытии списка запросов нет.
- Proxy: после включения трафик браузера идёт на сервер прокси или VPN, который вы настроили; необязательный companion соединяется только с серверами ваших профилей при подключении и проверке.
- Проверка прокси: только по нажатию — один HTTP(S) GET через выбранный прокси на адрес, который можно изменить (по умолчанию `api.ipify.org`).
- Ссылка на загрузку companion: вкладка Proxy показывает обычную ссылку на страницу последнего выпуска в репозитории GitHub (`github.com/vektort13/Detect.Expert`, Releases). Расширение само к GitHub не обращается и не скачивает и не устанавливает companion: адрес открывается в новой вкладке (без opener и referrer) только когда вы нажимаете ссылку, дальше действует политика GitHub. Карточка рядом со ссылкой ничего не хранит.
- Автосерфер и нативная сессия профиля: навигация собственной вкладки или окна по адресам, которые вы ввели, и ссылкам того же сайта.
- Ссылки (раздел «Контакты», шапка, письма `mailto:`) открываются только по нажатию.

### Что обрабатывается

Обычное наблюдение включается автоматически после установки на сайтах, к которым Chrome выдал доступ (ADR-041); область можно сузить, документ приостановить, наблюдение выключить («Выключить и очистить»). В этой области расширение наблюдает типы обращений к поддерживаемым браузерным API, насыщаемые счётчики, фазы вызовов, коды признаков и округлённые временные интервалы. Из событий навигации Chrome оно получает привязку документа и кадра; из сетевых событий — направления запросов. URL обрабатывается локально для проверки доступа и выделения разрешённых сведений; полный URL не сохраняется в отчёте. Домен отчёта и сетевые направления редактируются по встроенному офлайн Public Suffix List (ICANN + PRIVATE): сохраняется регистрируемый домен, для IP/локальных/неизвестных направлений — только категория или null. Произвольные поддомены, пути, query и fragment в отчёт не включаются. Для точных адресов маячков известных аналитических и рекламных сервисов (Google Analytics и Ads, Meta, TikTok, Яндекс, LinkedIn) адрес и тело запроса разбираются кратковременно в памяти; сохраняются только тип события, ограниченное значение и валюта, признаки наличия идентификаторов и согласия (ADR-030). Отдельные предпросмотры (Canvas/WebGL, выбранные технические значения API, WebRTC, X-Client-Data) живут только в памяти, а запись Pro по вашей команде содержит больше сведений — перечень в [политике для магазина](apps/production-extension/privacy.html).

### Что хранится

- В `chrome.storage.session` (память браузера, не диск): отчёты отдельных документов, счётчики, находки и их ограничения, coverage и счётчики потерь, редактированные сетевые направления; служебные идентификаторы вкладки/кадра/документа, привязки, состояние паузы, отметки доставки и данные контроля области доступа; запись Pro; токен Cloudflare; ключи Proxy Manager Geolocation API (если не включено «Запомнить ключи»); чекпойнт Автосерфера; сиды WebRTC на сессию; до 8 пар меток времени, когда датчики наблюдения удерживались вне страниц; доказательства модуля «Защита». Записи active-tabs содержат только tabId/documentId; метаданные привязок могут содержать схему http/https. Эти служебные данные не включаются в экспорт.
- Лимиты: до 100 KiB на отчёт и 4 MiB на session. При нехватке места данные вытесняются с указанием неполноты. Неактивные документы старше 10 минут очищаются при следующем событии расширения; остановленный service worker не просыпается по таймеру, поэтому это не точный срок удаления. Закрытие вкладки инициирует очистку; при прерывании операции остаток удаляется последующей очисткой. Перезапуск браузера, disable/reload/update расширения очищают session.
- В `chrome.storage.local` (профиль браузера на диске, не шифруется средствами расширения; 27 ключей на момент сверки, 28 при включённой памяти ключей Geolocation API; `storage.sync` не используется):
  - наблюдение: `scope: {v, scopeMode, hosts}` — выбранный режим и точные нормализованные имена выбранных пользователем сайтов (это постоянные настройки, а не история посещений), `data-consent:v1`, `scope:full-access-default-v1`, `scope:resume-mode-v1`; запреты API — `protection:v1`, `protection:pending:v1`, `protection:compatibility:1.1.0`; кэш значков `site-icons:v1` — регистрируемый домен посещённого сайта из области наблюдения и значок 32×32, до 64 сайтов, 7 суток;
  - Antidetect: `api-configuration:v1` (выбранные значения, исключения для сайтов, библиотека до 128 профилей с метками, тегами и заметками), `fingerprint-trash:v1` (корзина на 7 суток), `fingerprint-temporary:v1`, `identity-bundles:v1`, `antidetect-quiet-sensors:v1` (одно булево значение: не запускать датчики наблюдения, пока включён Antidetect), случайные ключи `profile-noise-root:v1` и `webrtc-device-site-seed:v1` (создаются при первом применении значений, которым они нужны);
  - Proxy: `proxy-configuration:v1` (имена профилей, адреса и порты серверов, маршрутизация; без логинов и паролей), `proxy-vault-state:v1`, `proxy-native-restart:v1`, `proxy-privacy-owner:v1`, `proxy-check-history:v1` (результаты ручных проверок и внешний IP прокси, 30 суток);
  - Proxy Manager Geolocation API: `proxy-geo-settings:v1` (переключатели, выбор столбцов, параметры провайдеров; без ключей), `proxy-geo-cache:v1` (до 200 результатов для внешних IP ваших прокси, не старше 30 суток), `proxy-geo-credentials:v1` — ключи провайдеров, только если вы включили «Запомнить ключи на этом компьютере»;
  - Cloudflare и «Защита»: `precursor-modes:v1` (ID и имя зоны, последний режим, история переходов), `precursor-transport:v1`, `protect` (настройки модуля);
  - интерфейс: `ui-language-v1`, `ui-theme-v1`, `ui-mode-v1`.
- На диске в IndexedDB (не шифруется средствами расширения): `detect-expert-pro-report-history` (Pro-отчёты, которые вы сохранили кнопкой Save; до 20 штук и 8 MiB), `detect-expert-protect` (данные модуля «Защита»: исключения, решения, история «Кто вас узнаёт» по отдельной галочке на 7/30/90 дней, журнал запросов о данных) и `detect-expert-autosurf` (список ваших адресов и последний отчёт Автосерфера).
- В `localStorage` страниц расширения: зеркало темы `ui-theme-v1`, вид списка прокси `proxy-view:v1`, отметка скрытого уведомления Geolocation API `proxy-geo-banner:v1` и шаги экскурсий `ui-tour:v2` (по одной записи на раздел; прежнее значение `ui-tour:v1` читается один раз и заменяется).
- Секреты прокси (логин, пароль, URI VLESS, конфигурация OpenVPN с ключами) расширение не хранит: их хранит необязательная программа-companion в файле, защищённом Windows DPAPI, в профиле пользователя Windows. Только в памяти: значения cookies (Cookies), токен Cloudflare, ключи Geolocation API в полях ввода и данные ввода в окнах настроек, снимки Browser Debug, отпечатки значений и фрагменты запросов модуля «Защита».
- Синхронизация через аккаунт браузера, управляемый корпоративный канал (единственная политика `ProtectModuleDisabled` лишь запрещает модуль) и долговременный диагностический журнал не реализованы.

### Функции, которые включает пользователь

- **Запреты API.** Выключены по умолчанию. Хранятся ваши выбор, пресет и правила для сайтов. Выбранные вызовы могут отклоняться, что может нарушить работу сайта.
- **Antidetect.** Выключен по умолчанию. После включения подменяет значения, которые выбранные API возвращают страницам, и заголовки запросов браузера (User-Agent, Accept-Language, client hints; часть заголовков устройства и сети удаляется) на выбранные вами или построенные по встроенным таблицам значения; сайты видят подменённые значения, в этом смысл функции. Анонимность и необнаруживаемость не обещаются. Случайный ключ шума никогда не экспортируется, не передаётся и не удаляется действием в интерфейсе; он исчезает вместе с расширением. Страница Options может прочитать параметры вашего браузера (память, строки GPU, сведения адаптера WebGPU) только в память страницы для подсказок.
- **Proxy.** Выключен по умолчанию. Включение меняет настройку прокси браузера; оператор выбранного сервера видит адреса назначения и незашифрованное содержимое. Если прокси или companion отказывает, трафик блокируется, а не идёт напрямую (kill switch). Кнопка Copy JSON по вашей команде кладёт в системный буфер обмена полный набор профилей с логинами и ключами (optional-разрешение `clipboardWrite`); расширение не очищает буфер, и его содержимое могут прочитать другие программы. Удаление расширения не удаляет файл companion с профилями.
- **Cookies и инструменты сайта.** Optional-разрешение `cookies` запрашивается нажатием. Когда доступ есть, раздел сам читает метаданные cookies всех хранилищ браузера (имя, домен, путь, флаги, срок; значений в списке нет) и показывает их по доменам; без доступа ничего не читается. Значения cookies читаются только по отдельной команде (показать, изменить, экспорт), показываются только в памяти страницы Options и стираются при уходе со вкладки, скрытии страницы или отзыве разрешения. Файлы экспорта (JSON, Netscape, зашифрованный JSON с AES-256-GCM) содержат значения и создаются только по вашей команде. «Очистить cookies сайта» и тест восстановления выбранной cookie изменяют cookies браузера по вашему нажатию.
- **Автосерфер** (только Chrome, required `debugger`). После Start вкладка нового окна проходит по вашему списку адресов (до 200) и ссылкам того же сайта, прокручивает страницу и наводит указатель; Chrome показывает баннер отладки. Не нажимает, не вводит текст, не решает CAPTCHA. Сайты вашего списка устанавливают и читают свои cookies в профиле браузера так же, как при ручном посещении. По завершении, Stop или Clear расширение закрывает созданное им окно (вкладки, открытые вами в нём самим, остаются); недоступный сайт пропускается и записывается как прерванное посещение.
- **Browser Debug.** Каждый набор данных запрашивает свои optional-разрешения нажатием; данные браузера (история, закладки, загрузки, метаданные cookies без значений, вкладки, сеансы, топ-сайты, список чтения, расширения, настройки приватности, разрешения сайтов, системные сведения, профиль аккаунта) показываются только в памяти страницы Options. Отдельные записи можно менять по вашей команде. Экспорт — после preview, без query, fragment и userinfo в адресах.
- **Cloudflare (Precursor).** Токен вы вводите сами: он живёт в памяти и в `storage.session` (доверенные контексты), в `storage.local`, отчёты и экспорт не попадает. Сохраняются ID и имя зоны, последний режим и история переходов (до 128).
- **Proxy Manager Geolocation API.** Выключен по умолчанию. После включения и ввода ключа менеджер прокси показывает страну, город, организацию и признаки (прокси, VPN, Tor, хостинг) для внешнего IP ваших прокси. Для этого страницы расширения отправляют выбранному вами провайдеру (MaxMind GeoLite или GeoIP, ipgeolocation.io, ipdata или ip-api.com) запрос `GET` с публичным внешним IP, найденным ручной проверкой прокси, и вашим ключом (MaxMind — номером аккаунта и лицензионным ключом), без cookies, referrer и перенаправлений; частные и зарезервированные адреса не отправляются. Провайдер видит и адрес, с которого пришёл запрос (ваш IP или выходной IP активного маршрута), и со временем может узнать, какие прокси вы проверяете. Запросы идут сразу после ручной проверки (можно выключить), по кнопке и при проверке ключа; таймеров и запросов при открытии списка нет. Бесплатная точка ip-api.com работает только по незашифрованному HTTP и включается вашим отдельным подтверждением; с ключом используется HTTPS. Если провайдер не ответил, тот же адрес может уйти следующему включённому вами провайдеру (можно выключить). По умолчанию ключи лежат только в `storage.session` и исчезают при закрытии браузера; с галочкой «Запомнить ключи на этом компьютере» они хранятся в `storage.local` без шифрования. Кэш результатов (до 200 записей, 30 суток) лежит в `storage.local` и очищается кнопкой. Ключи не попадают в экспорт, отчёты, журналы и синхронизацию. Данные провайдеров приблизительны; они не оценивают безопасность прокси или сайта.
- **Модуль «Защита»** (только Chrome). Выключен по умолчанию; включается вами одним явным нажатием (отдельного окна подтверждения нет, ADR-098); организация может его только запретить. Правила `block`/`allow` и заголовок `Sec-GPC: 1`; сопоставление введённых вами e-mail, телефона и имени с исходящими запросами: значение читается в изолированном контексте страницы после доверенного ввода, в память service worker попадают только ключевые отпечатки (15 минут), тела запросов сканируются в памяти (до 64 KiB на запрос). Пароли, платёжные поля и одноразовые коды не читаются; значение и производные от него не записываются никуда.
- **Pro.** Запись запускается вами (до 10 минут, до 3 MiB); сохранённая кнопкой Save копия лежит на диске в IndexedDB и может содержать названия страниц, шаблоны адресов, значения исходящих Cookie и значения фиксированного списка из 38 технических заголовков запросов (например User-Agent, Accept-Language и client hints; Authorization и Set-Cookie — никогда).

### Экспорт и удаление

JSON скачивается только по действию пользователя после preview; скачивается ровно показанная проекция после проверки её актуальности. Она содержит сводку техник, интерпретации и ограничения, coverage, счётчики потерь, относительные интервалы, возраст наблюдения и режим области. Host исключён по умолчанию и включается отдельным флажком; внутренние ID документов и абсолютные даты не экспортируются. Список сетевых направлений не экспортируется. Остальные функции экспортируют только свои данные и только по команде: конфигурация и библиотека Antidetect (без приватных ключей), профили Proxy (без логинов и ключей), файлы cookies, Browser Debug, отчёт Автосерфера, данные модуля «Защита».

Отдельный диагностический preview в Options содержит только версию схемы/расширения, major Chrome и доступность service worker; не сохраняется в session. Передача скачанного файла другим людям — самостоятельное действие пользователя вне расширения.

Удаление: очистка в UI удаляет текущий отчёт; при продолжающемся наблюдении данные могут появиться снова. «Выключить и очистить» удаляет отчёты, запись Pro, архив Pro-отчётов, кэш значков и подключение Cloudflare; общая очистка сессии удаляет отчёты, запись Pro, архив Pro-отчётов и подключение Cloudflare, но не кэш значков (он стирается при выключении наблюдения, смене разрешений и через 7 суток). Функции удаляются своими средствами: корзина и профили Antidetect, профили и история проверок Proxy, список Автосерфера, purge модуля «Защита», кнопки «Удалить все ключи» и «Очистить кэш» Geolocation API. При удалении расширения Chrome удаляет его хранилища и выданные ему разрешения. Уже скачанные файлы и содержимое буфера обмена остаются у пользователя; vault companion остаётся на диске, пока вы не удалите профили в Proxy или файл. Для удаления внедрённых обёрток из уже открытых страниц требуется перезагрузка этих страниц.

### Что не собирается

Наблюдающие сенсоры и мост не записывают содержимое форм, нажатия, координаты, clipboard, cookie values, токены, Authorization, тела запросов/ответов, пиксели/dataURL, аудиосемплы, строки измеряемого текста, точные аппаратные значения, аргументы/результаты Math, сырые стеки, ICE-кандидаты или IP-адреса. Два уточнения действуют в рамках наблюдения без отдельной команды: кратковременный разбор тел запросов к известным endpoint маячков (сохраняется лишь структурированная проекция, см. выше) и список настроенных ICE-серверов (адреса серверов, не IP клиента) в `storage.session`. Остальные узкие исключения действуют только для описанных функций и только по вашей команде: значения cookies (Cookies, значения исходящих Cookie в записи Pro), токен Cloudflare, логины прокси в companion, внешний IP прокси в истории проверок и в запросе к выбранному вами провайдеру геолокации вместе с вашим ключом, сопоставление введённых значений в модуле «Защита». Расширение не создаёт профиль устройства или идентификатор, который передаётся за пределы браузера, и не продаёт данные; случайные локальные ключи (шума и WebRTC) никогда не покидают браузер. Отправка организации, upload и удалённые обновления правил отсутствуют.

Наблюдение ограничено доступными API и разрешениями; workers, WASM, CSS и серверные проверки имеют пробелы покрытия. Отсутствие находок означает, что ничего не наблюдалось в доступной области за период. Наблюдения из страницы имеют `page-controlled` integrity; обёртки могут быть замечены страницей и влиять на совместимость. Расширение не оценивает безопасность сайта. Расширение не шифрует локальные хранилища браузера; файл профилей companion шифруется самим companion средствами Windows DPAPI.

## English

detect.expert is an informational browser-check analyzer with several optional tools: API denials, Antidetect (selected values), Proxy, cookie tools, Autosurfer, Browser Debug, Cloudflare zone reading, the Proxy Manager Geolocation API and the Firewall module. Processing stays locally in your browser. No account is needed; there is no analytics, telemetry or developer server. The extension does not send reports, settings or history to its developer or an organization, and does not download code or rules. Requests made by visited pages and Chrome's own service connections are outside this statement.

### What changed since the 2026-09-13 edition

The previous edition described observation only: one `chrome.storage.local` key `scope`, no outgoing connections, no disk history. That is wrong for version 2.0.0. This edition adds Antidetect (values, profile library, trash, private noise key); Proxy (profile metadata, check history, the optional companion program with a protected vault); the cookie tools, Autosurfer, Browser Debug, Cloudflare zone reading and the Firewall module; the Pro report archive and three IndexedDB databases on disk; the site-icon cache; interface settings; and the connections that can happen when you use a feature. The earlier claims "no outgoing connections" and "only `scope` is stored" are replaced by an exact list.

### Outgoing connections

Not present: an account, analytics, telemetry, crash reporting, remote code (all executable code and recognition rules ship in the package; Antidetect page scripts are assembled on your device from packaged functions and your selected values), remote lists or rule updates, automatic upload of reports, settings or history. The Content Security Policy of the extension pages allows their scripts to connect only to the addresses listed here: `connect-src https://api.cloudflare.com https://geolite.info https://geoip.maxmind.com https://api.ipgeolocation.io https://api.ipdata.co http://ip-api.com https://pro.ip-api.com` (Cloudflare and the hosts of four geolocation providers; the latter are used only by the Proxy Manager Geolocation API).

Without a command from you the extension starts one network operation on its own: to show the icon of a visited site, it asks the page in the observation scope to load once more the icon address that Chrome already reports for the tab (no referrer; `data:` icons need no request). Everything else happens only when you use a feature:

- Cloudflare: after "Connect" with a token you entered, `GET` requests to `api.cloudflare.com` (the details of one zone and its Precursor mode), then about once a minute while the connection stays active.
- Proxy Manager Geolocation API: after you turn it on and add a key, `GET` requests to the provider you chose with the public exit IP of a proxy that a manual check found, and your key (details in the features section); there is no timer and no request when the list opens.
- Proxy: once enabled, browser traffic goes to the proxy or VPN server you configured; the optional companion connects only to the servers of your profiles while connecting or checking.
- Proxy check: only when you press the button — one HTTP(S) GET through the chosen proxy to an address you can edit (default `api.ipify.org`).
- Link to the companion download: the Proxy tab shows a plain link to the latest release page of the GitHub repository (`github.com/vektort13/Detect.Expert`, Releases). The extension itself never contacts GitHub and never downloads or installs the companion: the address opens in a new tab (no opener, no referrer) only when you click the link, and GitHub's own policy applies from there. The notice next to the link stores nothing.
- Autosurfer and the native profile session: navigation of their own tab or window to addresses you entered and same-site links.
- Links (Contacts section, header, `mailto:` letters) open only when clicked.

### Processing

Ordinary observation starts automatically after installation on sites to which Chrome granted access (ADR-041); you can narrow the scope, pause a document or turn observation off ("Turn off and clear"). Within that scope the extension observes supported API operation types, saturating counts, call phases, signal codes and rounded time buckets. Chrome navigation events provide document/frame bindings; network events provide request destinations. URLs are processed locally for access checks and permitted metadata extraction; full URLs are not stored in reports. Report domains and network destinations use the bundled offline Public Suffix List (ICANN + PRIVATE): a registrable domain, or a category/null for IP, local and unknown destinations. Arbitrary subdomains, paths, query strings and fragments are excluded from reports. For the exact beacon endpoints of known analytics and advertising services (Google Analytics and Ads, Meta, TikTok, Yandex, LinkedIn) the request address and body are parsed transiently in memory; only the event type, a bounded value and currency, and flags showing whether identifiers and consent states are present are kept (ADR-030). Separate previews (Canvas/WebGL, selected technical API values, WebRTC, X-Client-Data) live in memory only, while a Pro recording that you start holds more — the list is in the [store policy](apps/production-extension/privacy.html).

### Storage

- `chrome.storage.session` (browser memory, not disk) holds document reports, counters, findings and limitations, coverage and loss counters, redacted network destinations, internal tab/frame/document IDs, bindings, pause state, delivery watermarks and access-scope records; also the Pro recording, the Cloudflare token, the Geolocation API keys (unless you chose to remember them), the Autosurfer checkpoint, session WebRTC seeds, up to 8 pairs of timestamps for the periods when the observation sensors were kept out of pages, and Firewall evidence. Active-tabs records contain only tabId/documentId; binding metadata may contain the http/https scheme. These internal records are excluded from exports.
- Limits are 100 KiB per report and 4 MiB per session. Eviction is reflected in coverage. Documents inactive for over ten minutes are cleaned at the next extension event, not at an exact deadline: a stopped service worker does not wake on a timer. Closing a tab initiates cleanup; interrupted cleanup can leave data until a later cleanup. Browser restart and extension disable/reload/update clear session storage.
- `chrome.storage.local` (browser profile on disk, not encrypted by the extension; 27 keys at the time of review, 28 while Geolocation API keys are remembered; `storage.sync` is not used):
  - observation: `scope: {v, scopeMode, hosts}` — the selected mode and exact normalized names of sites you selected (persistent preferences, not browsing history), `data-consent:v1`, `scope:full-access-default-v1`, `scope:resume-mode-v1`; API denials — `protection:v1`, `protection:pending:v1`, `protection:compatibility:1.1.0`; the site-icon cache `site-icons:v1` — the registrable domain of a visited site in scope and a 32×32 icon, up to 64 sites, 7 days;
  - Antidetect: `api-configuration:v1` (selected values, per-site exceptions, a library of up to 128 profiles with names, tags and notes), `fingerprint-trash:v1` (7-day trash), `fingerprint-temporary:v1`, `identity-bundles:v1`, `antidetect-quiet-sensors:v1` (one boolean: do not run the observation sensors while Antidetect is on), random keys `profile-noise-root:v1` and `webrtc-device-site-seed:v1` (created when you first apply a value that needs them);
  - Proxy: `proxy-configuration:v1` (profile names, server addresses and ports, routing; no logins or passwords), `proxy-vault-state:v1`, `proxy-native-restart:v1`, `proxy-privacy-owner:v1`, `proxy-check-history:v1` (manual check results and the proxy's exit IP, 30 days);
  - Proxy Manager Geolocation API: `proxy-geo-settings:v1` (switches, chosen columns, provider options; no keys), `proxy-geo-cache:v1` (up to 200 results for the exit IPs of your proxies, at most 30 days old), `proxy-geo-credentials:v1` — provider keys, only if you turned on "Remember keys on this computer";
  - Cloudflare and Firewall: `precursor-modes:v1` (zone ID and name, last mode, transition history), `precursor-transport:v1`, `protect` (module settings);
  - interface: `ui-language-v1`, `ui-theme-v1`, `ui-mode-v1`.
- On disk in IndexedDB (not encrypted by the extension): `detect-expert-pro-report-history` (Pro reports you saved with Save; up to 20 and 8 MiB), `detect-expert-protect` (Firewall data: exceptions, decisions, the "Who recognizes you" history behind a separate checkbox for 7/30/90 days, the data-request journal) and `detect-expert-autosurf` (your address list and the last Autosurfer report).
- In the `localStorage` of extension pages: the theme mirror `ui-theme-v1`, the proxy list view `proxy-view:v1`, the dismissed state of the Geolocation API notice `proxy-geo-banner:v1` and the steps of the guided tours `ui-tour:v2` (one entry per section; the earlier `ui-tour:v1` value is read once and replaced).
- The extension does not store proxy secrets (login, password, VLESS URI, OpenVPN configuration with keys): the optional companion program keeps them in a file protected by Windows DPAPI in the Windows user profile. In memory only: cookie values (Cookies), the Cloudflare token, Geolocation API keys in input fields and form input in settings pages, Browser Debug snapshots, value fingerprints and request fragments of the Firewall module.
- Account-based synchronization, a managed enterprise channel (the only policy, `ProtectModuleDisabled`, can merely forbid the module) and a persistent diagnostic log are not implemented.

### Features you turn on

- **API denials.** Off by default. Your choices, preset and per-site rules are stored. Selected calls may be refused, which can break a site.
- **Antidetect.** Off by default. Once on, it replaces the values selected APIs return to pages, and the browser's request headers (User-Agent, Accept-Language, client hints; some device and network headers are removed), with values you select or build from built-in tables; sites see the replaced values, which is the purpose of the feature. No anonymity or undetectability is promised. The random noise key is never exported or transmitted and no interface action deletes it; it disappears with the extension. The Options page may read parameters of your browser (memory, GPU strings, WebGPU adapter details) into page memory only, to suggest values.
- **Proxy.** Off by default. Enabling it changes the browser's proxy setting; the operator of the chosen server sees destination addresses and unencrypted content. If the proxy or companion fails, traffic is blocked rather than sent directly (kill switch). The Copy JSON button, on your command, puts the full set of profiles with logins and keys on the system clipboard (optional permission `clipboardWrite`); the extension does not clear the clipboard and other programs can read it. Removing the extension does not remove the companion's file of profiles.
- **Cookies and site tools.** The optional `cookies` permission is requested by a click. Once access exists, the section reads the metadata of the cookies of every browser store by itself (name, domain, path, flags, expiry; no values in the list) and lists them by domain; without access nothing is read. Cookie values are read only on a separate command (show, edit, export), are shown only in the memory of the Options page and erased when you leave the tab, hide the page or revoke the permission. Export files (JSON, Netscape, AES-256-GCM encrypted JSON) contain values and are created only on your command. "Clear cookies of this site" and the restore test for a selected cookie change browser cookies when you press them.
- **Autosurfer** (Chrome only, required `debugger`). After Start, a tab in a new window walks through your address list (up to 200) and same-site links, scrolls the page and moves the pointer; Chrome shows its debugging banner. It does not click, type or solve CAPTCHAs. The sites of your list set and read their own cookies in your browser profile just as when you visit them yourself. When the run finishes, or on Stop or Clear, the extension closes the window it created (tabs you opened in it yourself stay); a site that cannot be reached is skipped and recorded as an interrupted visit.
- **Browser Debug.** Each data set requests its own optional permissions by a click; browser data (history, bookmarks, downloads, cookie metadata without values, tabs, sessions, top sites, reading list, extensions, privacy settings, site permissions, system information, account profile) is shown only in the memory of the Options page. Individual records can be changed on your command. Export follows a preview and strips query strings, fragments and userinfo from addresses.
- **Cloudflare (Precursor).** You type the token yourself: it lives in memory and in `storage.session` (trusted contexts) and never reaches `storage.local`, reports or exports. The zone ID and name, the last mode and the transition history (up to 128) are stored.
- **Proxy Manager Geolocation API.** Off by default. Once you turn it on and add a key, the Proxy manager shows country, city, organisation and flags (proxy, VPN, Tor, hosting) for the exit IP of your proxies. For that, the extension pages send the provider you chose (MaxMind GeoLite or GeoIP, ipgeolocation.io, ipdata or ip-api.com) a `GET` request with the public exit IP that a manual proxy check found and your key (MaxMind: account ID and licence key), without cookies, a referrer or redirects; private and reserved addresses are never sent. The provider also sees the address your request comes from (your IP or the exit IP of the active route) and may, over time, learn which proxies you check. Requests are made right after a manual check (can be switched off), on a button, and when you test a key; there is no timer and no request when the list opens. The free ip-api.com endpoint works over plain unencrypted HTTP only and is used only after your separate confirmation; with a key, HTTPS is used. If a provider fails, the same address can go to the next provider you enabled (can be switched off). By default keys stay in `storage.session` and vanish when the browser closes; with the "Remember keys on this computer" box ticked they are kept unencrypted in `storage.local`. The result cache (up to 200 records, 30 days) is kept in `storage.local` and cleared by a button. Keys never reach exports, reports, logs or synchronization. Provider data is approximate and is not an assessment of the safety of a proxy or a site.
- **Firewall module** (Chrome only). Off by default; you enable it with one explicit click (there is no separate confirmation dialog, ADR-098); an organization can only forbid it. `block`/`allow` rules and the `Sec-GPC: 1` header; matching your typed e-mail, phone and name with outgoing requests: the value is read in the page's isolated context after trusted input, only key fingerprints reach the service worker memory (15 minutes), and request bodies are scanned in memory (up to 64 KiB per request). Passwords, payment fields and one-time codes are not read; the value and anything derived from it is written nowhere.
- **Pro.** A recording you start (up to 10 minutes, up to 3 MiB); a copy you save with Save lies on disk in IndexedDB and may contain page titles, URL templates, outgoing Cookie values and the values of a fixed list of 38 technical request headers (for example User-Agent, Accept-Language and client hints; never Authorization or Set-Cookie).

### Export and deletion

Downloading JSON requires your action after a preview. The extension checks that the preview is current and downloads exactly that projection: technique summaries, interpretations and limitations, coverage, loss counters, relative intervals, observation age and scope mode. Host is excluded by default and requires a separate checkbox. Internal document IDs and absolute timestamps are excluded. The network destination list is not exported. The other features export only their own data and only on your command: Antidetect configuration and library (without private keys), Proxy profiles (without logins and keys), cookie files, Browser Debug, the Autosurfer report, Firewall data.

A separate Options diagnostic preview contains only schema/extension version, Chrome major version and service-worker availability. It is not saved in session storage. Sharing downloaded files is a separate action you take outside the extension.

Deletion: the UI clear action deletes the current report; continued observation can create data again. "Turn off and clear" deletes reports, the Pro recording, the Pro report archive, the site-icon cache and the Cloudflare connection; the global session clear deletes reports, the Pro recording, the Pro report archive and the Cloudflare connection, but not the site-icon cache (it is erased when observation is turned off, when permissions change and after 7 days). Features are removed by their own controls: Antidetect trash and profiles, Proxy profiles and check history, the Autosurfer list, the Firewall purge, the "Forget all keys" and "Clear cache" buttons of the Geolocation API. Uninstalling removes the extension's storage and granted permissions through Chrome. Downloaded files and clipboard contents remain under your control; the companion's vault stays on disk until you delete the profiles in Proxy or the file. Reload already open pages to remove injected wrappers.

### Data not collected and limitations

Observation sensors and the bridge do not record form contents, keystrokes, coordinates, clipboard, cookie values, tokens, Authorization, request/response bodies, pixels/data URLs, audio samples, measured text, exact hardware values, Math arguments/results, raw stacks, ICE candidates or IP addresses. Two clarifications apply within observation without a separate command: the transient parsing of request bodies sent to known beacon endpoints (only a structured projection is kept, see above) and the list of configured ICE servers (server addresses, not the client IP) in `storage.session`. The other narrow exceptions apply only to the features described above and only on your command: cookie values (Cookies, outgoing Cookie values in a Pro recording), the Cloudflare token, proxy logins in the companion, the proxy's exit IP in the check history and in the request to the geolocation provider you chose together with your key, matching of typed values in the Firewall module. The extension creates no profile or identifier that leaves the browser and does not sell data; random local keys (noise and WebRTC) never leave the browser. Organization upload and remote rule updates are absent.

Observation depends on available APIs and permissions; workers, WASM, CSS and server-side checks have coverage gaps. No findings means nothing was observed within the available scope during the observation period. Page observations have `page-controlled` integrity. Pages may detect wrappers, and wrappers may affect compatibility. The extension does not assess site safety. The extension does not encrypt browser-local storage; the companion protects its own profile file with Windows DPAPI.
