# Досье релиза

P10 · E03-01/E17-01 · ADR-002/016 · ТЗ I §5.2, V §10.

- `pnpm sbom` без сети создаёт `sbom.json`, `licenses.md` и корневой `NOTICE`. SBOM — минимальный CycloneDX-подобный формат, не заявление о соответствии полной схеме CycloneDX. Он содержит все registry packages lockfile и отдельные встроенные ресурсы; `resolved.integrity` — integrity из lockfile, для ресурсов — SHA-256 исходного файла. Это инвентаризация, не повторная криптографическая проверка содержимого установленного npm-пакета по tarball integrity.
- `pnpm release:verify` проверяет SHA-256 lockfile и точное соответствие всех трёх файлов генератору. Новая внешняя зависимость в esbuild inputs останавливает сборку до её включения в reviewed инвентарь. Preact входит в UI, остальные npm-пакеты — инструменты разработки. Workspace-код не считается сторонней зависимостью.
- Лицензии извлекаются из локальных `package.json`. Для неустановленных platform optional dev-пакетов — `NOASSERTION`, без угадывания; на другой платформе таблицу нужно пересоздать и проверить diff. Формат lockfile v9 и registry integrity поддерживаются явно; неизвестный формат/источник останавливает генератор. Новых зависимостей и загрузок нет.
- `NOTICE`, исходный снимок PSL и MPL-2.0 включены во все профили сборки и ZIP (`third-party/`). Preact MIT-текст взят из установленного `LICENSE`. Логотип и его PNG-производные перечислены отдельно; название и логотип остаются за автором.
- Материалы публикации: [STORE_LISTING.md](STORE_LISTING.md), [PRIVACY.md](../../PRIVACY.md). Для production 2.0.0 (Chrome Web Store, Privacy practices): [черновик ответов](CWS-PRIVACY-PRACTICES.md); `STORE_LISTING.md` относится к TS-базе 0.1.0 и для 2.0.0 устарел. Фактические результаты P10: отчёт. Процедуры: [release](../../runbooks/release.md), [rollback](../../runbooks/rollback.md).
