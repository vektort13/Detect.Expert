# ADR-007. Redaction и retention

Статус: **Accepted** (2026-09-12). Владелец: security/privacy (TBD); реализация — `packages/collector`, `packages/background`, `packages/export`.

## Контекст

Все страницы, на которых ведётся наблюдение, — чувствительный контекст (банки, медицина, внутренние сервисы). AUD-04: `argsSummary`, полные URL, заголовки. `storage.session` — память на время сессии, не защита от владельца ОС; хеш домена не анонимизирует. CWS 2026 требует необходимости обработки и раскрытия. Диагностический режим не должен стать лазейкой.

## Решение

1. **Точка redaction — до моста.** Сенсор передаёт только: тип операции, насыщаемый счётчик, enum `signalCodes`, `phase`, `intervalBucket`, sanitized origin hint. Bridge и SW не могут «раскрыть» больше, чем пришло. Список запрещённого — `docs/data-inventory.md` §7 (перенос ТЗ I §4.4).
2. **Сеть**: в callback `webRequest` разрешена кратковременная нормализация URL (удалить userinfo/query/fragment, host → ASCII lowercase, path → шаблон правила или отброс); сырой URL не покидает callback. Заголовки — только имена из allowlist правил; `requestBody`, cookie values, `Authorization`, тела ответов не читаются. Cookie-name sensor — отдельный optional, выключен по умолчанию.
3. **Stack**: `Error().stack` только по бюджету (≤8 samples/2 с/realm) и только для origin-подсказки; sample locations (очищенные) — в локальном диагностическом режиме, не в отчёте и не в экспорте по умолчанию.
4. **Retention**: отчёты, bindings, watermarks, диагностика — `storage.session` (TTL неактивного документа 10 мин, закрытие вкладки, перезапуск, 4 MiB LRU); предпочтения — `storage.local`; политики — `storage.managed`; `storage.sync` и диск для отчётов — никогда. Диагностический ring ≤1 MiB, TTL 24 ч, без hosts/paths. История на диске — только отдельным ADR с TTL, очисткой и индикацией.
5. **Экспорт**: только redacted-проекция, показанная в preview (docs/PROJECT_RULES.md REQ-013); preview перечисляет поля. Требование E14-01 #3: возможность исключить host, чувствительные локальные hostname — только по выбору, по умолчанию исключены/заменены категорией. **В срезе 1 это не реализовано (F064):** host включён с предупреждением, переключателя исключения и автоматического скрытия чувствительных hostname нет. Отдельный диагностический экспорт из options также отсутствует (E14-01 #8). «detailed» и передача организации — требования будущих действий, не возможности текущего Local. Смена документа между preview и сохранением → preview заново. Cases #3/#8 остаются открытыми, поддержка не запрашивает отсутствующий файл.
6. **Удаление**: `ui-clear` удаляет отчёт документа и его watermark; отзыв scope удаляет данные scope; disable/update расширения очищает session.
7. **Терминология**: не называть хранилище «зашифрованным», хеши доменов — «анонимизацией», session storage — защитой от компрометации профиля.
8. **Privacy inventory** (`docs/data-inventory.md`) — нормативный список; поле вне инвентаря не может появиться в схеме.

## Последствия

- Для некоторых сигнатур (query-параметры, path с ID) детекция невозможна по построению — принимается.
- Privacy policy перечисляет фактический `storage.local`: единственный ключ `scope` содержит `{ v: 1, scopeMode: off | active-tab | site | all-sites, hosts: string[] }` (`packages/background/src/scope.ts`, enum из `packages/contracts/src/enums.ts`). `scope.hosts` — нормализованные hosts выбранной пользователем области, не история посещений; это не origin patterns. `sitePatterns`, `pausedSites`, `disabledSensorIds`, `locale`, `onboardingAcknowledgedVersion` не сохраняются в срезе 1.
- Пауза — `DocumentMeta.paused` в snapshot документа (`storage.session`), адресуется `UiPauseRequest.documentKey`, а не host. Новый документ того же сайта не наследует паузу. Текущая строка `action_pause` ошибочно обещает сайт (F088); требуется review RU/EN строки о текущем документе и регрессия навигации на том же host.
- Тесты privacy — release blocker.

## Приёмка

Data inventory заполнен для каждого поля схем. `pnpm test:privacy`: канарейки (текст canvas, значение cookie, query, локальный IP, аргумент Math, полный path) отсутствуют в `storage.session/local`, UI-логах, экспорте, сообщениях моста; изолированный профиль — 0 исходящих запросов с initiator расширения; экспорт равен preview (schema validation); `ui-clear` удаляет данные; после закрытия вкладки/TTL отчёта нет; диагностический ring не содержит hosts.
