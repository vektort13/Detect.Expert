# ADR-059 — WebAssembly: полное перечисление JavaScript-интерфейса

2026-10-20. Прямое решение владельца продукта: расширить API для WebAssembly и покрыть все функции; владелец подтвердил оба направления — отчёты и управление. E22-10, DET-065, REQ-002/003/004/005/010/011/012/015. Развивает API Guard ADR-045/046 и переносимые настройки ADR-048/049. Реализация и приёмка выполнены; фактические результаты в отчёте ниже.

## Область

Общий детерминированный список `packages/contracts/src/webassembly-apis.mjs` определяет публичные namespace-функции, конструкторы, статические методы и prototype методы/accessors. Исходные десять operation names/indexes сохраняются, новые добавляются в конец общего wire-реестра. Всего 37 условных поверхностей: 36 найдены дескрипторами в Chrome 153/155 и Firefox 153 testbuild; Firefox 138 имеет 31, без трёх JSPI операций и двух Memory conversion methods. Документированный `Tag.type` отсутствует во всех четырёх проверенных версиях и остаётся conditional, без создания отсутствующего метода.

Источники: [WebAssembly JavaScript interface](https://webassembly.github.io/spec/js-api/), [Web API](https://webassembly.github.io/spec/web-api/), [JS Promise Integration](https://webassembly.github.io/js-promise-integration/js-api/), [MDN JavaScript interface](https://developer.mozilla.org/en-US/docs/WebAssembly/Reference/JavaScript_interface). Native descriptor evidence — `test-results/production-1.1.0/wasm-inventory/`.

Список не включает унаследованные общие Object/Function/Error методы, data-константу JSTag, символы/служебные поля, внутренние Wasm opcodes, engine JIT/GC/SIMD и произвольные импортированные/экспортированные функции модуля. Обёртка native exported function меняет её brand и несовместима с передачей в JSPI/Table/imports, поэтому такие функции не подменяются. Память и байты/секреты/stack не читаются. Наблюдение workers/worklets не добавляется; это прежняя граница page hooks.

## Наблюдение

Дополнительные операции дают только operation/phase/count. Не добавляются параметры/результаты Global.value, Table.get, Exception.getArg/stack, имена imports/exports/custom sections, module bytes или функции страницы. Существующие десять операций и прежний Pro allowlist не расширяются произвольными результатами.

Методы сохраняют оригинальные this/arguments, синхронный результат/исключение и идентичность Promise; оригинал вызывается ровно один раз, observer ошибки подавляются. Чужой Promise не получает then/catch. Accessors остаются неконструируемыми; getter/setter одного свойства устанавливаются совместно без изменения другой стороны. Статические методы устанавливаются до конструктора. Только точный собственный prototype.constructor, указывающий на исходный конструктор, связывается с обёрткой и восстанавливается по владению. Page replacements сохраняются. Маскировки toString/name/length нет.

Обычное JS-конструирование Exception с traceStack создаёт в Chrome/Firefox собственный getter stack. Наблюдатель и соответствующее правило Guard учитывают его отдельно от прототипа, только через дескриптор успешного native результата, без чтения stack. Native setter не меняется. Одна weak cleanup ring до 128 объектов ограничивает хранение; вытеснённые обёртки продолжают работать, после disable/stop пропускают native, полное снятие требует нового документа. Старые native ссылки, прежние объекты и исключения, созданные внутри Wasm без наблюдаемого JS-конструктора, сюда не входят.

Прежняя startup queue наблюдения до handshake ограничена 32 записями. Ранний burst всех операций может дать явный budget-exceeded/degraded; лимиты ради теста не увеличиваются. Полнота регистрации Guard document_start и доставка допустимых событий наблюдения в отчёт проверяются отдельно: по одному target на новом native документе. Это не обещание наблюдать любой размер раннего burst.

## API Guard и конфигурации

Прежний `webassembly` остаётся общим выключателем с прежней семантикой и ID. Его ON скрывает весь namespace; child OFF не возвращает скрытый родителем объект. 37 granular rules добавлены отдельно, по умолчанию BYPASS. Отсутствующие browser APIs не создаются. ON намеренно запрещает выбранный вызов/доступ через SecurityError, асинхронные namespace функции — rejected Promise; BYPASS/OFF сохраняют существующую систему наследования и разрешения. Custom для этих ресурсных/исполняемых API не добавляется.

Отдельные setter/getter блокируются независимо; восстановление одной стороны не снимает блокировку другой. Proxy сохраняет constructibility методов/конструкторов и subclass newTarget. Constructor alias учитывается только при точном владении. API Guard не отзывает заранее сохранённые ссылки или уже переданные Wasm ресурсы и не управляет кодом внутри других worker. Действуют прежние условия прав, включения и новых документов, без новой команды страницы/сети/permissions.

Каталог v2, формат JSON v1. Первые 105 ID/order/metadata остаются прежними; новые 37 следуют после них, всего 142. Канонические legacy feature IDs — прежние 89 и новые 37; пресеты не включают новые блокировки сами. V1 полностью валидируется по историческим 105 строкам до миграции, включая metadata, дубли и site scopes. Библиотеки Custom/selected/settings и состояние master/site сохраняются; новые строки BYPASS/unset. Startup миграция сохраняет конфигурацию атомарно с новым revision под прежней очередью. Отказ storage сохраняет старые данные и возвращает storage-error, не заменяет конфигурацию legacy fallback. Import сохраняет preview/Cancel и использует тот же валидатор миграции.

UI использует собственную сворачиваемую группу WebAssembly, общий родитель и технические имена API, существующие режимы и поиск/фильтры. Порядок отображения не меняет канонический порядок экспорта. Локализованы элементы управления группой, технические имена едины.

## Приёмка

Независимое review схем/миграции, наблюдения, denial и UI выполнено. Semantic unit покрывает native methods/accessors/constructors, coercion/throw/Promise/get-set/cleanup/ownership. Native Chrome153 и Firefox138 проверили все доступные granular rules и реальную доставку отчётов, сохранение старого JSON/Custom. Observer отдельно проверен Chrome153/155; UI/импорт/экспорт проверены native Chrome. Typecheck/lint/unit3370 и release:verify с privacy7 PASS, оба пакета обновлены. Точные результаты и пределы измерений — отчёт.
