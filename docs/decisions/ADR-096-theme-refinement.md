# ADR-096 — Отдельная Pearl и компактное внешнее меню

Уточнение оформления от 2026-11-01: [ADR-099](ADR-099-vivid-interface-palettes.md) усиливает насыщенность всех палитр и свечение, сохраняя самостоятельные System/Pearl, прежние IDs/controller и отсутствие кнопки темы во внешнем popup. Исторические цвета ниже заменены текущим CSS; поведение не меняется.

31.10.2026. Прямое решение владельца продукта уточняет ADR-089: во внешнем popup больше нет кнопки выбора темы. Выбор остаётся во внутреннем меню и существующей боковой панели. Popup отдельно инициализирует прежний shared controller, сохраняя first paint, storage.onChanged и реакцию на системную цветовую схему без отображения picker.

System остаётся автоматической темой со своими светлой и тёмной палитрами. Внутренние effective ID — system-light/system-dark. Pearl — самостоятельная постоянно светлая палитра слоновой кости с мягкими акцентами шампань. Она не копирует System при светлой ОС. Bootstrap и controller одинаково выбирают effective ID; в storage по-прежнему записывается только один из шести прежних preference ID, ключ и wire-контракты не меняются.

Обновляются локальные CSS-токены и соответствующие миниатюры picker. Геометрия, шрифты, брендовый синий знак, SVG paths и исходный logo.svg сохраняются. Forced-colors, reduced-motion, все существующие контроллеры, разрешения, CSP, сенсоры, fingerprint и Protect не меняются. Никаких зависимостей или внешних ресурсов не добавляется.

Проверки и поставляемые файлы: внутренний отчёт.
