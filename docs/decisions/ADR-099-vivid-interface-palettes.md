# ADR-099 — выразительные палитры и светящиеся контуры

Дата: 2026-11-01. Прямое решение владельца продукта: переработать бледные цветовые схемы, добавить насыщенность, свечение и гладкие линии. Уточняет оформление ADR-089/094/096 без изменения логики тем.

Сохраняются шесть preference IDs и прежний storage/controller/bootstrap. System имеет отдельные light/dark палитры. Pearl сочетает слоновую кость, янтарь и медь; Aurora — тёмный синий, циан и фиолетовый; Graphite — глубокий графит, изумруд и бирюзу; Orchid — светлые розово-лиловые поверхности с насыщенной фуксией; Glass — тёмную фиолетовую основу, розовый и синие отражения. System остаётся самостоятельной сине-кобальтовой схемой.

CSS централизует более заметные границы, многоуровневые тени и свечение активных элементов. Эффекты рисуются поверх прежней геометрии и не меняют размеры, позиции, отступы, шрифты или hit areas. Нет новых непрерывных анимаций. Обычные переходы color/border/shadow остаются короткими; reduced-motion выключает их даже во время установленного theme-transition flag. Forced-colors сохраняет системные цвета, отдельный keyboard focus, GrayText и отсутствие свечения.

Положительные/отрицательные состояния сохраняют зелёную/красную семантику. Выбранные режимы, hover и disabled имеют явные scoped rules, без включения функций через оформление. Категории и системы сохраняют собственные hue; adaptive stroke/light-dark следует фактически выбранной теме, а не только цветовой схеме ОС. Disabled остаётся disabled, но подписи не исчезают в чрезмерной прозрачности.

Фирменные SVG paths, исходный синий #2463c9, размеры и прежний brand CSS блок неизменны. Прозрачные mark/identity containers сохраняются; окружающая шапка popup/sidepanel использует собственную глубокую header surface для контраста с ярким фоном страницы. Белая плашка, фильтры и перекрашивание логотипа не добавляются. У ручек переключателей используется контрастный semantic ink соответствующего состояния; forced-colors использует ButtonText.

Настройка темы остаётся во внутреннем меню и существующей боковой панели. Во внешний popup кнопка темы не возвращается, но синхронизация и восстановление выбора работают по прежнему controller. JS, wire, permissions/CSP, backend, сенсоры, fingerprint, Protect и внешние соединения не меняются; новых зависимостей/ассетов нет.

Независимая проверка цветов, sampled/composited contrast, native проверки тем/синхронизации/семи масштабов, logo invariants и точные hashes приведены в отчёте.
