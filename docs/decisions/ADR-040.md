# ADR-040 — один полный пакет Chrome и один пакет Firefox

DBSC-часть решения отменена [ADR-044](ADR-044.md) от 2026-10-10.

2026-10-10. Прямое решение владельца продукта: убрать разделение Chrome на обычную
и DBSC-сборки; выпускать один пакет для каждого браузера.
REQ-004/010/012/015; изменение поставки ADR-027.

Единственная Chrome-сборка включает существующий DBSC inspector. Source
manifest и `productionManifest('chrome')` объявляют обязательный `debugger`
и minimum Chrome 153 — ту же границу, что прошедший проверку DBSC transport.
Сборка напрямую из `apps/production-extension` имеет те же возможности.
Никаких изменений wire contracts, CSP, host permissions или новых зависимостей.

DBSC запускается явной кнопкой Cookie panel после consent, cookies permission
и проверки текущего документа. Наличие permission само по себе не подключает
debugger. Stop/navigation/pause/revoke и unknown TPM поведение ADR-027 остаются.

Firefox использует всю общую кодовую базу с прежним browser adapter, native
background и sidebar. `debugger` и `sidePanel` исключаются из его manifest,
minimum Chrome удаляется. Firefox не предоставляет Chrome CDP DBSC transport;
его отсутствие остаётся browser capability status, а не отдельной редакцией.

Поддержаны только targets `chrome`, `firefox`, `all`. Команда
`build:chrome:dbsc` удалена; старый target отклоняется до изменения output.
`--browser all --release` выпускает ровно два архива. Устаревшие generated
`dist/chrome-dbsc` и текущие versioned release DBSC artifacts переносятся
в служебную `.tmp` после проверки конечных абсолютных путей внутри проекта.
В `dist`/`release` отдельного варианта больше нет. Исторические документы
review сохраняют сведения о фактически проверявшихся прежних пакетах.

Проверки: manifest positive/negative cases, Firefox isolation, rejection
старого target, существующие DBSC semantic/privacy/race suites и native
`scripts/test-dbsc-diagnostic.mjs`, который теперь загружает `dist/chrome`.
Независимый reviewer проверяет permission delta, отсутствие auto-attach и
native/browser boundaries. Результаты и hashes фиксируются в release evidence.
