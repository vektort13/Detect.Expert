# ADR-065 — детерминированная подмена трансцендентных Math

> Уточнено [ADR-106](ADR-106-antidetect-continuation.md): время жизни приватного ключа — профиль (локальный корень в `storage.local`, HMAC от применённых Custom-строк); упоминания `storage.session` ниже описывают версию до ADR-106.

Статус: реализация по прямому решению владельца продукта 2026-10-21, задача E22-18. Продолжает ADR-048/049/064. Семантика каждой функции, первичные источники и проверяемые случаи: [Math coverage](../coverage/math-transcendentals.md).

## Область разрешённого изменения

В Antidetect → Browser / All добавляется отдельный управляемый профиль `math-transcendentals`. Поддержаны 20 функций: acos, acosh, asin, asinh, atan, atanh, atan2, cos, cosh, exp, expm1, log, log1p, log2, log10, sin, sinh, tan, tanh, pow. Пользователь выбирает функции отдельно; общий master не включается автоматически. Allow и Bypass сохраняют профиль, не применяя его. Пустой набор допустим, не ставит hooks и не показывается активной подменой. ON для новой строки запрещён: весь Math namespace не отключается.

Разрешено узкое исключение из REQ-001/002: при включённом общем master и Custom выбранные успешные числовые результаты могут детерминированно сдвигаться максимум на один соседний binary64 ULP. Это farbling, а не fdlibm-нормализация движков. Нативная функция вызывается ровно один раз с теми же this/arguments. Преобразование типов, ошибки и их identity выполняются браузером; обёртка не повторяет ToNumber/valueOf. Подмена применяется только к аргументам типа primitive Number; аргументы других типов сохраняют нативный результат. Это явно обозначенная граница, а не обещание неподдающейся обходу защиты.

REQ-003 не изменён: Function.prototype.toString не патчится, нативная строка не подделывается. Proxy сохраняет исходную неконструируемость и metadata как compatibility-мера. Обнаружимость, отсутствие атомарной установки между расширениями и непокрытые поверхности не скрываются. Новых permissions, CSP, host grants, зависимостей, сети или page command channel нет. Наблюдающие Math sensors и запрет передачи аргументов/результатов не меняются.

## Арифметические гарантии

NaN, ±0, ±Infinity, субнормальные и точные/консервативно сохранённые результаты возвращаются без изменения. Не допускаются переход в ноль, subnormal, Infinity/NaN, изменение знака или выход из диапазона функции. Сохраняются integer results, известные константы и специальные atan2 направления. Числа, на которых native уже округлил малую функцию до аргумента, остаются прежними. Направление сдвига ключуется по функции и модулю исходного результата, поэтому сохраняется нечётность там, где она была у исходного движка. Межфункциональные тождества и монотонность соседних входов этим не гарантируются.

Для pow отдельно сохраняются основания — двоичные степени, неотрицательные целые показатели и дробные показатели с reduced dyadic denominator ≤1024. Отрицательные целые степени основания с нечётной мантиссой >1 могут сдвигаться: их точный математический результат не является dyadic. Для остальных дробных показателей доказательство отсутствия точного binary64 результата приведено в матрице. Это позволяет изменять fingerprint probe Math.pow(Math.PI,-100), сохраняя точные корни вроде Math.pow(81/256,0.25). Оператор **, sqrt, cbrt, hypot, округления, Math.random и константы не меняются.

## Ключ и ранняя установка

256-битный секрет создаётся CSPRNG и хранится только в private storage.session. Он не входит в JSON, настройки API, наблюдения, отчёты или MAIN↔ISOLATED сообщения. Повторный SW использует существующий seed; ошибка storage не подменяется локальным или общим ключом. Секрет передаётся только в private validated native userScript source. Два domain-separated SipHash-2-4 с разными половинами session key выводят 128-битный ключ origin; второй SipHash по function ID и binary64 bits определяет направление сдвига. Внутри страницы нет Math.random, счётчика вызовов, часов или растущего кэша аргументов.

Область разделения — настоящий origin, включая scheme/port; это не eTLD+1 верхней страницы. Same-origin окна и доступные наследуемые фреймы получают одинаковый профиль, другой origin — другой ключ. Workers/Worklets, CSS, WebAssembly, ** и недоступные realm не переписываются. Пример из исследования с упрощённым «две последние метки» и маскировкой toString не используется.

Установка встроена в прежний immutable document-start bootstrap с синхронным наследованием доступным realm. Новый профиль не доставляется асинхронным сообщением сайта, публичного stop/restore нет. В недоступных inherited opaque realm отсутствует синхронный доступ к доверенному session key: отдельный статический fallback запрещает вызов двадцати методов группы с SecurityError, оставляя остальные методы Math. Сам публичный document marker не является аутентификацией; first-inline/динамические/fallback случаи проверяются отдельно.

UserScripts с вшитым ключом могут сохраниться после закрытия браузера, а новая storage.session и startup reconciliation асинхронны. Восстановленный документ может начать с прежним shifted-профилем до обновления регистраций; исходный нативный результат от этого не становится доступным. Переключать ключ внутри работающего документа нельзя: его профиль остаётся неизменным до навигации. При изменении зарегистрированного Math source выставляется reloadRequired. Атомарная ротация до первого restored документа не обещается.

## Формат и проверка

FormatVersion 3 / CatalogVersion 5 добавляет одну строку в конец: 143 API, из них 39 Custom. Исторический каталог 4 из 142 API заморожен с SHA-256 `8078b7f3f2eade1aba87a950fc1f8fa79ed75091267f798a90dcbbd9f2cc2f43`. Миграция сохраняет все режимы, библиотеки, selections, сайты и policy; новая строка Bypass. Профиль — только `{algorithm:'deterministic-ulp-v1',functions:[known names]}`; неизвестные алгоритмы/имена, дубли и код отвергаются. Порядок функций канонический; секрета в переносимом файле нет. Сохраняет прежний CAS-писатель и exact Options sender, второй store не создаётся.

Нужны independent semantic review всех двадцати методов, literal ECMA cases, независимый BigInt ULP oracle, SipHash official vectors и дополнительный independent oracle, coercion/throw/order/poisoned intrinsics, native Chrome/Firefox first inline и frames, mode transitions, session seed/SW restart, 21 locale, dark/RTL/forced colors, performance и source/dist/ZIP proof. Результаты фиксируются в E22-18, не предполагаются этой записью.
