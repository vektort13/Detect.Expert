# ADR-019. База публичных антифрод-интеграций и отдельные сводки Shodan

Статус: **Accepted**. Дата: 2026-10-09. Основание: прямое решение пользователя исследовать 100+ антифрод-систем; владельцы `packages/catalog` / offline research tooling. Трассировка: E12-01, ADR-009, REQ-001/005/008/010/011.

## Решение

1. Сохранить исследовательскую базу отдельно от production-правил: `packages/catalog/data/antifraud.v1.json`, CSV и исходные записи A–D. Источники — официальные страницы поставщиков и официальные интеграционные руководства. Продукты не ранжируются по распространённости; разные SKU и семейства явно различаются.
2. Разделять документированные точные ресурсы, шаблоны, provider-family/shared SDK, page-controlled имена, build-time SDK metadata и продукты без подтверждённого браузерного признака. Не сохранять значения параметров, cookie, заголовков, форм, ICE-кандидаты или IP. Не превращать описанную WebRTC-возможность в сигнатуру конкретного endpoint.
3. Генератор воспроизводит JSON, CSV, индекс доменов и статистику. Validator проверяет candidate gate, источник каждого сигнала, допустимые host/path/templates, протокол, kind-specific поля, связанные артефакты и производные индексы. Все новые записи выключены; включение — через gate ADR-009 и отдельный релиз расширения.
4. По прямому решению пользователя разрешён отдельный Node CLI для Shodan. Он выполняет только GET `/shodan/host/count` к `api.shodan.io` по ранее опубликованным точным доменам. Условие запроса фиксировано в коде; произвольный query, scan, host-search, DNS/сертификатные pivots, серверные IP/port/banner/CVE списки не реализованы. Расширение CLI не вызывает и не импортирует его данные.
5. Ключ читается только из явно указанного файла внутри проекта или специально названной переменной процесса. Проверяются resolved path и realpath, включая junction. Ключ, сырой URL API и error body не выводятся и не сохраняются. Redirect запрещён, запрос/чтение ограничены 10 секунд и 64 KiB, между началами запросов не менее секунды, не более 100 опубликованных доменов за запуск; 401/403 останавливают последовательность. Offline plan не читает ключ и не делает запросов.

## Границы

Manifest, permissions, CSP, wire-схемы, текущие production-правила и hot path не меняются. Расширение сохраняет отсутствие исходящего служебного трафика по умолчанию. Исследовательский CLI является отдельным вручную запускаемым инструментом и не включается в архивы Chrome/Firefox. Shodan-сводка не подтверждает применение антифрода на сайте; нулевой count не доказывает отсутствие системы или сервера.

Данные существуют на дату исследования. Protocol-relative и неизвестные схемы сохраняются отдельно. Исторические ресурсы имеют lifecycle `legacy`; новые источники требуют пересборки/проверки базы. Ни одного нового WebRTC-признака или passing production fixture не заявлено.

## Проверка

`pnpm catalog:lint`, `pnpm catalog:test`, `pnpm typecheck`, `pnpm lint`, `pnpm test:unit`, `pnpm release:verify`. Независимые source/semantic reviews: внутренний отчёт и `2026-10-09-antifraud-peer-review.md`. Реальные API результаты проверяются отдельно от mocked network tests и offline plan.
