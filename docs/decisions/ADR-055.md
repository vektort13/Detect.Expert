# ADR-055 — единое окно управления расширением

Дата: 2026-10-20. Прямое решение владельца продукта: объединить основные разделы общей современной навигацией, добавить последнюю вкладку «Контакты».

Канонический документ — существующий `options.html`. Общий header и вкладки Firewall → Защита (API) → Настройки → Контакты переключают панели через hash в том же документе. Активная вкладка выделяется; предусмотрены клавиатура, RTL, узкий экран, тёмная тема и reduced motion. Общая навигация локализована на 21 языке. Контактные данные и биография не выдумываются: раздел подготовлен для последующего наполнения владельцем.

Повторно используются существующие компоненты настроек и отдельные согласия. Посещённые панели остаются смонтированными и скрываются при переключении, поэтому основной API draft, поиск и Undo не сбрасываются. Открытые диалоги при внешней смене hash закрываются через существующую отмену. `?tabId=` сохраняет контекст исходной тестируемой вкладки; активное окно управления не становится её заменой. Старые ссылки `#protect`, `#firewall`, `#history`, `#requests` открывают соответствующий подраздел Firewall. Старый `protection.html?tabId=…` переводится в `options.html?tabId=…#api` до монтирования привилегированных панелей.

Большая кнопка Firewall теперь открывает его настройки согласно последнему решению. Компактный ON/OFF сохраняет существующее переключение с прежним согласием. Открытие или смена раздела само по себе не включает модуль, не меняет пользовательские значения и не очищает данные.

Внешние точки входа используют общий локальный helper для открытия или активации существующей собственной management-вкладки. Идентификатор, URL и актуальная принадлежность проверяются до навигации; посторонние вкладки не переиспользуются. `firewall.html` остаётся отдельным окном настоящего решения по обнаружению, а не страницей общих настроек. Временное подтверждение включения также остаётся отдельным окном.

Точный Options-only pathname привилегированных команд Firewall не меняется. Новых permissions, CSP, wire-схем, удалённых ресурсов и зависимостей нет. Vendor 722fae8 сохраняется побайтово; production-адаптер messaging меняет только навигацию к настройкам. Firefox получает общий интерфейс с действующими API/настройками/контактами и явным состоянием недоступного Firewall, без поставки модуля.

Проверки: независимый review навигации и границ доверия, unit/typecheck/lint, реальное переключение вкладок и сохранение draft, deep links/история/клавиатура/локали/геометрия, повторное использование вкладки, production privacy gate и сборки обоих браузеров. Фактические результаты фиксируются в отчёте задачи; этот ADR не объявляет проверки пройденными до выполнения.
