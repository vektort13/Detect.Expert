# ADR-079 — состав метаданных каталога

Дата: 2026-10-30. Решение владельца продукта. Дополняет ADR-078; REQ-005/008/010/015.

В поставляемой базе нет названий, идентификаторов и ссылок источника данных.
Справочник сохраняет дату, нейтральный идентификатор набора, все системы,
hostname associations, страны, темы и рейтинговые buckets.

Публичные URL источника и отдельной системы необязательны. Если URL передан,
действуют прежние проверки HTTPS, credentials, query/fragment и bounds.
Без URL интерфейс отображает текст вместо ссылки. Фиктивные адреса,
скрытые ссылки, переприсвоение авторства и runtime network не добавляются.

Каталог собирается offline из нормализованных входов существующей сборкой
(`node scripts/build-autosurf-sites.mjs`).

Сторонние лицензии CrUX/MIT остаются. Независимые доменные записи Cookies/PSL
не относятся к каталогу сайтов; они сохраняются байтово, поскольку влияют на
классификацию и обработку публичных суффиксов.

Приёмка: равенство всех 8329 site records/279 систем/13342 associations,
отсутствие сведений об источнике в программных файлах и метаданных каталога,
unit/preflight/build, Chrome/Firefox, сохранение Add, неизменность canonical
Cookies/PSL и лицензий.
