# ADR-018 — общая production-база Chrome/Firefox

Дата: 2026-10-09. Трассировка: REQ-002, REQ-004, REQ-006, REQ-009, REQ-010, ADR-002, ADR-003, ADR-004, ADR-017.

Production-исходник — восстановленная поставленная сборка `apps/production-extension`, см. ADR-017. `scripts/build-production.mjs` копирует эту общую базу в `dist/chrome` и `dist/firefox`. Старый TypeScript toolchain остаётся отдельным legacy-контуром; он не заменяет production 1.0.0 неполной сборкой.

Chrome сохраняет MV3 service worker, sidePanel, прежние разрешения/host permissions/CSP. Firefox использует MV3 event page (`background.scripts`), `sidebar_action` и Promise API `browser`. Разрешение sidePanel удалено только из Firefox-манифеста. Разрешения не расширены. Gecko ID — `detect.expert@detect.expert`, API floor 128.0 (MAIN/ISOLATED и matchOriginAsFallback). Gecko data_collection_permissions — `none`: новый порт не передаёт пользовательские данные внешним получателям.

Firefox на этом ПК — 138.0.4. Нативный `documentId` в runtime.MessageSender, scripting.InjectionTarget, tabs.sendMessage, webNavigation и webRequest появился в Firefox 153 согласно [Mozilla compatibility data](https://github.com/mdn/browser-compat-data/blob/main/webextensions/api/runtime.json). Подмена его простым frameId или ID из MAIN-пакета не допускается.

`browser-adapter.js` создаёт криптографический 32-hex ID в приватном ISOLATED global. Он не находится в DOM или MAIN. Bridge оборачивает собственные runtime-сообщения этим ID вне канонического MAIN-пакета. Background принимает такой envelope только от собственного расширения с browser-issued MessageSender tab/frame. Перед допуском он сверяет stamp с ID живого ISOLATED контекста через scripting.executeScript. Старое сообщение после навигации отклоняется; недоступный документ закрывается отказом. getAllFrames и навигационные события получают тот же приватный ID. Очереди ограничены; регистрация и отзывы scope остаются в прежнем runtime.

Служебные ответы документу получают recipient-stamp; bridge проверяет его до передачи исходной команде. Навигация между проверкой фрейма и tabs.sendMessage не доставляет команду новому документу. UI origin вычисляется из browser-issued runtime.getURL, поскольку Gecko runtime.id и UUID в moz-extension URL различаются. Проверка собственного ID и origin сохранена.

Точная поздняя file-инъекция в documentId на Firefox <153 недоступна: попытка завершится no-access. Регистрация MAIN/ISOLATED на document_start для выбранного сайта/всех сайтов работает. Frame-target fallback для поздней инъекции не выполняется. Адаптер пока использует этот консервативный контракт также на новых Firefox; переход на нативные documentIds потребует отдельной проверки.

У Firefox 138 нет подтверждённого source-document ID webRequest. Resource log Pro сохраняется, но обычная per-document network attribution не заявляется. Проекция отчёта получает существующий `network-limited`, а coverageState — `partial`, в том числе при all-sites. Новые wire enum/поля не добавлены. Lifecycle/prerender метаданные Chrome не выдумываются: Firefox live identity применяется к текущему активному фрейму; полноценный отдельный prerender-аудит не проведён.

Время генерации ID, getFrame и scripting.executeScript — IPC адаптация транспорта, а не hot path каждого наблюдаемого API. MAIN wrappers используют общий исходник без адаптера. Logical timeout IPC — 1500 ms; physical identity jobs ограничены 256 и удерживают слот до фактического завершения native Promise даже после timeout. Асинхронные исключения navigation observer изолируются. Количественное измерение Firefox overhead не проводилось.

Проверки: `node --test scripts/test/firefox-adapter.test.mjs` — 11 passed; `node scripts/test-firefox.mjs` — 11 native assertions passed на Firefox 138.0.4/geckodriver 0.37.1. Native Pro проверяет разные значения, повторные количества, технический аргумент Memory.grow и DOM общего отчёта. PDF проверяется в отдельном Chrome-контуре. Полная версия evidence: `.tmp/firefox/runs/1791495591537/evidence.json`; компактный результат — результат прогона Firefox. Peer review проверил sender boundary, recipient race, запрет позднего frame fallback, манифест и API semantics. Замечания про secure-context randomUUID, async observer exception и network coverage исправлены; root review добавил physical capacity и navigation observer rejection fixtures.
