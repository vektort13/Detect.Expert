# ADR-008. Source attribution и PSL/private suffixes

Статус: **Accepted** (2026-09-13, P01). Владелец: `packages/attribution`; реализация E11-01. Ограничения browser-приёмки перечислены ниже.

## Контекст

AUD-11: в `domains` находились значения с путями; AUD-13: присутствие стороннего скрипта связывалось с API «по соседству». `Error().stack` неполон и page-controlled (inline/eval/async/bundler/sourceURL). Same-site не доказывает общего владельца; один CDN не доказывает вендора; first-party может обслуживать вендорский коллектор через CNAME/proxy. Внешний DNS lookup создаёт исходящий канал с историей посещений.

## Решение

1. Раздельные поля: `documentOrigin`, `scriptOriginHint`, `requestDestination`, `initiatorOrigin`, `registrableDomain`, `vendorCandidate`. Host, path, scheme — отдельные типизированные признаки; hostname сравнивается по границам DNS-меток (`evil-online-metrix.net`, `online-metrix.net.evil.example`, `online-metrix.net@evil.example` → отрицательно).
2. Встроенная версионируемая Public Suffix List с private suffixes (snapshot с датой в `packages/attribution/data`); IDN → ASCII (punycode) до сравнения; site relation: `same-origin | same-site | cross-site | opaque | unknown`.
3. `attributionConfidence`: `exact-resource` только при browser-observed initiator + URL; `sampled-stack` — подсказка из ограниченной выборки, помечается как page-controlled; `frame-only`; `unknown` — не подставлять origin основной страницы.
4. Граф наблюдений (ТЗ I §4.2): рёбра имеют `relationType`, evidence IDs и confidence; совпадение времени не создаёт `executed-by`; связь «canvas → домен» запрещена без независимого основания.
5. IP parser: IPv4/IPv6/loopback/link-local/private/ULA/IPv4-mapped через канонизацию; `localhost`/`.local` — категория имени; иное — `unresolved`.
6. Внешний DNS lookup — никогда; enterprise alias (подтверждённый CNAME/first-party) — данные конфигурации с owner/source/expiry, не измеренный факт.

## Последствия

- Много `unknown` в отчётах — ожидаемо и честно.
- PSL snapshot требует обновления по расписанию (release maintenance).

## Приёмка

Unknown сохраняется для inline/eval/blob/анонимных стеков; CDN/IDN collision tests (похожий hostname, punycode homoglyph, shared CDN) отрицательны; внешний script в top frame и в nested frame атрибутируются по доступным evidence раздельно; тест «время соседства не создаёт причинность».

## Реализация P01 (2026-09-13)

REQ-005, A3/A9, F038/F181. Снимок PSL от 2026-09-12: SHA-256 `4b673689999dbaca60b93fa3e1da5752505ef9717b1c4dc44acbfdafd35679ea`, 10 325 правил ICANN + PRIVATE. Исходник `packages/attribution/data/public_suffix_list.dat`, MPL-2.0 и SOURCE.md сохранены; сеть не используется.

Индекс `src/psl-index.json`: ASCII-правила, сортировка по перевёрнутым символам и front coding (`длина общего префикса:остаток`), блоки по 128 правил; 100 162 байта. Runtime разворачивает Set один раз. `scripts/gen-psl.mjs` проверяет хэш и лимит 150 000 байт; каждая сборка вызывает `--check`. Обновление: вручную положить reviewed snapshot, обновить дату/хэш SOURCE.md и генератора, запустить `node scripts/gen-psl.mjs`, unit/privacy/browser/build/release проверки и review PR. Расширение обновлений PSL не загружает.

`toAsciiHost` использует URL для IDN/IP и удаляет userinfo/port/path/query/fragment. Wildcard/exception/PRIVATE учитываются; неизвестный suffix не получает неявного wildcard. `redactHost` возвращает registrable domain либо категорию IP/local/unknown. IP value — только класс loopback/link-local/private/ULA/public; public означает остаточный класс, не доказанную глобальную маршрутизируемость: unspecified/reserved/multicast отдельно не различаются.

DocumentReport.host и FrameBinding.host содержат только registrable domain или null. hosts[] (≤128) содержит ровно одно из registrableDomain/category, browser provenance, relation, requestCount, firstSeenBucket/lastSeenBucket (секунды от создания документа), ruleIds (сейчас пуст). Группировка по представлению и relation. Миграция отбрасывает старые raw-host записи; storage реконструирует allowlist. Домен регистрации также может идентифицировать сайт: это минимизация, не анонимизация.

Точный hostname проверяется до редактирования. Доступ далее связан с documentKey и поколением scope; во время обновления разрешений admission закрыт. После обновления выполняется сверка по свежим getAllFrames; ошибка browser query не сохраняет прежний доступ. ActiveTab session содержит только tabId/documentId. Пользовательские scope.hosts остаются точной настройкой области (§4 data-inventory); PSL-домен не используется для расширения разрешения на соседние поддомены.

Наблюдатель требует отдельные host permissions на target и browser initiator и документ текущего scope. IP/unknown не проходят в поле домена, сохраняется только категория. Same-origin вычисляется до redaction по scheme/host/port; same-site — schemeful PSL, с равенством локальных имён/IP без учёта порта. Непроверенный/opaque инициатор не получает доступ.

API-счётчики не содержат источник скрипта: их attributionConfidence = unknown, включая inline/eval/blob. Engine разрешает exact-resource лишь для HTTP(S) script URL с browser-network/browser-observed provenance; frame-only — для известной frame-привязки без неопределённого script kind. Соседний network script не атрибутирует API. Полные script URL не сохраняются; текущие page-hook строки не получают exact-resource.

Browser canary реально загружает random-label.example.com:4174 через локальный resolver и literal 127.0.0.1:4174. Существующий grant разрешает только literal: проверены loopback-категория, unknown inline и отсутствие обоих сырых значений в session/export; random target отклоняется. Разрешённый PSL target + initiator подтверждён unit, не browser. Полная F181 приёмка требует отдельного review тестового grant: P01 не меняет manifest, CSP и permissions.
