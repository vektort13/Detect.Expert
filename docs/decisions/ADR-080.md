# ADR-080 — общие локальные иконки систем

Дата: 2026-10-30. Прямое решение владельца продукта: добавить иконки к именам систем,
с возможностью использовать те же изображения в главном popup. REQ-008/010/015;
дополняет ADR-034/035/078/079.

## Решение

Отдельный справочник `system-branding-data.js` задаёт точные system id/name,
локальный путь, `brand | generic`, необязательный brandId и явные aliases.
`systemBrand` принимает только bounded string, без coercion/fuzzy matching.
Иконка декоративна и не влияет на детекторы, confidence, отчёты или системные связи.
Названия продуктов с общей корпоративной маркой остаются отдельными identity.
Глобальный company-branding и его прежние aliases не меняются.

`SystemMark`/`SystemLabel` используются в подборе сайтов и блоке каталога Inspector;
их API пригоден для последующего отображения распознанных систем в popup.
Размер 20/28 px, имя доступно отдельно, декоративный img имеет пустой alt.
Unknown identity получает векторную пиктограмму без букв. Иконки родителя не
наследуются по совпадению строк; проверенные отрицательные случаи — TransUnion /
iovation и AdShield / Ad-Shield.

Настоящие марки собраны до сборки с официальных сайтов, plugin registry и
существующего проверенного company registry. Для переименований требуется
первичный relationship source. Неактуальные/припаркованные домены, общие иконки
платформ и автоматически сгенерированные plugin placeholders отвергнуты.
Без проверенного изображения используется нейтральная собственная пиктограмма.

Новые assets нормализованы в PNG 96×96. SVG перед обработкой проверяются как
статическая графика: запрещены scripts, обработчики, внешние href/CSS, entity,
fonts и активные элементы; допускаются внутренние fragment refs и raster data
только PNG/JPEG/GIF/WebP. Чужие namespaces/metadata не участвуют в рендеринге.
Обработка выполняется в собственном loopback-документе, все внешние запросы
отклоняются. PNG output не содержит исполняемого SVG или исходных metadata.
Геометрия/цвета сохранены, прозрачные поля обрезаны, белые marks получают
нейтральную тёмную подложку. Старые assets остаются байтово неизменными.

## Границы

Нет runtime fetch, favicon proxies, внешних изображений, новых зависимостей,
permissions/CSP, сенсорных правил или чтения страницы. Print gate ожидает также
`img[data-system-logo]`. Сборка проверяет exact coverage всех 279 систем,
неоднозначные aliases, локальность путей, SHA-256/размер каждого изображения,
PNG dimensions и бюджет уникальных файлов 8 MiB. Metadata источников не
попадает в identity resolver; метаданные каталога по ADR-079 сохраняются.

Проверки: focused identity/decoy/neutral-print cases, offline builder --check,
unit/typecheck/lint, нативное декодирование всех иконок Chrome/Firefox,
светлая/тёмная тема, RTL, отсутствие egress и сохранение Add/Save.
