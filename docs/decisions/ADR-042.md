# ADR-042 — переключатель расширения и обновление оформления

Дата: 2026-10-10. Прямое решение: аккуратный тумблер под логотипом и современное оформление в духе iOS 27 вместо объёмных кнопок.

Тумблер в popup/sidepanel использует существующий trusted UI route `ui-set-scope`. OFF запоминает предыдущий режим в локальном `scope:resume-mode-v1` и выбирает off; ON восстанавливает all-sites, site или active-tab. Список сайтов хранит прежний контроллер. Это не команда очистки: остановленный Pro-отчёт остаётся доступен. Старое сохранённое отключение всего сбора можно включить через существующий `ui-data-consent-set`; отдельная «Выключить и очистить» остаётся в настройках. Permissions, CSP, wire-schema и sender checks не меняются. Значение UI берётся из background, ошибки не изображаются успехом.

Общий `button-surfaces.css` заменён: полупрозрачная навигация, лёгкие градиенты, тонкие края, скруглённые сегменты и карточки, мягкие тени без выпуклой нижней грани. Оформление применяется к popup, sidepanel, options, API blocking и экранному предпросмотру отчёта. Print-правила, таблицы и 12pt summary не затрагиваются. Предусмотрены dark mode, keyboard focus, reduced motion/transparency и forced colors. Новые подписи включены во все 21 UI-локализацию.

Источники дизайна: [Apple iOS 27](https://www.apple.com/sg/os/ios/), [Apple HIG Materials](https://developer.apple.com/design/human-interface-guidelines/materials), [iOS 27 User Guide](https://support.apple.com/en-euro/guide/iphone/iphfed2c4091/27/ios/27). Внешние ссылки используются для разработки; расширение не загружает стили или ресурсы Apple.

Проверки: helper unit tests, native default/start/stop/resume и сохранение Pro, реальные страницы Chrome/Firefox, desktop/narrow/RTL/dark/forced colors. Фактические результаты — в отчёте задачи и release evidence.

Дополнение 2026-10-10: по решению владельца продукта OFF сворачивает popup до шапки,
заканчивающейся тремя ссылками на сайты. Все соседние блоки ниже Brand скрываются
из layout и клавиатурной навигации; нижний разделитель и его отступ убраны.
Правило следует текущему `aria-checked` существующего тумблера, включая изменения
из другой панели и загрузку сохранённого OFF. ON возвращает прежние разделы и
выбранный режим. В sidepanel скрывается тот же контент; размер браузерной боковой
панели задаёт сам браузер. Меню языка и настройки остаются доступны.
На время открытия меню языка свёрнутый popup расширяется до 440 px; список
ограничен 300 px и прокручивается. Это исключает зависимость высоты списка от
уже свёрнутого viewport. После выбора или закрытия возвращается высота шапки.
Изменены только screen CSS и документация; состояние записи и backend не менялись.

Следующее уточнение владельца: языковое меню полностью непрозрачное. Его фон
использует сплошной `--surface` светлой/тёмной темы, граница — `--border`,
размытие фона отключено. Размеры, прокрутка и выбор языка сохранены.
При открытом списке шапка поднимается над нижними разделами, чтобы кнопки
блокировки не перекрывали языковое меню.

Уточнение 2026-10-20: по прямому решению владельца продукта из production popup и sidepanel
удалена кнопка «Приостановить наблюдение в текущем документе» вместе с её вариантом
«Возобновить наблюдение». Управление наблюдением остаётся у верхнего общего
переключателя; export и очистка в ReportActions сохраняются. Это изменение
отображения, без изменения backend-команд и legacy приложения.

Следующее уточнение 2026-10-20: нижняя кнопка «Открыть панель» перенесена в шапку
popup как локальная SVG-иконка пина непосредственно справа от выбора языка.
Действие остаётся обычной кнопкой с прежним session.openSidePanel: Chrome открывает
sidePanel, Firefox — sidebarAction через существующий адаптер; затем popup закрывается.
Внутри уже открытой боковой панели пин не дублируется. Подсказка и aria-label используют
прежний open_sidepanel на всех 21 языках. Настройки браузерного закрепления расширения,
permissions и состояние наблюдения не меняются. Sync UI actions обновляет и существующую
шапку, и factory иконок идемпотентно.

Следующее уточнение 2026-10-20: по решению владельца продукта popup расширен с 380 до 400 px.
В `popup.css` поверхность html/body скруглена на 14 px; высота и основной scroll-container
остаются автоматическими. Локальные полосы прокрутки popup и вложенных списков
получили округлый ползунок и прозрачную дорожку: стандартный thin в Firefox,
8 px и без стрелок через webkit-псевдоэлементы в Chromium. Предусмотрены тёмная тема
и системная полоса при forced colors. Внешнюю рамку toolbar popup рисует браузер;
CSS меняет поверхность документа без обрезания контента. Диапазон компактной шапки
с пином расширен до 380 px контейнера, чтобы новая ширина без полосы прокрутки
сохраняла кнопки в одной строке. Sidepanel, Options, тексты и backend не менялись.

Коррекция по следующему решению владельца продукта 2026-10-20: искусственные radius html/body
и непрозрачный фон html удалены — их сочетание оставляло видимые белые углы под
градиентом body. Фон body снова заполняет canvas; внешняя рамка остаётся браузерной.
Для заметной прокрутки Chromium дорожка расширена до 12 px, видимый округлый ползунок —
до 8 px, с мягкой дорожкой, градиентом и контрастными hover/active состояниями.
Firefox использует стандартную ширину auto вместо thin и те же цвета; точная ширина
зависит от браузера/ОС. Системное оформление forced colors сохраняется.
По последнему точному размеру от владельца панель settings/language/pin имеет высоту
30 px, кнопки — 28 px, иконки — 16 px. Это заменяет промежуточные варианты 25 px и высоты
по букве t. Прозрачный hit target — 32 px, текст языка — 12 px. Флаг в trigger — 18×12,
флаги выпадающего меню сохраняют прежние 20×14; SVG chevron оформляется отдельно.

Уточнение 2026-10-20: по решению владельца продукта убран отдельный 8 px промежуток между
описанием расширения и строкой ссылок. Screen gap шапки теперь 0; геометрия кнопок,
переносы переводов и структура Brand сохраняются.
