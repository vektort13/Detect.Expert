# ADR-056 — ограниченное восстановление регистрации Custom после ошибки браузера

Дата: 2026-10-20. Основание — проверка совместимости Cloudflare по решению владельца продукта, ADR-048/049, REQ-002/012/015.

Подтверждён самостоятельный дефект: после сохранения OFF временный отказ `userScripts.unregister` оставляет прежний ранний профиль и opaque fallback зарегистрированными. Контроллер корректно показывает error/pending, но успешное восстановление native API раньше не завершало cleanup при обычном чтении состояния. Причинная связь с сообщённым зацикливанием Cloudflare не установлена.

После неудачного reconcile сохраняется pending. Следующий доверенный UI get-state при доступном native userScripts допускает одну сериализованную попытку завершения операции. SET-response не расходует этот бюджет. Параллельные GET используют одну физическую попытку; постоянный отказ не запускает бесконечные повторения при UI polling. Бюджет обновляется только новой операцией reconcile или фактическим переходом доступа в ready. Переход проверяется по актуальному состоянию после native await, чтобы параллельное восстановление доступа не выдало несколько бюджетов.

Успешное восстановление очищает pending после проверки регистрации и прежнего legacy finishApplication. Выбор пользователя, значения, библиотеки и revision не меняются. Открытый Custom-документ остаётся неизменным до выхода из него: публичного stop/restore, временного раскрытия native и специальных исключений Cloudflare не добавляется. OFF действует на новые документы после подтверждённого снятия регистраций.

Permissions, wire, sender guards, детекторы, Firewall/DNR, чтение полей и сенсоры не меняются. Наблюдающие обёртки не маскируются. Проверки Cloudflare разделяют официальные тестовые виджеты Turnstile и реальные production Challenge Pages: первое не доказывает прохождение второго.

Проверки: unit temporary/persistent failures, access restoration и concurrent reads; независимый review; нативная ошибка настоящего unregister, проверка userScripts/opaque регистраций, старого Custom-документа и нового OFF-документа. Фактические результаты — во внутреннем отчёте.
