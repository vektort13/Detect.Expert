# ADR-037 — значения исходящих Cookie в локальной Pro-записи

2026-10-10. Прямое решение владельца продукта: сводная таблица «№ / имя / переданное
значение» в локальном Pro preview/PDF. REQ-004/005/011/012/013/015; ADR-023/036.

Это узкое дополнение к ADR-023 и REQ-005: при явно начатой trusted UI
Pro-записи и действующем согласии расширение сохраняет значения Cookie,
которые браузер сообщил в исходящем `webRequest.onSendHeaders`. Снимок
cookie jar не используется: наличие cookie в хранилище не доказывает её
отправку. Расширение не меняет запросы, не создаёт запросы и не читает
Authorization, Set-Cookie, остальные значения заголовков или тела запросов.
Optional cookies permission для этого канала не нужна; действуют уже
существующие webRequest и host permissions. Permissions/CSP не расширяются.

Новый необязательный `page.cookieValues` отделён от metadata-only
`page.cookies`. Он содержит `documentKey`, `supported`, `truncated` и строки
`documentKey / destinationHost / name / value / count / firstSeenAt / lastSeenAt`.
Значения берутся только из privileged native observer. MAIN/ISOLATED мост,
PageBatch, Light, `ui-get-cookies` и `ui-get-cookie-view` этот канал не
принимают. Canonical reader проверяет точные поля, own data descriptors,
типы, дубликаты, привязку вкладки, период записи и лимиты. Production
background/popup/sidepanel/report используют один canonical reader.

До чтения заголовков проверяются активная запись, согласие, readiness,
tracked tab, native documentId, текущая page/document binding, lifecycle,
pause/scope и разрешение destination host. Native timestamp должен попадать
в период записи; для обычных запросов — также в текущее посещение. Старое
событие не может попасть в новую SPA-запись того же документа. При отзыве
доступа значения очищаются через существующие clear/forget границы.

Для навигации допускается ограниченная очередь: существующий native
requestId и его текущий request object, точный documentId, scope generation
и session identity сохраняются до совпадающего native navigation commit.
Совпадение домена или времени не служит привязкой документа. Отменённые,
заменённые или неподтверждённые запросы удаляются. Оригинальная временная
метка отправки сохраняется и может предшествовать commit нового посещения,
но не началу Pro-сессии. Буфер не включается в snapshot до подтверждения.

Лимиты: 256 вариантов и 256 KiB на посещение; имя ≤256 символов, значение
≤16 384 символов; ≤128 headers, суммарно ≤65 536 символов Cookie headers и
≤512 cookie pairs на событие; ≤200 обычных событий/с. Pending navigation:
≤32 записи / 128 KiB / 10 секунд, входит в общий Pro budget. Очередь
очищается при stop/reset/dispose. Cookie и pending budget входят в общий
лимит Pro 3 MiB. Превышение отмечается `truncated`/ограничением записи;
слишком длинное значение пропускается целиком, а не выдаётся за полное.

Пустые значения, `=` внутри значения и разные варианты одного имени
сохраняются без URL/base64/JWT декодирования. Повторное наблюдение той же
четвёрки document/host/name/value увеличивает насыщаемый счётчик. Native
браузер определяет отправленные store/partition cookies; расширение не
выбирает другой cookie store и не обходит partition restrictions.

Сохранение идёт только в существующую локальную Pro session storage; экспорт
остаётся явным действием из той же preview-проекции. Внешнего upload,
telemetry, логирования значений и новых зависимостей нет. TPM/DBSC membership
по Cookie header не выводится. Существующий TPM unknown статус не меняется.

Если browser adapter не даёт авторитетный network documentId (текущий
Firefox adapter), `supported=false`, raw значения не собираются. Запросы
без подтверждённой привязки не присваиваются текущему документу наугад.
Это ограничение показывается один раз в деталях записи. Уже сохранённые
metadata Cookie таблицы продолжают работать в обоих браузерах.

Проверки: `scripts/test/pro-cookie-values.test.mjs` и независимый
`scripts/test/pro-cookie-values-review.test.mjs`: parser/bounds, exact
variants, epoch/consent/pause/revoke, native source/destination, navigation
commit/cancel, memory/time budget, canonical Pro wire и Light isolation.
Реальные browser результаты фиксируются в release review, отдельно от unit.
