# ADR-026. Пассивное наблюдение запросов социальных сервисов

Status: Accepted, implemented; прямое решение владельца продукта 2026-10-09. DET-059; REQ-001/002/004/005/007/008/010/011/012/015, ADR-021/025.

Владелец запросил кнопку Social Networks рядом с Cookie и указание скрипта, запросившего социальный сервис. Расширение наблюдает действия страницы и браузерную сеть. Оно не запрашивает сайты для проверки входа, аккаунтов, истории или cookies и не читает результат авторизации.

Отдельная вкладка содержит фиксированные наблюдения для 45 социальных, identity, OAuth и widget сервисов (расширение ADR-028). В production включены 57 семейств host/path/type правил: 19 tracking SDK, 15 обычных SDK, 14 tracking collector/pixel и 9 embed. Источники закреплены в локальных source ledgers: базовый реестр содержит 22 primary ссылки, расширение — 42 primary URL, 78 positive expansion fixtures и 12 bounded hosted-code reads HTTP 200 без исполнения или сохранения SDK. Неподтверждённые VK SDK, collector paths и legacy AddThis не повышаются выше общего обращения к сервису; неизвестные Mastodon instances остаются unknown. Общий провайдер/widget SDK сам по себе не считается трекингом.

Обычная OAuth-навигация, iframe, обычный/tracking SDK, pixel, embed, возможная проверка статуса и Login Status API имеют разные kind. Они описывают запрос/вызов, а не установленное состояние аккаунта. Неподтверждённый provider unknown остаётся строкой и не увеличивает число распознанных сервисов. Canonical manual-redirect/FedCM enum сохранены для совместимости; текущие MAIN hooks не создают такие строки из произвольных параметров fetch или CredentialsContainer.get.

Browser webRequest даёт browser-observed request count и frame-only/unknown attribution. MAIN hooks дают отдельные page-controlled call/DOM counts. Счётчики этих источников не суммируются в запросы. CurrentScript даёт exact-resource; безопасный own-data Error.stack sample даёт sampled-stack; иначе script неизвестен. Нативный вызов выполняется один раз с прежними this/args/result/exception; чужие Promise не наблюдаются. Getter/coercion произвольного аргумента, request body, query/fragment, полный URL, raw stack, account/status value не читаются и не передаются. Script хранится как registrable host и фиксированный basename либо /<script>; частные пути удаляются.

MAIN наблюдает fetch, XHR open/send, sendBeacon, native src image/script/iframe, Element.setAttribute('src', ...), вставку ресурса, window.open и Login Status API. Fetch init и credential options полностью непрозрачны, включая descriptors/Proxy traps. Fetch с init, отличным от undefined/null, имеет MAIN method UNKNOWN; без init допускаются строковый URL либо branded native Request getters. CredentialsContainer.get даёт лишь общий DET-059 с settlement-unobserved и исходным Promise. Beacon true/false остаётся исходным результатом; social row описывает попытку POST/ping, не доставку. src/attribute и последующая вставка одного ресурса дедуплицируются; повторное присваивание считается отдельным действием страницы.

Канонические readers в packages/contracts проверяют точную форму, enums, provenance, counts, descriptors и bounds. MAIN не может повысить integrity до browser-observed или инициировать privileged action. Browser event требует авторитетный documentId. Firefox без этого поля имеет неподдержанный browser channel; page channel с ISOLATED identity сохраняется. Inaccessible snapshots пусты. Background/UI отменяют late replies при document/access/consent/pause/permission changes.

При missing/malformed/unavailable MAIN bridge или timeout независимо авторизованные browser rows остаются partial с truncated; прежние page rows удаляются. Повторная авторизация обязательна и для этого fallback. Отказ доступа/навигация/pause возвращает пустой no-access результат. Cookie inventory и Social Pro capture имеют независимые каналы: ошибка Cookie read не подавляет доступное social наблюдение.

Limits: 32 background documents, 64 rows и 64 KiB/document, TTL 10 минут, 20 network events/document/s и 100/extension/s, два logical/physical reads с timeout 1,5 секунды; лимиты MAIN и bridge перечислены в coverage. Badge считает различные известные сервисы. Pro capture сохраняет доступные текущие main/child documents одного визита, максимум 24 snapshots/256 rows, с исходной integrity и явным truncated; счётчики относятся к наблюдаемому документу, а не только периоду Pro.

Live bridge сохраняет один pending slot и 500 мс интервал после завершения чтения. Ранний trusted read ждёт интервала в единственном слоте; его response timeout 400 мс начинается после отправки MAIN сообщения. Повторный pending read не вытесняет очередь и получает unavailable; ответы страницы до фактической отправки игнорируются. Это сохраняет ограничение чтений и предотвращает стирание Pro snapshot пустым мгновенным ответом при последовательном live/Pro capture.

Переполнение 24 документов отмечается truncated в первом сохранённом snapshot; переполнение 256 rows — в ограниченном документе. Scope/consent/document identity проверяются после async операций и flush. Полная social таблица Pro и динамические UI/report подписи локализованы во всех 21 существующих локалях; имена провайдеров фиксированы.

Новых permissions, runtime external connections или зависимостей нет. Production antifraud seeds не активируются. Отключение — pause/отзыв scope/consent; полноценное удаление hooks после reload согласно действующей политике.

Источники, compatibility, positive/negative/adversarial fixtures, redaction и native результаты: [coverage](../coverage/social-networks.md), реализация, native review, UI review.

Предыдущий baseline: 82 unit tests, Chrome 24 checks, Firefox 33 assertions. Для текущего расширения complete social suite — 98 tests, 98 pass, 0 fail/skip; включает exact serialized source equality, native semantics, Proxy opacity, source-backed positive/negative cases, browser-only/Pro-overflow и queued bridge timer regressions. Независимый review: 63 pass, блокирующих замечаний нет. Новые native/performance показатели добавляются после выполнения release checks.
