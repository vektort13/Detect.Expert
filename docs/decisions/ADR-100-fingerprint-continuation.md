# ADR-100 — Temporal defaults, CSS queries and asynchronous Custom guards

2026-11-01. The owner requested continuation of the fingerprint production audit after the remaining Temporal/CSS, Worker and internal Promise limitations were identified. This extends ADR-048/049/087/095. Evidence belongs to внутренний отчёт; REQ-003/004/005/010/011/012/015 remain unchanged.

## Selected default Temporal timezone

The existing `intl-formatting` Custom timezone takes precedence over the existing `timezone` Custom value. Locale-only Intl without either selected timezone does not change Temporal. No configuration field, API catalog ID or wire schema is added. The shared Intl installer may run for a legacy timezone-only profile, but that does not enable the newer Intl constructor projection. Registration runs that installer before the base metadata installer, so validation captures the original Intl resolver before the legacy timezone hook can replace its returned label. A lowercase legacy label may retain its old spelling while Temporal uses the canonical native identifier; equality of those raw labels is not promised.

Only existing Temporal.Now interfaces are eligible. timeZoneId invokes its original once and replaces the successful string with the selected zone. For zonedDateTimeISO, plainDateTimeISO, plainDateISO and plainTimeISO, an omitted or undefined first argument is replaced with that trusted primitive zone in the same native call. Explicit arguments, coercion, validation errors, receiver and extra arguments remain native. This narrow exception to original argument identity avoids a second clock sample and produces genuine native Temporal slots, including timezone rules. instant, explicit-zone conversion and constructors are unchanged. Missing/immutable APIs are not fabricated. Stop and descriptor ownership remain enforced; no shared native-source masking is introduced. Optional private argument-list indices must be checked against length before reading, so a call without that argument does not execute an inherited numeric getter. This also corrects the existing Intl optional-options path and the covered RTC callback/options paths; defining replacement private slots must not invoke inherited setters.

This aligns the covered default methods, not every Temporal/Date formatting route, Worker, local Date field or the operating system timezone. A selected legacy fixed Date offset is not a complete DST model.

## Bounded JavaScript media-query evaluation

The original matchMedia call and native receiver/coercion/throw happen first. Its genuine MQL and captured native media/matches accessors are retained. The evaluator adds boolean features, simple feature negation and modern/reversed/chained width, height and resolution comparisons using existing selected fields. Existing px/dppx/dpi/dpcm and unitless zero lengths are supported; unknown syntax/units remain native. Input length, alternatives and conjunction counts remain bounded. No native extra query, stylesheet rewrite, layout emulation or synthetic change event is added.

Mixed expressions use three-valued logic: selected false dominates AND; selected true dominates OR. If selected pieces cannot determine the expression, the existing native result remains. This corrects the former whole-expression fallback that could discard a decisive selected branch. The actual CSS renderer, conditional rules and native query-event scheduling remain separate known limitations.

## Asynchronous guard boundary

Private post-return constructor/species pinning from ADR-095 remains necessary, but it cannot protect a native backend's pre-return internal Promise chain. A covered asynchronous Custom operation may therefore check captured descriptors before calling its backend. The check must not invoke page getters, inspect unrelated application state or alter shared prototypes. The checked scope is the captured public Promise infrastructure, existing known static methods and their bounded effective lookup chains, and Object/Array inherited then paths. A changed checked boundary may produce an explicit captured guard error before backend invocation. Ordinary clean operations, selected results, rejection reasons and stopped/OFF behavior must remain functional.

Such guarded refusal in unsafe Custom state can precede native receiver/argument validation; tests and coverage must identify that compatibility difference. Deferred mutation after a backend has started, argument-driven reentrancy outside the existing narrow RTCOfferOptions guard, interface-specific result prototypes, unknown backend internals, foreign receiver realms and already retained native handles are not proven isolated by a pre-call check. The first baseline also assumes an early, unpoisoned target realm; an initially hostile Proxy cannot be declared a pristine intrinsic by descriptor lookup alone. No virtual success is substituted for an operation that needs its actual backend. Storage retains its separate ADR-085/086 selected-snapshot semantics without a native quota operation.

## Unchanged architecture and validation

There is no Worker/SharedWorker/ServiceWorker/worklet script rewriting, new permission, CSP change, privileged channel, dependency, telemetry or remote runtime code. Document MAIN userScripts are not Worker injection. Detector thresholds, Protect/password boundaries, catalog data, logo, themes and menu functions are unchanged. Actual BrowserLeaks access and executable versions must be recorded separately from owned local fixtures; a blocked new binary is not represented as a successful remote test.

Required evidence: RED/GREEN semantic regressions, independent API review, native Chrome/Firefox selected/OFF/stop controls, actual native Temporal where available, mixed CSS query controls, hostile descriptor/Promise and ordinary success/error controls, Worker coverage measurements, bounded hot-path comparison, full typecheck/unit/lint/privacy/build, and source/dist/ZIP bindings. Historical reports remain immutable. Neither passing this scope nor the supplied 280-key inventory proves universal virtualization or statistical naturalness.

Standards: [Temporal.Now](https://tc39.es/proposal-temporal/#sec-temporal-now), [Promise algorithms](https://tc39.es/ecma262/multipage/control-abstraction-objects.html#sec-performpromisethen), [Media Queries Level 4](https://drafts.csswg.org/mediaqueries-4/).
