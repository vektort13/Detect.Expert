# ADR-103 — Редизайн «Спокойное стекло»: одна модель модулей и единые состояния

Дата: 2026-11-04. Прямое утверждение владельца по итогам аудита
внутренние материалы проекта:
«Утверждаю! Приступай!». Уточняет ADR-089, ADR-090, ADR-091, ADR-099 и ADR-102
только в оформлении и навигации. Логика модулей не меняется.

## Решения владельца

1. Detector переносится в отдельную группу «Анализ». Группы Options: «Анализ»
   (Detector), «Защита» (API Guard, Firewall), «Атака» (Antidetect, Автосерфер,
   Cookies, Proxy), «Инструменты» (Интеграции, Настройки, Контакты). Это заменяет
   состав групп ADR-090.
2. Режимы правил API показываются как «Как в пресете», «Разрешить»,
   «Блокировать», «Своё значение» и в этом порядке. Сохранённые значения
   `bypass`, `off`, `on`, `custom`, формат конфигурации и wire не меняются.
3. «Выключено» — нейтральное состояние: серое кольцо и серая дорожка
   переключателя. Зелёный — работает, янтарный — частично, пауза или подключение,
   красный — только ошибка. Это заменяет правило красных точек ADR-090.
4. Ссылки detect.expert, anti.bot и antidetect.com переезжают в низ popup и
   боковой панели. Атрибуты ссылок (`_blank`, `noopener`, `noreferrer`) прежние.
5. «Пульт» — стартовый раздел Options (`#hub`). Прежние hash, `tabId` и алиасы
   разделов продолжают работать; шестерёнка popup открывает Пульт.

## Область

Popup, боковая панель и внутреннее меню Options со всеми разделами. Отдельные
окна (firewall.html, findings.html, report.html, requests.html,
activation-toast.html, privacy.html, precursor-settings.html) сохраняют
текущий вид.

## Реализация

- `redesign.css` подключается последним в popup.html, sidepanel.html и
  options.html. Он переопределяет токены шести тем (семь фактических палитр) на
  спокойные поверхности без многослойного свечения и задаёт общий вид
  переключателя, статус-чипа, кнопок, навигации, карточек и редакторов.
  Каскадные слои пока не вводятся: списки `<link>` и часть CSS принадлежат
  sync-скриптам с проверкой `--check`. Поэтому правила используют один якорь
  `:root body #root`; перевод всей таблицы стилей на `@layer` — отдельный шаг.
- Options: группа «Анализ», раздел «Пульт», шапка с поиском по разделам
  (Ctrl K / ⌘K, только локальные названия разделов и подразделов; без сети и
  хранения запросов), точки состояния различаются формой. При ширине до
  1119, 600 и 380 px шапка растёт строками, навигация идёт после неё в потоке.
- Пульт переиспользует существующие лаунчеры Antidetect, API Guard, Firewall и
  DPI Guard. Их переключатели выполняют прежние действия: CAS, а для Firewall —
  прямое включение одним кликом по ADR-098. Detector,
  Proxy, Автосерфер и Cookies показывают состояние из существующего
  read-only контроллера ADR-090 и ведут в свой раздел; у Detector есть
  прежний переключатель наблюдения. Блок «Требует внимания»
  использует только чтение: доступность `userScripts` и
  `permissions.contains` для optional `cookies`. Новых сообщений, разрешений,
  хранилищ и сетевых обращений нет.
- Popup и боковая панель: карточка сайта с чипом покрытия (существующее
  состояние и заголовки coverage), подписанный переключатель наблюдения,
  лаунчеры сгруппированы в «Защита» и «Атака», категории без наблюдений
  свёрнуты, заголовок вендоров по REQ-007, вкладки «Обзор» и «Запись Pro».
  Правки бандлов делает идемпотентный `scripts/production/sync-redesign-ui.mjs`
  по якорям, с `--check` в preflight. Встроенный Detector есть только в бандле
  popup, поэтому боковая панель получает фиксированную форму без `embedded`.
- API Guard и Antidetect: новые подписи режимов, локализованные категории.
  Категории Antidetect («Все» в конце списка) заменены «Быстрыми настройками» и четырьмя
  уровнями по [ADR-104](ADR-104-antidetect-privacy-rework.md).
- «Слежение третьих сторон» (уточнение владельца): панель начинается, как
  «Активная» и «Пассивная», с таблицы техник — видов сторонних запросов с доменами
  и числом запросов, затем обращения к API во встроенных документах и домены.
  Таблица ресурсов ADR-029 не изменена, но свёрнута в «Сторонние запросы».
  Новых строк локализации, сообщений и хранилищ нет.
- Распознанные сервисы (решение владельца продукта): блок «Подробности распознавания» под
  списком удалён. Системы из датированного каталога ADR-078 показываются карточками в том
  же списке, у каждой подпись источника и даты; отдельного блока «Системы из каталога» нет.
  Это уточняет показ ADR-078: карточки каталога не становятся live-результатами
  (`data-vendor-id`), не входят в счётчики и не заменяют проверенные сигнатуры REQ-008.
  У карточки live-вендора доказательства остаются под «Подробности».
- Разделы в стиле редакторов антидетект-браузеров (решение владельца продукта по образцам Dolphin
  Anty, AdsPower, Hidemyacc), только существующие функции и данные:
  Antidetect — верхние вкладки, секции из строк «подпись + сегментированный переключатель»,
  липкая панель «Обзор» (сохранённое и черновое состояние, счётчики правил по категориям,
  на вкладке профилей скрыта); библиотека профилей — генератор строками и список профилей с
  пометками «Применён» / «В предпросмотре»; API Guard — единая панель фильтров, сворачиваемые
  группы, плашка действующего режима и компактный трек режимов; Proxy, Cookies и Автосерфер —
  таблицы менеджеров с сортируемыми заголовками, плашками состояния и круглыми действиями.
  Страна, срок, теги прокси и покадровый запуск в очереди Автосерфера не добавлены: таких
  данных нет (ADR-070/071/075).
- Анимация: один слой в `redesign.css` под `prefers-reduced-motion: no-preference` —
  переходы цвета и тени до 180 мс, нажатие кнопок `scale(.97)`, появление всплывающих окон,
  диалогов и раскрытых секций до 160 мс; без трансформаций у измеряемых элементов, без
  бесконечных анимаций, Protect не затрагивается.

## Сохраняется

Знак, logo.svg, цвет #2463c9 и декоративный слой ADR-094; собственные hue
категорий, протоколов и систем ADR-099; компонентные кольца фокуса и forced-colors;
шесть ID тем, ключ `ui-theme-v1` и контроллер;
имена сообщений и wire; permissions и CSP; vendored-код 722fae8, тексты
согласия и поведение модуля «Защита» (Firewall меняется только host-стилями);
CAS, черновики и проверки отправителя; 21 язык; REQ-001…015, включая покрытие
рядом с выводами и отсутствие вердикта о сайте.
