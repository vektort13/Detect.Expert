# ADR-109 — Proxy Manager Geolocation API

Дата: 2026-11-06. Прямое решение владельца продукта: рядом с пунктом Cloudflare Precursor добавить пункт для менеджера прокси,
предложить включить геолокационные API (ipdata, ip-api.com, ipgeolocation.io, MaxMind; рядом с MaxMind золотая звезда),
сделать переключатель включения, поля для ключей, совместимость с данными этих API, уведомление со ссылкой на вкладке
«Proxy» и дополнительные столбцы при включении. Блок называется **Proxy Manager Geolocation API**.
Дополняет ADR-070/071/108 (менеджер прокси); прецедент явного внешнего API-канала — ADR-076.
REQ-001/002/005/010/013/015; docs/PROJECT_RULES.md правило 10 («без исходящего трафика по умолчанию»).

Владелец назвал «три API», но перечислил четыре ссылки. Реализованы все четыре; порядок опроса задан каталогом
(`GEO_PROVIDERS` в `proxy-geo-shared.js`): MaxMind, ipgeolocation.io, ipdata, ip-api.com.

## Что разрешено (узкое исключение)

Один явный исходящий канал: фиксированные HTTPS/HTTP GET к шести хостам провайдеров, из собственной страницы расширения
(Options, страница настроек блока). По умолчанию функция выключена, до явного включения и ввода ключа запросов нет.

- **CSP extension_pages** получает ровно `connect-src https://api.cloudflare.com https://geolite.info https://geoip.maxmind.com
  https://api.ipgeolocation.io https://api.ipdata.co http://ip-api.com https://pro.ip-api.com`. Список хостов — единый источник
  `geoConnectOrigins()`; тест сверяет manifest с ним. `script-src 'self'; object-src 'none'; base-uri 'none'; frame-ancestors 'none'`
  не меняются. Новых permissions нет: `host_permissions` уже содержит `http://*/*` и `https://*/*`.
- **Запрос**: только `GET`, `credentials: 'omit'`, `redirect: 'error'`, `cache: 'no-store'`, `referrerPolicy: 'no-referrer'`,
  таймаут 12 с, тело ≤ 64 КиБ, тип содержимого JSON, один HTTP-запрос на попытку, без повторов в цикле. Исполняет только
  `proxy-geo-client.js`; запросы идут не из service worker и не из MAIN/ISOLATED, нового канала сообщений нет.
- **Что уходит провайдеру**: публичный внешний IP, найденный ручной проверкой прокси (частные и зарезервированные адреса не
  отправляются вообще), ключ (MaxMind — номер аккаунта и лицензионный ключ в заголовке Basic), а также то, что видит любой
  получатель запроса: адрес отправителя (ваш IP или выходной IP активного маршрута браузера) и стандартные заголовки браузера.
  Не уходят: URL посещённых страниц, содержимое страниц, cookie, адрес и порт прокси, логин и пароль прокси, ваши метки и заметки.
  Провайдер со временем может узнать список ваших прокси — это плата за функцию, и страница настроек говорит об этом прямо.
- **Когда**: после завершённой *ручной* проверки (опция «Определять сразу после проверки», включена), по кнопке «Определить» в
  деталях профиля и «Проверить ключ» на странице настроек. Нет таймеров, опросов, запросов при открытии списка и
  обновлений в фоне. Результат кэшируется по IP, повторный показ идёт без сети.
- **Резерв провайдеров**: если первый готовый провайдер вернул ошибку, которую может исправить другой (ключ, тариф, лимит,
  сеть, «нет данных»), тот же IP уходит следующему *включённому и имеющему ключ* провайдеру. Переключатель
  «Пробовать следующего провайдера» включён по умолчанию; все провайдеры в цепочке — только выбранные пользователем.
- **Хранение**: три значения. `proxy-geo-settings:v1` (`storage.local`): переключатели, выбор столбцов, параметры провайдеров, без ключей.
  `proxy-geo-credentials:v1`: ключи — по умолчанию только в `storage.session` (TRUSTED_CONTEXTS, до закрытия браузера);
  при включённом «Запомнить ключи на этом компьютере» — в `storage.local` без шифрования. `proxy-geo-cache:v1`
  (`storage.local`): до 200 нормализованных результатов, не старше 30 суток; очищается кнопкой. Ключи не попадают в экспорт
  конфигурации, отчёты, снимки, логи, сообщения между контекстами, историю проверок и кэш. Кэш и история проверок содержат IP
  прокси пользователя; в экспорт они не входят.
- **Что не делается**: никаких вердиктов («безопасный/опасный»), решений о блокировке, смены маршрута или Antidetect по результату;
  флаги — «по данным провайдера»; координаты, почтовый индекс и ваш собственный IP не сохраняются и не показываются;
  автоопределение «страны по IP» для Antidetect не вводится (ADR-107/108 в силе); метка страны остаётся собственной заметкой.

## Совместимость с API (проверено по документации 2026-11-06)

Живые запросы выполнены 2026-11-06 из страницы расширения, собранной из исходников (общий CSP, `credentials: 'omit'`, без
referrer): бесплатная точка ip-api.com (успех для 8.8.8.8 и `private range` для 10.0.0.1) и по одному запросу с заведомо
неверным ключом к ipdata, ipgeolocation.io, MaxMind (`geolite.info` и `geoip.maxmind.com`) и ip-api Pro. Подтверждено: CSP
пропускает все шесть хостов, CORS не мешает чтению ответа, незашифрованный `http://ip-api.com` не блокируется браузером, хост
вне списка блокируется CSP, формы ответов об ошибке ключа совпали с документацией (ipdata и ipgeolocation.io — HTTP 401 и
`{"message": …}`; MaxMind — HTTP 401, тип `application/vnd.maxmind.com-error+json`, `AUTHORIZATION_INVALID`; ip-api Pro — HTTP 403 и
`{"status":"fail","message":"invalid/expired key…"}`). Успешные ответы MaxMind, ipgeolocation.io, ipdata и ip-api Pro не проверялись
(ключей нет): разбор построен по документации и образцам ответов, статус **candidate** (REQ-015); настоящую проверку выполняет
пользователь кнопкой «Проверить ключ».

| Провайдер | Запрос | Авторизация | Ошибки (→ код) | Лимиты по документации |
| --- | --- | --- | --- | --- |
| MaxMind GeoLite City / GeoIP City Plus / Insights | `GET https://geolite.info/geoip/v2.1/city/{ip}`, `https://geoip.maxmind.com/geoip/v2.1/{city\|insights}/{ip}` | HTTP Basic: номер аккаунта + лицензионный ключ; только HTTPS (HTTP → 403 без JSON) | JSON `{code,error}` с типом `application/vnd.maxmind.com-error+json`: 400 `IP_ADDRESS_INVALID/REQUIRED/RESERVED` → `not-public`; 401 `AUTHORIZATION_INVALID/ACCOUNT_ID_REQUIRED/LICENSE_KEY_REQUIRED` → `unauthorized`; 402 `INSUFFICIENT_FUNDS` → `quota` (для GeoLite — суточный лимит); 403 `PERMISSION_REQUIRED` → `forbidden`; 404 `IP_ADDRESS_NOT_FOUND` → `not-found`; 429 → `rate-limited`; 5xx → `server` | GeoLite: суточный лимит; платные — баланс; `maxmind.queries_remaining` в ответе |
| ipgeolocation.io | `GET https://api.ipgeolocation.io/v3/ipgeo?apiKey=…&ip=…` (+ `include=security` по галочке, только платный тариф) | параметр `apiKey` | 400 → `not-public`/`bad-response`; 401 (ключ, неподтверждённая почта, приостановленная подписка) → `unauthorized`, а текст «not supported on your subscription / paid subscriptions only» при включённом `security` → `plan`; 402 (срок платной подписки истёк) → `unauthorized`; 403 → `forbidden`; 404 → `not-found`; 423 (bogon/частный) → `not-public`; 429 → `quota` (бесплатный тариф исчерпан); 5xx → `server` | бесплатно 1000 кредитов в сутки; запрос стоит 1 кредит, `security` +2 |
| ipdata | `GET https://api.ipdata.co/{ip}?api-key=…` | параметр `api-key` | JSON `{message}`: 400 (частный/зарезервированный/не IP) → `not-public`; 401 → `unauthorized`; 403 (квота исчерпана) → `quota`, («upgrade to a paid plan») → `plan`, иначе (список разрешённых) → `forbidden`; 5xx → `server` | суточная квота по тарифу; на бесплатном — геолокация, ASN, часовой пояс; `threat` и `company` зависят от тарифа, `is_vpn` — Business |
| ip-api.com | бесплатно `GET http://ip-api.com/json/{ip}?fields=…` (только HTTP); с ключом `GET https://pro.ip-api.com/json/{ip}?key=…&fields=…` | без ключа или параметр `key` | HTTP 200 с `{"status":"fail","message":"private range"\|"reserved range"\|"invalid query"}` → `not-public`; HTTP 403 с `status: fail` и сообщением о ключе → `unauthorized`; HTTP 429 → `rate-limited` (заголовки `X-Rl`, `X-Ttl`: при `X-Rl: 0` пауза `X-Ttl` с) | бесплатно 45 запросов в минуту, без коммерческого использования, при постоянном превышении бан на час; Pro — без лимита |

Форма Pro (`https://pro.ip-api.com/json/{ip}?key=…`) взята из теста стороннего клиента (`…/json/24.48.0.1?key=foo`): первичная
страница Pro в личном кабинете недоступна без входа. Живой ответ на неверный ключ (HTTP 403, «invalid/expired key») показывает,
что сервер узнаёт и хост, и параметр `key`; успешный ответ Pro не проверялся.

Нормализованная запись (`normalizeGeoRecord`): провайдер и сервис, время, IP, страна (ISO), название страны, регион, город,
часовой пояс (IANA), ASN, организация, провайдер связи, тип использования (`residential/hosting/mobile/business/education/
government/isp/cdn/other`) и восемь флагов `proxy/vpn/tor/hosting/mobile/relay/residentialProxy/threat` со значениями
`true/false/null` («не сообщено»). Строки очищены от управляющих и bidi-символов и ограничены 80 символами; интерфейс
показывает их только текстовыми узлами. Флаг `proxy` у ip-api означает «прокси, VPN или Tor» (провайдер не различает) — подсказка
говорит об этом. Отсутствующие у тарифа данные — «не сообщено», а не «нет».

## Интерфейс

- **Настройки → Интеграции**: рядом с Cloudflare Precursor второй пункт «Proxy Manager Geolocation API»; он открывает собственную
  страницу `proxy-geo-settings.html` в том же стиле (7 тем, 21 язык, RTL). На странице: общий переключатель, параметры
  («после проверки», «следующий провайдер», «запомнить ключи»), четыре карточки провайдеров (MaxMind — с золотой звездой и подписью
  «Рекомендуем»), для каждого — ссылка на документацию, поля ключа с кнопкой показа, «Проверить ключ», «Удалить ключ»,
  состояние; очистка кэша и всех ключей. ip-api без ключа работает только по явному подтверждению, что бесплатная точка
  использует незашифрованный HTTP.
- **Proxy**: пока функция выключена или не готова, над списком показывается закрываемое уведомление «Улучшите результаты: укажите
  ключ Geolocation API» со ссылкой на страницу настроек. Когда она включена, в список добавляются столбцы **Локация, Сеть, Тип,
  Признаки, Часовой пояс**; видимость каждого настраивается в меню столбцов (группа «Геолокация (API)»). Карточки на узком
  экране и панель деталей показывают те же данные и источник; несовпадение страны с вашей меткой подсвечивается подсказкой.

## Решения по умолчанию, которые владелец может изменить

1. **Ключи не сохраняются на диск** (как токен Cloudflare по ADR-076); галочка «Запомнить» включает хранение в `storage.local`
   без шифрования. Чтобы сделать запоминание поведением по умолчанию, достаточно изменить `remember` в `defaultGeoSettings()`.
2. **Бесплатная точка ip-api.com — HTTP.** Она добавляет `http://ip-api.com` в CSP. Если Chrome Web Store или владелец не
   принимают незашифрованный хост, достаточно удалить его из `GEO_PROVIDER_INFO.ipapi.origins` и CSP: останется Pro по HTTPS.
3. **Определение после ручной проверки включено**; это не «автоматическая проверка IP» по ADR-070: нет таймера, нет запроса без
   ручной проверки или кнопки.
4. **Firefox**: манифест объявляет `data_collection_permissions: required ['none']`, а функция передаёт IP ваших прокси и ключи
   сторонним провайдерам по вашему включению — то же открытое решение, что у токена Cloudflare и прокси.

## Не реализовано и почему

Пакетные запросы провайдеров (платные, лишний риск), европейская точка ipdata (ещё один хост в CSP), язык ответов (`lang`),
координаты и почтовый индекс (минимизация данных), автоматическая подстановка региона в Antidetect (запрещено ADR-107/108),
оценка «качества» прокси по флагам (вердикты запрещены правилом 7), кэш в IndexedDB (хватает `storage.local`).

## Известные пределы

Ключей нет, поэтому ответы MaxMind, ipgeolocation.io и ipdata не проверялись вживую; бесплатные тарифы возвращают меньше полей
(это «не сообщено»); данные геолокации приблизительны и могут отличаться между провайдерами; запрос идёт тем маршрутом, который
сейчас выбран в браузере; расширение не проверяет, разрешает ли тариф коммерческое использование.
