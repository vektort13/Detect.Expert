# ADR-025. Полная таблица Cookie и сбор метаданных при закрытой панели

Status: Accepted, implemented; прямое решение владельца продукта 2026-10-09. REQ-004/005/007/011/012/013/015, ADR-021/023/024.

Владелец запросил полный список cookie с расшифровками и локализацией в Pro-отчёте. Ранее отчёт использовал карточки, а известные cookies имели закрытый details-анализ. Кроме того, metadata snapshot появлялся только после чтения открытой панелью.

Каждый сохранённый snapshot отображается таблицей без дополнительного ограничения, объединения одинаковых маскированных имён или скрытого анализа. Строки содержат имя, локальную марку компании, domain scope, категорию, tracking, confidence, полное admitted purpose, анализ всех атрибутов, все admitted rule IDs и source URLs, срок жизни, отдельные статусы DBSC и TPM. Таблица повторяет заголовок при печати; значения и live handles в неё не входят. Старые snapshots без новых optional полей поддерживаются; отсутствие snapshot имеет функциональный статус недоступности.

Все заголовки, категории, статусы, даты и анализ атрибутов локализованы на 21 язык. Декларации IAB из 14 фиксированных purpose tokens и фиксированное описание CookieBlock переводятся полностью. Свободный текст других справочников сохраняется в исходной формулировке, когда точного перевода нет; назначение не заменяется догадкой. Источники и технические имена атрибутов сохраняются.

ProCookieCapture автоматически читает только metadata с прежним optional cookies permission и действующими consent/scope. До двух физических capture workflows; максимум 16 текущих страниц; интервал одной страницы 5 секунд, timer 750 мс, ожидание остановки до 6 секунд. CookieInspector использует последовательные native queries при автоматическом сборе, общие limits/physical capacity и повторную авторизацию. UI не нужен. Последний snapshot заменяет предыдущий в пределах визита; это не история всех удалённых cookies. Total до сканирования/вывода отдельно от количества admitted rows; при ограничении сохраняется truncated.

Запись привязана к объекту сессии, page object, текущему documentKey, access generation и cookie epoch. Смена страницы, остановка, отзыв доступа и clear отменяют допуск результатов. Незавершённые физические jobs продолжают занимать слот. После flush, включая reject, устаревший принадлежащий операции snapshot удаляется; accounting текущей сессии не изменяется результатом другой сессии. После восстановления Pro размеры Cookie и Social snapshots учитываются в общем лимите.

Permissions, CSP, внешние соединения, значения Cookie и зависимости не расширяются. Исключение ADR-023 остаётся только явным live просмотром одного значения.

Приёмка: независимый capture review, UI review, native Chrome/Firefox table/closed-panel fixtures и итоговое покрытие выпуска.
