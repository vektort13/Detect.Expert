# ADR-084 — корректность realm, Document.open и Undo профиля

Дата: 31.10.2026. Повторный аудит владельца, ранее данное разрешение исправлять
найденные проблемы. REQ-002/003/004/005/010/011/012/015; ADR-048/049/064/068/083.
Артефакты: внутренний отчёт.

## Подтверждённые случаи

- FP-14: Custom-массивы/словари, создаваемые унаследованным installer, получают
  прототипы родительского realm. Выбранные значения применяются, но native
  child Array/Object identity нарушается. Native Chrome/Firefox воспроизведено.
- FP-15: трёхаргументный Document.open возвращает новое Window, которое не получает
  синхронное наследование через этот hook. Native Firefox воспроизведено;
  Chrome в проверенной сборке закрывает окно собственной ранней регистрацией.
- FP-16: Undo импорта API configuration берёт dirty draft вместо saved baseline
  и записывает настройки, которых до импорта не было в storage.

## Решение

1. Public Custom arrays/dictionaries получают captured прототипы целевого realm.
   Не вызываются страничные constructors/getters ради копирования. Native handles,
   brand checks, один native call и ошибки сохраняются; Function masking нет.
2. После успешного Document.open native Window result передаётся существующему
   bounded protect() до возврата. Null/Document/error/недоступный Window сохраняют
   native outcome. Защита использует прежний Window brand guard, cap1024, marker
   и capture veto, не новый канал и не обход SOP.
3. Undo импорта хранит подтверждённый saved snapshot до импорта. Прежний dirty
   draft не становится persisted через Undo. Preview/Cancel/CAS и более новая
   revision сохраняют прежние границы; автоматических повторов записи нет.

## Проверки и границы

RED/GREEN регрессии, независимый review, native Chrome/Firefox Options и
BrowserLeaks, source/dist/ZIP hashes. Точный HTML observer pin обновляется только
после независимого review прежнего literal forwarding; scanner не ослабляется.
Permissions/CSP/manifest, schema/enums/catalog, native API availability, privacy
storage и Protect не меняются; новых зависимостей/соединений продукта нет.

FP-12/13 остаются отдельными открытыми async interception gaps: native Promise
resolution может вызвать inherited then getter, а SpeciesConstructor раскрывает
native Promise при преобразовании результата. Native подтверждение ограничено
StorageManager. Эти правки не объявляются исправлением Promise paths, Canvas
round-trip, Worker/CSS/fonts/audio/network или статистической натуральности.

Target-realm исправление относится к public arrays/dictionaries generic runtime,
не к realm самих wrapper functions или dedicated RTC/Canvas/Math allocations.
При absent/accessor Array/Object globals используется captured parent fallback
без вызова страницы; data-свойство с подменённым prototype не доказывает native
identity. Раннее применение в чистом browser realm проверяется отдельно.
