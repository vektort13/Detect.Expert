# ADR-077 — локальный подбор сайтов по стране и категории

Дата: 2026-10-30. Прямое решение владельца продукта: красивый интерфейс поиска сайтов
для встроенного автосерфера, собственные цвет и иконка каждой категории,
флаг каждой страны. REQ-004/005/010/011/012/015; дополняет ADR-075.

## Данные и границы

В собственную Options добавляется поставляемый каталог `autosurf-sites-data.js`.
Данные собраны до сборки расширения: датированный CrUX country snapshot через
Internet Health Report, закреплённые commit/month и SHA-256 исходников,
проектная разметка точных доменов по двадцати темам. Страна означает аудиторию
CrUX, не ccTLD, язык, местонахождение сервера или юрисдикцию организации.
Один выбранный HTTPS origin получает только страны и rank buckets, в которых
этот точный origin присутствует. Между www и другими именами страны не переносятся.
Bucket не является точным местом; порядок внутри bucket детерминируется именем.
Каталог не называется полным рейтингом или top-50 и не является проверкой
актуальной доступности либо вердиктом о безопасности сайта.

Источник CrUX — Google, лицензия CC BY 4.0; авторство, изменения и источник
доступны в UI и поставляемом `autosurf-sites-LICENSE.txt`. Настоящие флаги —
локальные SVG flag-icons, MIT, с закреплённым commit и хэшами; внешних ссылок,
скриптов и active SVG в них нет. Иконки и цвета тем заданы в коде UI.
Полная схема происхождения: `docs/data/autosurf-sites.md`.

В runtime используются только static imports и локальные изображения. Нет новых
permissions, CSP, SW-команд, remote packs, API keys или запросов при поиске.
Исследование владельца — источник вариантов; его примеры многовкладочности,
поисковых API, хранения ключей и GitHub cron не исполняются этим решением.
Сборщик может обновляться вручную из закреплённых публичных источников;
автоматическая публикация, push и расписание не добавляются.

## Интерфейс и изменение плана

Поиск по имени/домену, локализованный выбор страны с флагом, двадцать цветных
тем с различными SVG, фактические счётчики, страницы по двенадцать карточек,
выбор страницы и общий выбор. Клавиатура работает в country combobox; текст,
иконка и состояние выбора сопровождают цвет. Доступны тёмная тема, RTL и
все двадцать один язык существующего расширения.

Добавление обновляет только актуальный несохранённый `draft.urls`. Parent
повторно проверяет native-client readiness, текущий snapshot, видимость,
running/paused и последнюю редакцию черновика. Исходные URL, query, fragment,
пути и пробелы сохраняются; дедупликация по каноническому полному URL.
Уже заданные разные пути одного host не объединяются. При ошибке либо
переполнении план не меняется частично. Save и Start остаются отдельными
пользовательскими действиями, исходная CAS base dirty draft не меняется.

## Ограничения и проверка

Исходный предел 5000 строк расширен ADR-078 до 50 000 строк / 500 систем;
57 известных стран и 20 тем; HTTPS root origins,
bounded строки, массивы и исходные evidence. Query до 120 символов,
страница максимум 24 строки (UI 12), выбор и конечный план до 200 URL,
существующий byte budget ADR-075. Checked copy глубоко заморожена;
индекс, локализованные названия стран и поисковая выдача кэшируются.

Обязательны tests на точность country membership, неподдерживаемые URL и
метаданные, неизменность старого плана, дубликаты, границы 199/200,
dirty CAS и reconnect, keyboard/RTL, native Chrome/Firefox и отсутствие egress.
Preflight выполняет offline builder `--check`; lint принимает только явные
статические URL каталога/происхождения, не даёт сетевое исключение новому коду.
Результаты, измерения, review и хэши: внутренний отчёт.
