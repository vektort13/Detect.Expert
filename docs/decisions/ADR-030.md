# ADR-030 — декодер наблюдаемых маячков

2026-10-09. Решение владельца: «декодер маячков → фоновая работа → проверка восстановления cookies. Реализуй». REQ-002/004/005/008/010/011/012/013/015; развитие ADR-017/025/026/028/029.

## Решение

В существующем разрешённом webRequest callback допускается кратковременный разбор query и тела только известных host/endpoint/transport. Non-blocking `requestBody` listener не меняет отправку. Raw URL, body, IDs, email, phone, hash, secrets, custom names, purchase/order/product fields не сохраняются и не выходят из decoder. Разрешённая структурированная проекция расширяет REQ-005: фиксированный event enum, ограниченный decimal value, ISO currency, наличие известных идентификаторов, фиксированные consent states. Это прямое решение владельца продукта; общей телеметрии и сетевого сканирования нет.

Документированные transport profiles отделены от проверенных примерами форматов browser SDK и endpoint-only наблюдений. gcs/gcd показывают наличие: неизученный encoding не превращается в выдуманный consent state. Browser native document identity и разрешения проверяются до разбора. Firefox использует текущий ISOLATED Resource Timing fallback и не получает выдуманный native documentId или POST body.

Наблюдение вызова страницы со скриптом отделено от browser network event. Тайминг, общий host или параметр GTM не создают связь конкретного hit со скриптом. Существующие подтверждённые цепочки загрузки GTM сохраняются отдельно. Лимиты и redaction заданы каноническим контрактом; pause/revoke/navigation очищают текущие наблюдения.

## Приёмка

Positive/negative fixtures каждого формата, lookalike host/path, duplicate fields, invalid JSON/percent, file/body limits, privacy canaries, native Chrome/Firefox, независимый review. Preview, Pro и печать используют одну валидированную проекцию. Проверки и измерения записываются в отчёт реализации; этот ADR не является доказательством passing tests.
