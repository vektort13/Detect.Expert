# ADR-038 — улучшения по внешнему ревью датчиков

2026-10-10. Решение владельца: проверить приложенный отзыв и реализовать
улучшения. REQ-002/004/005/009/011/012/013/015; DET-014/022/023/042/049/058/064/069/074.

В общей production-базе Chrome/Firefox добавлены 27 именованных операций
(371 → 398). Worker/SharedWorker/Worklet наблюдаются на стороне вызывающего
документа; оригинальные URL, options, Promise, new.target, исключения и
результаты сохраняются. Переписывания через blob/importScripts/import нет.
Успешный синхронный возврат создания отмечает `worker-not-observed`:
внутренний код этих реалмов не инструментируется. Работающий менеджер
дочерних iframe сохраняется.

Новые операции: семь Generic Sensor constructors, три motion event types
через addEventListener и on* setters, CredentialsContainer.create, четыре
Clipboard methods, WebTransport, GPUBuffer.mapAsync/getMappedRange/unmap,
Worker/SharedWorker/Worklet.addModule, Document.cookie.get/set. Чувствительные
аргументы, результаты Clipboard, данные WebAuthn, GPU bytes, показания
датчиков и содержимое воркеров не читаются наблюдателями. Наличие вызова
не превращается в доказательство намерения или аппаратной идентичности.

Math распознаёт семь точных примитивных сигнатур официального FingerprintJS
math.ts. Это отдельный ограниченный сигнал DET-022/023, не vendor rule и
не новый порог confidence. Обёртки устанавливаются лишь при Pro-сеансе,
снимаются при clear/stop с проверкой владения. Числа и результаты не
передаются через мост, стек не снимается. Microbenchmark Pro выявил
существенные накладные расходы; общий performance gate не объявлен пройденным.
На повторных Pro-сеансах список owned handles не растёт.

Для document.cookie один registry handle владеет обоими accessor methods.
Сеттер вызывает оригинал ровно один раз и сохраняет имя cookie, фазу,
счётчик и нормализованный источник скрипта. Значение cookie в этот канал
не поступает. Произвольные object/Proxy аргументы не приводятся к строке.
Источник: native currentScript/src либо ограниченная выборка стека;
exact-resource и sampled-stack сохраняются раздельно. Это наблюдение
записывающего скрипта, а не доказательство сохранения cookie или источника
её восстановления из другого хранилища.

Канон — packages/contracts/src/cookie-writers.mjs. Новые сообщения
cookie-writers-query/cache, MAIN channel detect.expert/cookie-writers/v1,
trusted UI request ui-get-cookie-writers; optional Pro page.cookieWriters.
MAIN остаётся page-controlled. Проверки sender, native documentId,
permissions, consent, pause, generation и актуального документа выполняются
до и после await. Незавершённый reset блокирует повторную выдачу старых данных.
Таймаут не освобождает слот незавершённой физической операции.

Лимиты: ≤64 rows/24 KiB на документ, ≤24 документов/256 rows в Pro;
≤32 cached documents/TTL 10 min; ≤2 concurrent backend operations,
1500 ms timeout, мост: одна ожидаемая выдача, 400 ms deadline, 500 ms read
interval и ≤8 подходящих ответов. Cookie writer bytes входят в общий Pro
budget 3 MiB; metadata-only UI и Pro используют один reader. Отдельный
существующий канал исходящих значений cookies (ADR-037) не меняется.

Pro принимает ≤32 различных кортежей технических параметров на операцию.
Общий лимит 256 rows/64 KiB остаётся; повтор уже принятой строки продолжает
увеличивать счётчик. При ограничении выставляется truncated. Intrinsics
сохраняются при загрузке, включая Map/Set для поздних child runtimes.
Bounded stop cleanup slots увеличены с 8 до 16 для новых installers.

DET-074 дополнен присутствием Set-Login, CSP, HSTS, COOP, COEP, X-Frame-Options;
их значения не читаются. Пояснения отделены от DBSC. ThreatMetrix RTC rule
после 2026-10-12 получает явный stale rule ID и локализованную метку согласно
ADR-009 downgrade_to_stale_hint, оставаясь weak-signal. Исходные даты
проверки не сдвигаются; occurrence identity не создаёт дубль на границе срока.
Иные правила не продлеваются автоматически.

Native Firefox проверка обнаружила независимую COOP navigation race:
onCommitted мог опередить переключение getFrame/ISOLATED executeScript,
из-за чего сохранялась старая about:blank identity. Firefox adapter теперь
объединяет pending identity только внутри одной generation, отклоняет
устаревший результат и очищает только собственный pending job. Для exact
native onCommitted допустимы четыре попытки (0/50/150/300 ms задержки),
привязанные к той же generation, полному URL и listener owner. До 128
физических commit jobs удерживают слоты даже после отмены до settle;
до 256 identity jobs; исходные 1500 ms deadlines сохранены. Новая навигация
или ошибка отменяют старый commit. Не добавлены host/time fallback,
доверие MAIN или подмена documentId значением из сообщения страницы.
Фикстура с CSP и COOP:same-origin после исправления проходит в Firefox
138.0.4; причина пользовательского белого экрана этим тестом не установлена.

Permissions, manifest, CSP, upload, telemetry и зависимости не изменены.
Новые видимые строки переведены на 21 UI-язык. Production synchronizers
проверяют воспроизводимость через --check; preflight сверяет новые модули
и canonical contracts. Независимое ревью: внутренний отчёт
2026-10-10-review-improvements-independent-review.md. Матрица замечаний и
фактические проверки: docs/coverage/review-improvements-2026-10-10.md.

При native Chrome проверке с открытой панелью выявлена потеря Pro stop target:
MAIN уже мог принять start, но timeout/unavailable response удалял токен
из карты успешных чтений. Поэтому lifecycle теперь хранит отдельный ledger
попыток до отправки start/read, независимо от read acknowledgement. До 128
native document targets сохраняются до остановки; запись в новый target
без места в ledger не запускается. Stop использует точные сохранённые
tab/frame/document IDs, в том числе при временном исчезновении binding.
Control epoch проверяется после authorization и непосредственно перед
dispatch. ISOLATED сохраняет до 128 retired tokens без вытеснения: поздний
trusted start после stop не включает тот же сеанс снова; при заполнении
новая запись в данном документе отклоняется. Эти проверки не объявляют
MAIN сообщения аутентифицированными и не дают странице privileged прав.
