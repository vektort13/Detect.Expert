# ADR-102 — Внешнее меню с мягкими стеклянными поверхностями

2026-11-01. По прямому решению владельца продукта внешний popup переработан в стиле
современного iOS. Визуальный ориентир — [Apple HIG: Materials](https://developer.apple.com/design/human-interface-guidelines/materials).
Это собственное CSS-оформление существующего расширения, без сторонних SDK/ассетов.

`external-menu.css` подключается последним только в popup.html/sidepanel.html.
Все правила ограничены `body[data-external-menu]`: встроенный Detector в Options
и другие внутренние страницы не получают этот стиль. Общие preference IDs,
сохранение/синхронизация тем, locale, JSX/контроллеры, тексты и роли не меняются.

Палитра темы сохраняет свой hue, но idle-поверхности, линии и тени становятся
нейтральными. Убирается многослойное свечение каждого элемента. OFF использует
серую дорожку, ON — зелёную; видимый ON/OFF и native switch semantics сохранены.
Firewall attention, disabled, live/SR-only статусы остаются отдельными состояниями.
Нулевые счётчики имеют спокойный фон, ненулевые сохраняют цветовую семантику.

Существующие несемантические brand div становятся display:contents для явной
сетки logo/title/actions/subtitle/master/links. Сам SVG, цвет знака, пути и
пропорции не изменяются. Observation switch остаётся потомком Brand, поэтому
существующее OFF-поведение и цепочка согласия остаются действующими.

Сохраняются definite bootstrap400px и native compact reflow ADR-092, без CSS
zoom/масштабирования/JS-resize/обрезания переполнения. При узкой области actions
переходят в самостоятельную строку; подписи могут переноситься. Клавиатурный
focus, reduced motion/transparency, increased contrast и forced-colors имеют
явные scoped правила. Без новых анимаций, permissions/CSP, зависимостей, данных,
внешних подключений, изменений Protect или сенсоров.

Фактические native popup screenshots, все семь browser zoom и функциональные
проверки: внутренний отчёт. Источник эталонного поведения —
существующие контроллеры, а не CSS состояния или тестовые снимки.
