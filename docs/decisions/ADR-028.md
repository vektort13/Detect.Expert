# ADR-028. Расширение пассивного распознавания социального трекинга

Status: Accepted, реализовано и независимо проверено. Прямое решение владельца продукта 2026-10-09: максимально расширить распознавание социальных трекеров, включить наблюдения в Pro и локализовать их. Трассировка: DET-059; REQ-001/002/004/005/007/008/010/011/012/013/015; ADR-021/025/026.

## Решение

Расширяются локальные фиксированные provider/domain/host+path profiles для социальных интеграций и связанных SDK/pixels. Новый kind `tracking-sdk` отделяет подтверждённый SDK трекинга от identity/widget SDK. Новые provider IDs и kind добавляются в канонический inspection contract; прежние записи сохраняют валидность. Production-правила требуют источников и positive/negative fixtures. Общий ресурс платформы остаётся обычным обращением к сервису, если специфическая интеграция не установлена.

Наблюдаются только действия страницы и доступные браузерные запросы. MAIN выполняет native оригинал ровно один раз с прежними this/args/result/throw/Promise identity. Дополнительные чтения произвольных fetch/FedCM options не допускаются: descriptor lookup также способен вызвать Proxy trap. Неустановленный request mode/provider остаётся неизвестным; общие вызовы credentials не объявляются FedCM. Native brand-checked Request getters допустимы при отсутствии options override. Bridge не получает query, bodies, cookie/account values, raw stacks, ID или состояние входа.

Потеря MAIN reply после повторной успешной авторизации не стирает browser-network rows текущего документа: возвращается partial snapshot с truncated и отдельными browser counts. Failed authorization, pause, revoke, новая document identity или generation возвращают пустой no-access snapshot. Невалидный/недоступный MAIN cache не продлевает прежние page rows как свежие.

Pro сохраняет все admitted Social snapshots и строки через общий canonical reader. Превышение лимита текущих дочерних документов отмечается truncated в сохранённой проекции; лимиты не увеличиваются. Network counts и page action counts не суммируются в точное число запросов. UI, Pro и печать локализуют категории, endpoint/resource labels и подписи counts на всех 21 языках. Неподтверждённый provider unknown не повышает badge.

Permissions, CSP, внешние runtime-соединения и зависимости не расширяются. Активные проверки социальных аккаунтов/истории/XS-Leaks, блокировка, подмена таймеров и чтение результатов авторизации не добавляются. Предложения приложенного текста сопоставляются с реальным покрытием; ложное приравнивание image request к top-level navigation и SDK к статусу аккаунта не переносится в код.

## Приёмка

Проверенные артефакты: source ledger, canonical enum parity, positive/negative endpoint fixtures, hostile options/Proxy/native semantics, доверенные маршруты и consent/scope/races, browser-only fallback, bounded Pro capture/overflow, полный admitted report, 21-language parity и native Chrome/Firefox loopback fixtures. Независимый reviewer проверил причинные выводы, false positives и UI. Изменённый hot path измерен. Фактические команды, source hashes и архивы: итог выпуска, независимое review, [покрытие](../coverage/social-networks.md).

Последовательный trusted read сразу после просмотра Social Networks занимает единственный pending slot и ждёт окончания прежнего интервала 500 мс. Timeout ответа 400 мс начинается после отправки; следующий интервал отсчитывается после завершения. Pagehide отменяет ожидание, pre-post сообщения не допускаются, проверки актуального доступа остаются в privileged observer. Это устраняет воспроизведённую потерю первого Pro admission при немедленной остановке записи; лимиты и число одновременно ожидающих запросов не увеличены.

По отдельному решению владельца продукта исправлена узкая верстка. При screen container ≤640 px существующие четыре ячейки отображаются карточкой, с localized labels и explicit table semantics; ≤400 px подписи располагаются над значениями. Wide/print остаются таблицей. Контракт, данные и counts не меняются. Фактическая независимая matrix92cases и native Chrome/Firefox результаты: отчёт исправления.
