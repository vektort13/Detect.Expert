# ADR-086 — Storage Custom: ранее сохранённые объекты других окон

> Уточнено [ADR-106](ADR-106-antidetect-continuation.md): охват расширен на `StorageBucket` и deprecated `webkit*Storage` (раздел 6); поиск окон ADR-086 переиспользуется для их реестра.

Дата:31.10.2026. Прямое решение владельца продукта «фикси» для ограничения ADR-085:
genuine StorageManager из другого Window, не прошедший getter-регистрацию,
отклонялся. REQ-002/003/004/005/010/011/012/015, ADR-048/049/084/085.
Артефакты: внутренний отчёт.

## Проблема и доверенная проверка

Менеджер мог быть сохранён до включения Custom, взят в независимом same-origin
окне или borrowed call мог использовать метод другого realm. Успешная установка
Navigator.storage getter не означает, что каждый genuine manager уже прошёл
его обёртку. Прежний getterHooked shortcut ошибочно отклонял такой объект.

StorageManager не предоставляет стандартного brand-only getter. estimate,
persist, persisted и getDirectory выполняют операции, а instanceof/prototype/
toStringTag допускают подделку. Новый код не использует их для аутентификации.
Native [NavigatorStorage.storage](https://storage.spec.whatwg.org/#navigatorstorage)
возвращает SameObject identity, а captured Window.navigator getter работает на
genuine same-origin Window. Native Window.document getter проверяет Window
brand и SOP до обращения к дочерним свойствам.

## Решение

1. Registry hit в private WeakMap остаётся прежним быстрым путём. Для unknown
   receiver выполняется только ленивое сравнение identity с manager,
   возвращённым captured native Window.navigator и Navigator.storage getters.
   Установка не читает navigator/storage и не вызывает estimate/backend.
2. Первый доверенный ранний installer сохраняет pristine native accessors.
   Поздние чужие globals/own getters/конструкторы не становятся источниками
   исполняемого кода для проверки. Own data Navigator допускается только через
   captured pristine native Storage getter. Если transferable Window.navigator
   getter отсутствует, поздний foreign accessor не вызывается вместо него.
3. За один фактический вызов estimate допускается bounded обход parent/top/
   opener и indexed child Windows, а также ранее известных Window hints.
   Native document brand+SOP gate предшествует any indexed descriptor read.
   Только indexed data values учитываются; page/named accessors игнорируются.
   Profile install/protect/inherit для обнаруженного окна не вызывается.
4. Window hints хранятся через captured WeakRef при его наличии; мёртвые slots
   могут переиспользоваться. Без WeakRef fallback bounded strong references.
   Caps:1024 Window hints,1024 кандидата на поиск,4096 child-edge inspections.
   Прежний manager registry cap1024 сохраняется. Только exact matched receiver
   добавляется в manager registry; failed guesses его не заполняют. Negative
   cache отсутствует, новый Window/Navigator или доступность проверяются снова.
5. При активном Storage Custom Window.open дополнительно пассивно запоминает
   возвращённый genuine Window через captured native self brand. Original
   вызывается один раз с прежними this/arguments; результат, throw и readonly/
   nonconstructable semantics сохраняются. Navigator/storage при open не
   читаются. Это позволяет искать отдельный popup без frame-tree связи.
6. Navigator.storage wrapper сохраняет original getter call/return/throw.
   Результат позднего отличающегося getter регистрируется только после совпадения
   с pristine native storage getter на том же genuine Navigator. Это не даёт
   странице записать fake/Proxy в private authenticated registry.
7. После успешной проверки возвращается прежний ADR-085 virtual selected
   snapshot. Выбранные значения и публичные Promise/Object prototypes принадлежат
   realm метода. Настройки и descriptors чужого окна не меняются: явный borrowed
   вызов Custom функции не включает Custom для остальных операций чужого окна.
8. Invalid/fake/Proxy/revoked/unknown receiver по-прежнему передаёт captured
   estimate только private invalid sentinel, не сам receiver. Native brand
   rejection возвращается без native quota operation. Аргументы не исследуются,
   public Promise species/then для скрытого quota Promise не добавляются.
9. Уже аутентифицированный manager остаётся допустимым при detach/navigation
   или закрытии исходного окна, пока сам manager удерживается. Stop сохраняет
   прежнюю ownership-safe очистку; future retained calls делегируют original.

Это узкое продолжение Storage исключения ADR-085. Нет новых permissions/CSP,
wire/schema/privileged каналов, telemetry, внешней сети или data-pack. Не
изменяются Protect, другие Custom API и общие Promise/Object prototypes.
Обёртка Window.open может быть наблюдаема, Function.toString masking не вводится.

## Строгая граница

Невозможно безопасно распознать произвольный genuine manager из уже недоступного
окна/старого документа, если он никогда не был аутентифицирован и ни одна
доступная pristine Navigator identity ему больше не соответствует. Его
prototype/tag не заменяет brand. Нельзя выдавать universal acceptance.

Native persisted() не выбран как запасной oracle: это дополнительный backend
запрос, способен отвергать genuine manager и выполняет Promise species при
подписке. Он не даёт универсальной совместимости и загрязнял бы наблюдение
запросом, которого страница не делала. getDirectory/persist/estimate также не
используются для обнаружения. Caps, opaque/cross-origin и отсутствующие getters
остаются fail-closed; исходная quota не возвращается.

## Проверки

RED сохранённого f39 и GREEN actual installer: cached own/child/popup managers,
borrowed methods с разными selected значениями/realm, поздние poisoned globals,
data/accessor/deleted storage, отсутствие API, fake/Proxy/unused arguments,
scope OFF, ownership/stop, native Navigator смена, negative-cache отсутствие,
1024 caps и4096 edges. Native Chrome/Firefox проверяют transferable accessors,
SOP/Proxy, lifecycle OFF document → fresh Custom frame/popup и сохранение чужих
descriptors. Native component считает successful quota attempts и непрошенные
backend calls; прежние FP-12/13 и B1 остаются закрыты. Общие unit/privacy/build,
source/dist/ZIP и независимый review обязательны; результаты в отчёте задачи.
