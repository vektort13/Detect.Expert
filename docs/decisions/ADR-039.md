# ADR-039 — полнота технических значений в Pro и сводных таблицах

2026-10-10. Прямое решение владельца продукта: отдельные сводные таблицы
«№ / имя / значение» для всех посещений, включая дочерние и сторонние
документы; алфавитный порядок, 12 pt, начало с новой страницы.
REQ-002/004/005/009/011/012/013/015; дополнение к ADR-017/036/037.

Расширяется только явно запущенная локальная Pro-запись. Light и PageBatch
не получают новые значения. Permissions, CSP, зависимости, сетевые запросы
самого расширения и политика блокировки не меняются.

Вместо общего `unobserved:object` для фиксированных технических API
сохраняется проверяемый профиль `technical`: языки, параметры Intl,
геометрия, TextMetrics, расширения WebGL, plugins/mimeTypes, UAData.
Поля имеют фиксированные имена, индекс, примитивный тип и значение.
Проектор использует захваченные native getters и собственные data
descriptors известных результатов; произвольная сериализация объектов,
итераторы и преобразование чужих объектов в строку не добавляются.
Оригинальная функция вызывается ровно один раз, возвращаемая ссылка,
исключение и Promise сохраняются. Обработчики к чужим Promise не добавляются.
Текст, переданный в measureText, не сохраняется.

Новый независимый `page.requestValues` содержит фактически отправленные
технические заголовки браузера, которые сообщил `webRequest.onSendHeaders`.
Allowlist фиксирует 38 имён: UA/Client Hints, Accept, предпочтения языка,
сжатие, DNT/GPC и Sec-Fetch. Нет wildcard; неизвестные заголовки,
Authorization, Set-Cookie, произвольные тела и полные URL не читаются.
Cookie остаётся отдельным каналом ADR-037. Источник и назначение проверяются
native document binding, текущим scope, consent, generation и временем
записи. Pending navigation подтверждается native commit, а не доменом.
При недоступной authoritative network document identity канал unsupported.

Ограничения технического профиля: 128 полей / 8 KiB; исходные ограничения
API Pro сохраняются — 256 вариантов / 64 KiB на документ. Request values:
256 строк / 256 KiB на посещение, отдельное значение до 4096 символов,
очередь навигаций 32 записи / 128 KiB / 10 секунд. Все данные включаются
в существующий общий бюджет Pro. Превышение фиксируется явно; оно не
превращается в выдуманное значение. Stop/reset/revoke прекращают запись.
Поздний ответ сенсора проверяется по control epoch после каждого await.
Resume повторно запускает сбор для возобновляемого документа до ответа UI,
в пределах существующего deadline; остальные документы не сбрасываются.

Сводка строится непосредственно из сохранённых apiValues всех документов,
requestValues и конкретных декодированных полей browser-network маячков.
Отсутствие карточки техники не скрывает уже записанное значение. Массивы
и структурированные результаты раскладываются на строки отдельных полей.
Все разные пары имя/тип/значение сохраняются; точный повтор не дублируется.
Metadata counters, попытки, нормализованные permission enums и признаки
наличия идентификатора не выдаются за переданное значение. Cookie-сводка
использует исходящие значения ADR-037, а не текущий cookie jar.

Сводные таблицы следуют за титульной страницей; каждая начинается с новой
страницы. Подробные таблицы, привязки документов, компании с локальными
логотипами и социальные сервисы следуют отдельным разделом. Preview и PDF
используют одну проекцию. На таблицы не накладывается второй UI row limit.
Старая запись не заполняется данными, которые не были собраны во время неё.

Проверки: canonical/adversarial/lifecycle unit suites, независимое review
другим инженером; реальные Chrome и Firefox fixtures и проверка текста,
размера шрифта и пагинации PDF. Фактические результаты и hash сборок
фиксируются отдельно в release evidence после завершения проверок.
