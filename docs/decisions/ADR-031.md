# ADR-031 — вызовы и состояние фоновых механизмов сайта

2026-10-09. Явное решение владельца продукта реализовать второй этап. REQ-002/004/005/009/010/011/012/013/015; DET-063/073; ADR-006/018/025/028.

## Решение

Пассивно наблюдаем ServiceWorkerContainer, PushManager, SyncManager, PeriodicSyncManager, Notification.requestPermission. Native original вызывается ровно один раз с исходными this/args/result/throw и Promise identity. Обработчики не добавляют then/catch к Promise страницы, не читают её произвольные init options, subscription или task tags.

Кнопка проверки состояния выполняет отдельную read-only диагностику текущего origin в ISOLATED realm: getRegistrations, getSubscription, getTags и Permissions.query. Pro-запись является явным включением захвата этой metadata. Диагностика не регистрирует worker, не подписывает Push, не запрашивает permission prompt, не отправляет события и не отменяет задачи. Локально вызванные диагностические Promise можно ожидать; они не являются Promise приложения.

В проекции только поддержка API, фактическое состояние разрешений, количества registrations/subscriptions/tags, нормализованные scope/script и worker state. Push endpoint, auth/p256dh, subscription JSON и tag names исключены. checkedAt отличает состояние проверки от текущих вызовов. После await повторно проверяются identity, consent и access generation. Capability, registration и фактическое выполнение остаются разными событиями; внутренние worker callbacks и выполнение после закрытия вкладки этим наблюдателем не записываются.

## Приёмка

Semantic/privacy/adversarial fixtures, native current-origin регистрация на loopback, Firefox unsupported Sync/Periodic, permission state, pause/revoke/navigation race, independent review. Permissions/CSP/debugger allowlist не меняются.

Нативная приёмка Firefox 138 обнаружила отсутствие ServiceWorkerContainer и связанных интерфейсов в trusted ISOLATED при работающей регистрации MAIN. В этом случае inventory остаётся unsupported с неизвестными counts; UI показывает недоступность проверки и сохраняет page calls. Отсутствие API в контексте проверки не является browser/site capability verdict. Native global lookup поддерживает inherited data descriptors и проверенные native getters, не исполняя произвольные getters. Privileged MAIN fallback и включение extensions.serviceWorkerRegister.allowed не применяются; [Mozilla ServiceWorkersEnabled](https://github.com/mozilla/gecko-dev/blob/master/dom/serviceworkers/ServiceWorkerUtils.cpp) подтверждает ограничение addon/expanded-addon principal.
