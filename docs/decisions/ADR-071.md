# ADR-071 — Proxy Manager: проверки профилей и полный JSON

2026-10-21. Прямое дополнительное решение владельца продукта: сделать менеджер сохранённых proxy по визуальным примерам, показывать тип, проверять соединение/доступность и иметь кнопку копирования JSON со всей информацией, включая конфиг, логины, пароли и настройки. Это разрешение на конкретный полный экспорт, в дополнение к metadata-only download ADR-070.

## Решение

Основной Profiles view становится компактным manager со строками на desktop и карточками на узких экранах: имя/адрес, цветной protocol badge, active state, результат последней ручной проверки, время/IP при наличии, row actions и поиск/фильтр/сортировка. Отсутствие проверки отображается как «не проверен»; online означает результат конкретного запроса, не непрерывный мониторинг. Страна, оператор, срок аренды и uptime не придумываются.

Check одного или видимого списка выполняется только пользователем. Native profile проверяется через временный helper/loopback, без изменения browser routing/config/revision или текущего local active tunnel. Тот же активный профиль использует существующий tunnel. Другой OpenVPN при активном OpenVPN возвращает active-vpn: сервер без duplicate-cn может разорвать прежнее соединение с тем же сертификатом. Расширение само не отключает активное подключение. Произвольные ограничения удалённого провайдера не считаются наблюдаемыми локально. Проверка direct SOCKS использует строго сохранённый endpoint; URL только в RAM. Batch последовательный, ограниченный существующим лимитом профилей, прекращается после ухода из раздела; уже начавшаяся native операция завершается физически до снятия общего lock.

## Полный JSON и clipboard

Copy одного/всех создаёт детерминированный `detect.expert.proxy.bundle`, version1: revision, selectedId/включённость для включённых в bundle профилей, routing, protectWebRTC, disablePrediction, autoConnect, killSwitch и profiles в сохранённом порядке. Каждый профиль содержит metadata и connection с полной typed конфигурацией. Native op export читает vault без записи; IDs уникальны, все существуют, неизвестные поля и cross-op параметры отвергаются. Большие коллекции читаются отдельными bounded native кадрами под одним физическим lock; агрегат ограничен 32MiB. При ошибке частичный результат не выдаётся.

Full secret response проходит только точному собственному top-level Options по его pending request. Нет broadcast, snapshot, status, storage, console, error-text или site report с secret JSON. Собственные страницы и content scripts без нужного sender не получают export route. UI не помещает bundle в Preact state/DOM: сериализация и запись clipboard выполняются локально, затем ссылки/промежуточные объекты очищаются; immutable JS строки не объявляются гарантированно обнулёнными в heap. Скрытие/уход и поздний permission grant прекращают выдачу/запись. Ошибки clipboard фиксированные, без фрагмента JSON. Уже выполненный clipboard write — именно результат прямой команды пользователя, его не заменяют фоновым автоочищением буфера.

Добавляется optional `clipboardWrite` для Chrome/Firefox, без clipboardRead, CSP или host permission изменений. Разрешение запрашивается синхронно в исходном click; оно нужно, чтобы `navigator.clipboard.writeText` работал после асинхронного чтения DPAPI/native ответа. Для metadata-only/direct профилей nativeMessaging не запрашивается зря. Обязательные manifest permissions исключаются из permissions.request: Firefox отклоняет запрос required-only разрешения. Primary sources: [MDN WebExtensions clipboard](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/Interact_with_the_clipboard), [Chrome permission list](https://developer.chrome.com/docs/extensions/reference/permissions-list).

## Review и проверки

Обязательны independent native boundary/privileged response review; all-or-nothing export, отсутствие secret broadcast/storage/error output; check success/failure при неизменном активном tunnel/browser route; cleanup временного child; строгие request/result allowlists и размеры; stale/hidden action и permission rejection; реальная clipboard запись через UI Chrome/Firefox в disposable fixture без clipboardRead production permission; 21 локаль, RTL/dark/narrow и финальные source/dist/archive hashes. ADR-070 DNS/Kill Switch и password privacy остаются обязательными.
