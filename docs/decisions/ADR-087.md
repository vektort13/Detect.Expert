# ADR-087 — расширяемые Custom fingerprint profiles

31.10.2026. Прямое решение владельца продукта: сделать изменяемыми fingerprint
поверхности из приложенного списка. Продолжение ADR-048/049/065/066/084–086.
REQ-002/003/004/005/010/011/012/015. Задача:
внутренний отчёт.

## Изменение продукта

Пятнадцать явных Custom bundles добавляются в существующую конфигурацию:
Navigator supplementary metadata; Plugin/MIME metadata; screen/window geometry;
CSS media и supports; Intl formatting; WebGL parameters/extensions; WebGPU
limits/features; Canvas TextMetrics; Audio readback; Audio metadata; clock
precision; Canvas font policy; optional browser feature exposure; WebGL readback.
Каждое значение редактируется/сохраняется прежним API UI и переносимым JSON.
Math дополнен sqrt/cbrt/hypot с сохранением специальных и точных случаев.

Формат6/catalog7 сохраняет строгие исторические catalogs1–6 и принимает прежние
валидные format1–5 данные через проверяемую миграцию. Режимы, оба независимых
masters, пользовательские значения, site overrides и library profiles не
теряются. Новые строки при миграции BYPASS/unset, автоматического включения нет.
CAS revision и privileged sender проверки прежние. Схемы сетевых/MAIN сообщений
и канонические detector enums не меняются.

## Разрешённая семантика

- Только существующие API; отсутствующие native interfaces, физические устройства,
  GPU features, executable plugins и codecs не создаются.
- Plugin/MIME выбранные записи — виртуальные metadata collections с публичными
  target-realm prototypes, private identity registry, стабильными индексами,
  named properties, iterator/item/namedItem и enabledPlugin links. Это не
  установка плагина. Native Navigator getter сохраняет brand/throw и вызывается
  один раз. Прямой сохранённый native method может отвергнуть virtual record;
  маскировка этого различия не вводится.
- Основной native method/getter вызывается один раз с прежними this/arguments,
  если ниже не указано конкретное исключение. Native errors сохраняются.
  Coercion пользовательских аргументов не повторяется для выбора метаданных.
  Значения результата выбираются только из локального валидированного JSON.
- Intl Custom вызывает requested native constructor один раз с исходными
  аргументами и сохраняет validation/option getters/errors. После успеха
  разрешена вторая private native конструкция из захваченных primitive
  resolvedOptions и выбранного locale/zone/calendar/numberingSystem. Возвращается
  настоящий formatter с выбранными native slots и исходным result prototype;
  format/parts/range/compare согласованы. Legacy chain-call identity сохраняется
  и не выдаётся за переинициализацию native slots. Старый timezone metadata hook
  не переписывает resolvedOptions нового Intl formatter.
- Canvas font policy сначала пропускает исходный native font setter, затем
  разрешает второй native setter для нормализованного выбранного списка семейств.
  Это меняет последующее настоящее Canvas drawing/measurement; DOM stylesheet,
  установленные ОС шрифты и сетевые font assets не меняются. Новые загрузки шрифтов
  и самостоятельное рисование/измерение не запускаются.
- AudioBuffer readback допускает bounded in-place идемпотентную проекцию finite
  Float32 samples в пределах выбранной amplitude. Silence, NaN/Infinity и
  subnormal сохраняются. copyFromChannel изменяет только фактически скопированные
  frames; padding/tail не меняются. Coercive/over-limit формы удерживаются без
  возврата исходного readback. Выбранные sampleRate/latency — metadata; duration
  AudioBuffer согласуется с его неизменным length и выбранным sampleRate.
  Уточнено ADR-104 (дополнение 2): выбранная sampleRate отдаётся только
  экземплярам AudioContext/webkitAudioContext, созданным без аргументов;
  OfflineAudioContext, AudioBuffer.sampleRate/duration и явная частота остаются
  native (иначе duration расходится с настоящим буфером). Предел проекции —
  2^26 samples, seed шума включает origin документа.
- WebGL/WebGPU capability metadata не создаёт capabilities. Extensions/features
  фильтруются пересечением с native, numeric maxima не повышаются, alignment
  minima не улучшаются. Actual rendering и устройства используют native backend.
- WebGL readPixels допускает original call один раз с private destination,
  затем копирование только покрываемых RGB/alpha участков в caller destination.
  Для правильного PACK layout/default framebuffer допускаются bounded captured
  native readonly pipeline-state queries по фактическому readback страницы.
  Это не самостоятельный render/fingerprint probe. getError не вызывается:
  очередь ошибок приложения не потребляется. PBO/shared/coercive/unsupported
  framebuffer/format/over-limit случаи удерживаются до native read. No-write
  или context-loss не позволяют копировать private sentinel/native bytes наружу.
  Лимит4MP и16MiB packed span. Полное совпадение результата с private sentinel
  остаётся conservative unknown; native bytes не возвращаются как fallback.
- Clock precision уменьшает точность reported Performance.now, Date.now и RAF
  timestamps. Планировщик, реальная производительность/JIT/GC и скорость CPU/GPU
  не эмулируются. Callback this, handle/cancellation и stop сохраняются.
- CSS.matchMedia/CSS.supports — выбранная JavaScript metadata projection.
  Реальные stylesheet/layout, CSS parser, font engine и native event scheduling
  не объявляются заменёнными. Browser exposure может скрывать только явно
  выбранные существующие configurable/writable optional surfaces.

## Прежние границы

Нет Function.toString/bind/native-source masking, поддельных function hashes,
скрытия самого инструмента, инъекции произвольного кода, Worker script URL
rewriting или эмуляции parser/WASM/JIT/GC/TLS. Стандартные JS constants и точная
арифметика не становятся произвольно выбираемыми значениями. Document MAIN
userScripts не означают универсальное раннее выполнение в Worker.

Нет новых permissions/CSP/host grants, debugger-команд, dependencies, privileged
каналов, telemetry, upload, удалённых пакетов или соединений продукта. Protect,
password/OTP boundaries, Firewall и detector thresholds не меняются. Продукт не
выдаёт эти настройки за полную замену браузерного движка.

Pixels, samples, измеренные значения, SDP/IP, реальные устройства и их хеши не
попадают в bridge/storage/export/logs. Только выбранные пользователем значения
сохраняются в прежней локальной конфигурации. Результаты тестов — booleans/counts
и synthetic fixtures. Native probe артефакты отдельно показывают отсутствующие
API, semantic limits и known engine boundaries.

## Проверки

Closed schemas, historical-domain/metadata pins, lossless migration global/site/
library, native brand/Proxy/coercion/errors, target prototypes, iteration/index
coherence, stop/ownership, repeated/offset/zero-length readback, GL padding/error
state, Audio copied-tail и early inherited realm cases. Нужны независимый review,
реальные Chrome/Firefox тесты, прежние Storage FP-12/13, общие unit/privacy/build
и побайтовая сверка native-tested source/dist/ZIP. Точный статус каждого из280
ключей хранится в coverage; совпадение одного хеша не заменяет semantic proof.
