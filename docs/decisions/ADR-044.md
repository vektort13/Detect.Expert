# ADR-044 — удаление DBSC

2026-10-10. Прямое решение владельца продукта: «Убираем DBSC».
REQ-004/010/013/015. Заменяет DBSC-часть ADR-027 и ADR-040.

Дополнение 2026-10-30: [ADR-075](ADR-075.md) по прямому выбору владельца разрешает отдельное применение Chrome Debugger для встроенного Автосерфера. Удаление DBSC, его каналов и UI по настоящему ADR сохраняется.

Удалены Chrome CDP controller, разрешение `debugger`, privileged DBSC routes,
подписки и lifecycle, кнопки запуска/остановки, статусы и колонка DBSC/TPM
в Cookie и Pro-отчёте. Удалены соответствующие строки всех 21 локализации.
Остаются два пакета 1.1.0: Chrome и Firefox с общей кодовой базой.
Минимальная версия Chrome 153 сохранена как проверенная граница продукта.
Cookies остаётся optional permission; CSP, host permissions и зависимости
не расширены. Контроллер не подключается к браузеру ни при установке,
ни при обновлении, ни по устаревшим сообщениям UI.

Совместимость сохранённых данных: `sessionBinding` и `boundSessionStatus`
допускаются только как необязательные own data properties старых snapshots.
Canonical reader удаляет их из результата. Полная валидация Pro, восстановление
записи и UI state response возвращают нормализованные cookie metadata.
Обычные cookies, классификация, значения, очистка, восстановление идентификатора,
социальные сервисы и остальные Pro-поля сохранены.

DET-074 продолжает считать наличие разрешённых имён response headers;
этот общий пассивный канал не запускает DBSC и не сопоставляет cookies с сессиями.
Новые сенсоры, сети, сигнатуры и пороги детекторов не добавлены.

Проверки: `scripts/test/dbsc-removal.test.mjs`, обновлённые Cookie/UI/manifest
регрессии, полные unit/typecheck/lint, две release-сборки, native Chrome/Firefox
Cookie/Social/Pro и Chrome automatic observation. Фактические результаты и
SHA-256: журнал приёмки 1.1.0, поле `dbscRemoval`.
Независимое ревью: внутренний отчёт.
