# Production «Защита»: исправления аудита 2026-10-20

Основание: ADR-047/050, F1…F8 из внутреннего отчёта. Итоги команд и артефакты — FIXES.md. Исходный `vendor/protect-722fae8` остаётся вендорной копией (код не менялся); production-исправления подключаются явными redirects сборщика.

## Чтение полей

Reader допускает только живое поле собственного документа с подтверждённой историей наблюдения. Открытые/закрытые shadow controls, чужой realm, отсоединённые и неотслеживаемые поля не читаются. Известные переходы типа сохраняются при временном отсоединении поля; мутации, ещё не доставленные callback, синхронно извлекаются до проверки.

Платёжные поля ищутся в light DOM и достижимых вложенных открытых shadow roots. Неполный обход, превышение node/root/control бюджета или ошибка observer запрещают чтение. Это ограничивает покрытие на больших формах и shadow-компонентах. Закрытые shadow roots невозможно перечислить; находящиеся там платёжные поля не обеспечивают document-wide suspension. Значения самих закрытых shadow controls отклоняются.

Историю до начала наблюдения восстановить нельзя: например, detached password, ставший text ещё до первого появления в наблюдаемом документе. Тесты не объявляют такой случай покрытым. Проверенная граница — известная история и запрет чтения из неотслеживаемых корней.

## Тела запросов

Неразобранный/усечённый JSON не передаётся в plaintext tokenization; запрос исключается из reverse-match ring. Без успешного структурного разбора credential pruning не объявляется выполненным. Непрозрачность и усечение обозначаются существующими limitations.

formData расходует общий 64 КиБ UTF-8 бюджет на ключи и допускаемые значения. Credential-значения пропускаются до обращения к ним, включая чтение длины. Перебор и копирование больших строк ограничены префиксом. Счётчики отражают исследованные ключи/значения, а не сетевой multipart overhead. Усечённые запросы, в том числе по числу токенов, не удерживаются в кольце.

## Уведомления, политики и gates

Возврат фокуса окна повторно оценивает ожидающую активную вкладку. После асинхронных browser calls surfacer повторно проверяет active/window/focus и актуальный prompt до расходования дедупликации и открытия. Сохраняются группировка и один popup на окно за 10 секунд.

Chrome-пакет объявляет `ProtectModuleDisabled:boolean` через `storage.managed_schema`. true останавливает активный модуль и запрещает включение; false/отсутствие не включают модуль без пользовательского согласия. Проверка ОС использует только случайный ID временной тестовой копии; временные ключи удалены. Firefox получает прежние инертные stubs без этой схемы.

`test:privacy`, `test:extension`, `test:production`, `release:verify` включают нативный production privacy gate. Инструментация добавляется только в тестовую копию готовых бандлов. Независимые labels и положительные контроли исключают прежнее ошибочное толкование нулевого tripwire. Сохраняются старые тесты наблюдения.

Исходная спецификация защиты находится в ADR-020-protect с сохранённым историческим статусом. ADR-020 карты Pro не заменён; текущие правила порта и review описывает ADR-047.
