# Firewall Options — inline настройки

Обновление 2026-11-01: отдельное подтверждение включения удалено по [ADR-098](../decisions/ADR-098-direct-firewall-activation.md). Enable напрямую использует прежний протокол; disabled previews и активные настройки сохраняются. Ниже описано исходное состояние ADR-062 и его исторические проверки.

Реализовано по [ADR-062](../decisions/ADR-062.md), E22-15. Фактические проверки.

На странице Options настройки пяти функций и трёх режимов видимы при OFF как disabled gray controls. Первичное согласие — inline-секция с прежними семью блоками и обязательным checkbox; Cancel не пишет настройки. Активная функция блокировки использует прежнюю форму режима, выключенная — disabled preview. Сохранённые данные и их доступность подчиняются прежним VM/backend. Текст/версия/digest согласия, сбор ввода, permissions и sender-пути не расширяются.

Покрытие: actual TSX8, native UI15/64 снимка, management8, обязательная privacy7 и overlay11, typecheck/lint/unit3471, обе сборки. Нативные ошибки разрешений/managed UI ветки частично проверяются через явные controlled fixtures; доставка корпоративной политики через ОС в этой задаче не проверялась. Launcher popup/sidepanel сохраняют прежний первый consent dialog. Firewall не поставляется в Firefox. Историческое pixel/perf baseline-сравнение без явно переданного пакета остаётся pending; новый perf-бенчмарк не заявляется.
