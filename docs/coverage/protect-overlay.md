# Уведомления Firewall внутри страницы

Актуальное решение — [ADR-058](../decisions/ADR-058.md), задача E22-09. Автоматические отдельные окна ADR-052/054 заменены popup в правом нижнем углу текущего HTTP(S)-документа. Системного заголовка/окна Chrome больше нет. Используются собственные логотип, заголовок и ×, закрытое дерево стилей, светлая/тёмная/forced-colors палитры и адаптивная ширина. Фокус при показе сохраняется.

Условия положительных находок сохраняются: актуальный включённый документ, соответствующая функция, value-match с кодировками либо оценённый положительный replay. Только ввод, password listener, opaque-after-input и replay none/signals-only сами popup не создают. Подтверждение успешного явного включения — отдельный вид уведомления на пять секунд после появления содержимого; восстановление ON, no-op, отказ и отмена согласия его не создают.

При временной потере native focus из-за меню расширения подтверждение ожидает исходный документ до пяти секунд. Переход в другую вкладку, навигация и OFF отменяют ожидание. Если фокус не вернулся вовремя, короткое подтверждение не показывается; состояние Firewall от этого не меняется.

Повторные события обновляют существующую карточку. Закрытая находка по тем же семантическим признакам не появляется из-за счётчика/evidenceId. Навигация, OFF, исключение/пауза, политика и отзыв прав учитываются SW и самим UI. После SW restart старый generation больше не может изменять правила; карточка закрывается по ограниченному refresh/изменению состояния. Сохранённые исторические findings не показываются как новые.

Внутри popup доступны только текущие once-решения и Undo собственных once-решений. Постоянные правила и общая пауза подтверждаются на собственной странице расширения с реальной актуальной карточкой; кнопка настроек открывает прежнее единое управление. Проверки производятся по native MessageSender/documentId/frame 0 и текущему prompt/revision/receivers. MAIN-сообщения не перенаправляются, а nonce/generation не считаются аутентификацией.

Лимиты: 64 документа, 128 dedup-ключей на документ, 1024 суммарно; native await/ACK ограничены тремя секундами. Отложенный SHOW не восстанавливает отозванный generation. Данные карточки остаются редактированной проекцией, без введённых значений и их производных. На внутренних/недоступных страницах браузера popup не показывается; доступ к сайту не расширяется ради UI. Сайт способен удалить или перекрыть свой UI-host. Сетевую блокировку подтверждает backend, а не внешний вид карточки.

Оболочка и новое сообщение подтверждения постоянных действий имеют 21 локаль; подробные унаследованные тексты модуля сохраняют RU/EN. Firefox-модуль остаётся stub по ADR-047. Нативное достижение положительного replay в production не заявляется; его прежняя UI fixture-проверка отделена от действительных transfer-сценариев.

Актуальная приёмка: `scripts/test/protect-overlay-native.mjs` и обязательный production privacy gate. Отчёт — внутренний отчёт. Прежние standalone window-страницы остаются для совместимости и доверенного review; automatic delivery их не создаёт.
