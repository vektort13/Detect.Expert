# Переключатель Firewall

Production Chrome, ADR-053, 2026-10-20. Название Firewall и соседний индикатор On/Off переключают модуль на текущей поверхности. Переход в настройки убран; настройки модуля остаются доступны в Options.

По прямому решению владельца продукта от 2026-11-01 [ADR-098](../decisions/ADR-098-direct-firewall-activation.md) убирает дополнительный диалог и inline-подтверждение. Клик сразу вызывает прежний enable. Сохранённые непустые функции и preset восстанавливаются; для первого включения/пустого набора используются прежние value-match, firewall, session-replay и normal, без history/GPC. Выключение сохраняет настройки, исключения и постоянные данные; временные данные сеанса очищаются прежним контроллером. Открытие UI и обновление состояния модуль не включают. Версия/digest и авторизация backend не меняются; штатные native permission prompts сохраняются.

При загрузке, недоступности, запрете организации и выполнении операции кнопки блокируются. Интерфейс показывает фактический ответ controller; ошибки сохранения не изображаются успешным переключением. После двух отказов записи OFF текущий SW остановлен и показана ошибка, но сохранение OFF между перезапусками при полном отказе storage не гарантируется.

Подписи действий и общая ошибка переведены на 21 язык. Подробные сообщения сохраняют RU/EN. Firefox по ADR-047 получает inert stub без Firewall; изменение не добавляет его поддержку. Верхняя панель языка/настроек/пина имеет высоту 30 px в Chrome и Firefox. Текущая проверка: direct activation.

Доказательства и ограничения проверок: отчёт.
