# Единый интерфейс управления — ADR-055

Основные разделы доступны в одном `options.html`: Antidetect, Автосерфер, Cookies, Proxy, API Guard, Detector, Firewall, Настройки, Контакты. По решению от 2026-10-21 Browser Debug открывается через отдельный пункт внутри «Настроек». Сохраняется прямой #browser-debug и кнопка возврата, основной активной вкладкой остаются «Настройки». Отдельные optional permissions и границы данных описаны в [покрытии Browser Debug](browser-debug.md). Вкладки меняют hash без перезагрузки документа. Посещённые панели сохраняют основной draft API, поиск и Undo; скрытый контент исключён из обычной клавиатурной навигации. Открытые диалоги при внешней смене hash закрываются через прежний Cancel без сохранения.

Старый API URL перенаправляется в канонический документ с исходным query. Ссылки на историю, журнал и правила Firewall сохраняются. Подробный интерфейс Firewall использует прежние RU/EN тексты; общая панель навигации локализована на всех 21 языках. В Firefox Firewall по-прежнему отсутствует, а его вкладка показывает состояние недоступности.

«Контакты» содержит предоставленные владельцем пять сайтов и десять социальных каналов: карточки с локальными иконками, переходом и отдельным копированием ссылки. Раздел использует общие темы, типографику и все 21 локализации; Clipboard API вызывается только по нажатию, буфер не читается. Подробности: [покрытие Контактов](contacts.md). Отдельные окна находок, решений Firewall и временного подтверждения включения сохраняют прежнее назначение.

Первоначальное изменение ADR-055 не расширяло покрытие API или детекторов и не меняло раннюю подмену, разрешения, приватность и авторизацию. Отдельное расширение Browser Debug ADR-063 добавляет только интерактивные собственные Options-пути и optional API permissions. Нативные проверки общей навигации: Chrome 8 и Firefox 4, все 21 языка, production privacy 7. Первоначальные результаты — во внутреннем отчёте; проверка пятой вкладки и итоговых сборок — в отчёте E22-16.

## Внутреннее меню — ADR-088, 2026-10-31

Внутреннее меню занимает всю ширину Options. При ширине от 1120 CSS px основная навигация находится слева; на меньшей ширине открывается кнопкой с состоянием `aria-expanded`. Она располагается в потоке документа, закрывается по Escape и при выборе раздела. Фокус сохраняется на видимом элементе при переходе через границу размера. Вложенные разделы Antidetect располагаются над редактором и переносятся на новые строки.

Формы и карточки используют доступную ширину, длинные таблицы прокручиваются внутри своих блоков, диалоги ограничены высотой viewport. На узких экранах и при низкой высоте панель сохранения Antidetect входит в поток страницы. На узких экранах и при coarse pointer управляющие кнопки имеют высоту не менее 44 CSS px. Повторяющиеся вводные абзацы убраны из внутренних заголовков; существующие действия, разрешения, ошибки, согласия и проверки ревизий сохранены. Во встроенных «Настройках» убраны информационные onboarding/inventory и повторное описание очистки; управление согласиями, областью наблюдения и очисткой остаётся.

Набор нативных проверок включает все восемь основных разделов и Browser Debug, одиннадцать размеров viewport от 320×568 до 3840×2160, настоящий zoom 100/125/150/175/200/250%, а также оконные 1024×768 и 1280×720 при 250%. Ширины телефонов и QHD/4K проверяются эмуляцией viewport в настольных Chrome/Firefox; проверки не означают испытание на физическом телефоне или отдельном физическом мониторе. Настоящий zoom подтверждается `tabs.setZoom/getZoom`, DPR и изменением CSS-размеров при неизменных CSS zoom и pinch scale. Точные результаты и снимки: отчёт.

Проверки диалогов включают Custom API, импорт и редактирование Cookies при 100% и 250%, доступность последнего элемента с прокруткой, клавиатуру, Escape/Cancel, отмену при переходе и возврат фокуса. При закрытии Cookies инициатор открытия запоминается синхронно, до временного отключения кнопок; собственная очистка черновиков сохраняется. Тесты имитируют отключение инициатора до выполнения passive effect и проверяют отмену отложенного фокуса.

В рамках завершённого ADR-088 внешнее меню возле адресной строки не менялось. Следующее решение ADR-089/ADR-090 добавляет общие темы в оба меню, три группы внутренней навигации, состояния шести модулей и Detector с прежним полным Inspector. Cookies, Settings и Contacts не имеют точек по уточнению владельца. Подробности и ограничения: [темы и единые разделы](interface-themes.md). Общие локализации, manifest, backend/runtime и исходники модуля «Защита» сохраняются; новые разрешения не требуются.

## Шапка раздела и экскурсии — ADR-111, 2026-11-07

У каждого из двенадцати разделов Options (Пульт, Detector, API Guard, Firewall, Antidetect, Автосерфер, Cookies, Proxy, Интеграции, Настройки,
Контакты, Browser Debug) есть своя экскурсия из 3–7 шагов (всего 49) и одна общая кнопка «Экскурсия» в строке шапки
([ADR-111](../decisions/ADR-111-guided-tours-and-header-actions.md)). Шаги подсвечивают настоящие части раздела и ничего не меняют: без `chrome.*`,
сообщений, разрешений и сети; единственное хранилище — `localStorage['ui-tour:v2']` страницы Options.

| Что | Где |
| --- | --- |
| Реестр шагов и селекторов цели (чистые данные) | `ui-tour-steps.js`; селекторы привязаны к панели раздела |
| Движок, состояние, кнопка и блок контрольного списка | `ui-tour.js` (`createTourEntry` → `TourButton`, `TourStart`) |
| Тексты (115 ключей × 21 язык) | `ui-tour-labels.js`, только Options |
| Место для кнопки оболочки (без импортов) | `ui-tour-slot.js`: оболочка Options регистрирует `TourButton`, заголовки, которые строятся и для popup/sidepanel (мастер-шапка, Detector), только читают его; popup, боковая панель, отчёт и фон движок и тексты не загружают (юнит-тест проходит по статическим импортам) |
| Кластер шапки, иконки-инструменты | `workspace-controls-ui.js`/`.css`, `workspace-tool-icons.js` |

Порядок кластера у inline-end строки: иконки-инструменты (Обновить, Экспорт), кнопка «Экскурсия», переключатель модуля; у раздела без переключателя
кнопка — последний элемент. Ниже 561 px подпись скрыта визуально (имя кнопки остаётся), кнопка 32×32; строка шапки не переносится при 340 px.
Заглушка 46×28 держит место переключателя Antidetect до его загрузки, поэтому соседние кнопки не прыгают. Firewall: шапку рисует модуль «Защита»
со своей копией Preact, поэтому оболочка передаёт его launcher не кнопку, а изготовитель `tourToolSlot('firewall')` (свойство `toolSlot`), и launcher ставит кнопку
средним ребёнком своей строки: заголовок → «Экскурсия» → переключатель 46×28 в DOM, на экране и для клавиши Tab (в RTL зеркально); без слота (popup, боковая
панель, Пульт) строка прежняя, из двух кнопок; в Firefox у модуля нет ни кнопки, ни команды палитры. Cookies: шапка у другого
издателя, кнопка приходит свойством `tourButton` и пока не рисуется; экскурсия доступна из палитры. Ctrl+K → «tour» ставит первой экскурсию текущего раздела.

Нативные проверки: `ui-tour-tabs-native.mjs` (кнопка в каждой шапке при 2576/1180/520/340 px, LTR и RTL, 21 язык, семь палитр, forced colors, все
12 экскурсий настоящими нажатиями клавиш, кнопки карточки (Далее, Назад, Готово, Пропустить) настоящей мышью, палитра, побочные эффекты, снимки в
`.tmp/ui-tour-header-screens`) и `ui-tour-native.mjs` (экскурсия Antidetect). По умолчанию они собирают копию из исходников (флаг `--dist` берёт готовую сборку).
Пределы: экранные чтецы не проверялись; 19 языков — машинный перевод без проверки носителями; шаги, зависящие от состояния (включённый Firewall,
загруженный список cookies), в состоянии по умолчанию проверены только там, где часть есть.
