# Автосерфер — область работы и проверяемые ограничения

ADR-078: поиск сайтов использует общие записи с независимыми фильтрами страны,
категории и трекинг-системы. Датированные связи каталога доступны локально;
они не доказывают наличие технологии во время текущего посещения. Основной
Inspector показывает источник и дату отдельно от наблюдаемых событий детектора.
Exact-host membership не переносится на www, поддомены или другие протоколы.
Страны новых строк назначаются только по точному HTTPS origin в закреплённом
CrUX snapshot; тематика и страна не угадываются по технологии или ccTLD.

REQ-001/004/005/010/011/012/013/015, ADR-075. Встроенный раздел после Cookie Doctor в общем окне управления.

## Подбор сайтов

Поиск систем расположен под заголовком «Трекинг-системы» и совпадает по ширине с «Название или домен» в той же логической колонке. Оба поиска используют общую двухколоночную сетку, а при ширине содержимого менее450px — одну полную колонку. Базовая высота input42px, прежний адаптивный минимум44px сохраняется; отступы и иконки согласованы. Поиск, фильтры и tab order не менялись. Native-проверки геометрии/локализаций: внутренний отчёт.

Панель выбранных сайтов сохраняет внутренние отступы12px по вертикали и14px по горизонтали, а счётчик — существующий структурный минимум36px. Общая типографика не сбрасывает его в min-width0. Поля, выбор, Clear/Add и граница200 не меняются. Проверка0/12/200, локализаций, RTL и семи масштабов: внутренний отчёт.

ADR-082: выбранные фильтры видны над категориями и снимаются по отдельности
или вместе. Несколько систем объединяют сайты по OR без повторов, остальные
условия пересекаются с выборкой. Сброс сохраняет выбранные сайты и черновик.
Отсутствующие темы сайтов не угадываются из систем. Проверки и сборки:
внутренний отчёт.

ADR-081: отдельная группа «Категории систем» фильтрует справочник систем и сайты
по шести сохранённым категориям технологий. Счётчики учитывают уникальные сайты
в выбранной стране/тематике и поиске. Несовместимая индивидуальная система
сбрасывается при смене категории; выбранные сайты и черновик плана сохраняются.
Нативная проверка Chrome/Firefox и результаты: внутренний отчёт.

По ADR-077 доступен локальный поиск по имени/домену, выбор страны аудитории
с настоящим SVG-флагом и двадцать цветных тем с собственными иконками.
Каталог основан на закреплённом CrUX snapshot; тематическая разметка проектная.
Страна не определяется по ccTLD и не означает юрисдикцию сайта. В UI показаны
фактические результаты, без обещания top-50 для каждой комбинации.
Выбор добавляет адреса только в текущий черновик, сохраняя ручные URL;
Добавление сайтов само не сохраняет и не запускает план. Save сохраняет без запуска;
явный Start при необходимости сохраняет текущий валидный черновик и запускает
именно принятую revision. Лимит 200 и ошибки проверяются атомарно.
Источники и лицензии поставляются в расширении. Проверки и измерения:
внутренний отчёт.

## Управление и переходы

Очередь до 200 пользовательских HTTP(S) адресов, последовательный или перемешанный порядок, воспроизводимый seed, случайная выборка, 1–5 циклов, внутренняя глубина 0–3. Время на странице 5–600 секунд, интервал между страницами 1–300 секунд, продолжительность прогона 1–480 минут. Поля проверяются в UI и повторно в SW. Три кнопки Play/Pause/Stop сохраняют действия Start/Pause/Resume/Stop: Play продолжает paused-прогон, а иначе запускает новый. Верхний единый ON/OFF вызывает те же Start/Stop; OFF не блокируется молча пустым или несохранённым планом. Некорректный план получает ошибку с фокусом поля. План сохраняется прежним CAS до Start строго с принятой revision; Save отдельно не запускает посещения. Нельзя начать зависимый этап после скрытия UI, unmount или более нового snapshot. Полные доказательства: внутренний отчёт.

Расширенный ввод работает в Chrome 153+ через required `debugger`. Создаётся собственное обычное окно и одна рабочая вкладка. Наведение — ограниченная плавная последовательность настоящих `mouseMoved`, прокрутка — `mouseWheel`. Обнаружение кандидатов выполняется фиксированной функцией в ISOLATED world с exact native documentId; события не отправляются через MAIN bridge. Адреса внутренних переходов ограничены тем же origin и фильтруются повторно в SW. Переход выполняется через browser navigation, без клика по странице.

В Firefox доступен редактор очереди и локальные отчёты; запуск расширенного ввода недоступен. Firefox manifest не содержит `debugger`.

Начальный пользовательский HTTP адрес может пройти подтверждённый браузером redirect на HTTPS того же точного hostname со стандартными портами 80→443. Другие cross-origin redirects приостанавливают прогон. Дальнейшие внутренние ссылки ограничены конечным origin. Потоки случайных чисел для времени, движений и выбора ссылок независимы и воспроизводимы по seed и позиции посещения.

## Прерывание и восстановление

Stop/Pause инвалидируют поколение до ожидания записи состояния. Тайм-аут не освобождает физически незавершённый вызов. Поздние результаты не запускают новые действия. Потеря фокуса, ручная навигация, закрытие/замена/выгрузка вкладки и debugger detach приостанавливают прогон. Другие вкладки, формы, клавиатура, cookie-баннеры и browser zoom не изменяются.

После перезапуска SW незавершённый прогон восстанавливается paused и сам ничего не делает. Он хранит id своего окна и вкладки (только в `storage.session`); Resume заново проверяет в браузере, что вкладка всё ещё созданная прогоном (существует, то же окно, не incognito и не выгружена, страница на хосте адресов прогона, `about:blank` или страница ошибки), и берёт то же окно обратно, не открывая второе. Если проверка не пройдена, идентичность отпускается без закрытия (окно остаётся пользователю) и открывается новое окно. Browser restart не запускает прогон автоматически: локально остаются конфигурация и последний redacted отчёт, без сохранённого права управлять прежними tabId (`storage.session` очищается). При восстановлении внутреннего обхода исходной точкой служит пользовательский адрес; наблюдавшиеся адреса не сохраняются на диск.

## Окна и вкладки (ADR-075, дополнение 2026-11-07)

Прогон владеет ровно одним созданным им окном. Завершение (в том числе по лимитам), Stop, Clear и новый Start закрывают это окно после debugger detach: целиком, если в нём только наша вкладка, иначе закрывается одна наша вкладка (вкладки пользователя остаются). Перед закрытием владение проверяется в браузере; чужое, перемещённое или уже закрытое окно просто отпускается. Pause окно оставляет: Resume использует то же окно, поэтому второе не накладывается. Окно, которое пользователь перехватил (ручная навигация) или закрыл, не закрывается и не переиспользуется. Редирект на чужой origin ставит паузу и возвращает нашу вкладку на `about:blank`; то же смена history/fragment собственным скриптом страницы не отпускает вкладку. Ограничения: если расширение перезагружено или обновлено во время прогона, `storage.session` очищается и окно остаётся пользователю. Вкладки и окна, которые открыла сама страница (Chrome блокирует их без жеста пользователя, а прогон посылает только наведение и прокрутку), не отслеживаются: новая активная вкладка в окне прогона ставит паузу `window-blurred`, Resume возвращает нашу вкладку на передний план, а при закрытии такая вкладка остаётся, потому что создана не нами.

## Недоступные сайты

Ошибка загрузки (DNS, отказ соединения, прерванная загрузка, скачивание) и тайм-аут навигации (45 с) не останавливают прогон: сайт записывается как посещение `interrupted` и событие `error`, вкладка возвращается на `about:blank` (страница ошибки браузера не перезагружает мёртвый адрес), прогон идёт дальше после обычного интервала. Три таких сайта подряд ставят паузу `navigation-error`; счётчик сбрасывается успешным посещением и Resume. События, не относящиеся к запрошенному адресу (повтор страницы ошибки самим Chrome, `ERR_ABORTED` заменённой навигации, события между двумя сайтами), не считаются отказом нового сайта; ошибка навигации во время работы со страницей по-прежнему ставит паузу. Статусы 403/429, challenge, чужой redirect и потеря фокуса ставят паузу без пропуска.

Если при открытии раздела фоновый обработчик не ответил, timeout освобождает
кнопку «Обновить»; повторное подключение только читает состояние. До подтверждения
состояния неизвестный план нельзя редактировать или запускать. Несохранённый
черновик сохраняется, старый ответ прежнего соединения не меняет новый интерфейс.
После замены файлов распакованного расширения может потребоваться штатное
«Обновить» в менеджере расширений браузера: перезагрузка страницы настроек
не гарантирует замену уже запущенного background. Автоматическая перезагрузка
всего расширения не выполняется.

После потери здорового неактивного соединения из-за остановки фонового
процесса видимый Options автоматически выполняет одно чтение состояния,
сохраняя выбранные сайты и несохранённый план. Чтения ограничены тремя за минуту,
скрытый раздел не будит worker. Ошибки и незавершённые команды требуют явного
Refresh; мутации не повторяются автоматически. Нативная регрессия остановки
worker и Add12: внутренний отчёт.

Resume заново загружает текущую страницу и начинает полный интервал её посещения; положение прокрутки не восстанавливается. Если ОС не передала фокус созданному окну, прогон остаётся paused до явного продолжения. Native debugger infobar управляется Chrome и не скрывается расширением.

Для top-level 403/429 и `cf-mitigated: challenge` — пауза без автоматического повтора. Крупная видимая challenge-форма также может приостановить действия как кандидат. Наличие обычного CAPTCHA-виджета, Precursor/JSD/Turnstile скрипта или password-поля само по себе не блокирует прогон. Универсальное распознавание всех challenge-страниц не заявляется.

## Метрики

Метрики включаются отдельно. `system.cpu` и `system.memory` требуют уже предусмотренных optional permissions по кнопке пользователя.

| Показатель | Реальная область |
|---|---|
| CPU, % | Вся система, дельта user+kernel относительно total между валидными выборками |
| Использованная RAM | Вся система: capacity − availableCapacity |
| JS heap | Renderer текущей рабочей вкладки, CDP Performance |
| Task duration | Накопленное время задач renderer; не загрузка всего Chrome |
| GPU, % | Недоступно; null, без вычисления по косвенным признакам |

Первая CPU-выборка, сброс счётчиков, смена документа и большой разрыв не создают ложный 0%. Частичная доступность API отражается отсутствующими значениями. Идентичность CPU и содержимое страницы не входят в метрики.

## Данные и отчёт

Конфигурация хранится в отдельном локальном IndexedDB. Trusted session checkpoint ограничен 1 MiB, 200 visits, 500 events и 1200 samples. Достижение лимита отображается явно. Отчёт содержит origins и агрегаты, без query/fragment/userinfo, координат, текста форм и содержимого запросов. JSON/CSV скачиваются из показанного preview; формулы CSV экранируются. Сохраняется последний локальный отчёт, очистка доступна в разделе. Никакой серверной загрузки отчётов или extension fetch.

## Подтверждение

Проверки и фактические версии браузеров публикуются во внутреннем отчёте, машинные результаты — внутренний отчёт и `test-results/production-1.1.0/autosurf/`. Нативные сценарии используют только собственный HTTP fixture и временные профили; работа на произвольных сторонних сайтах не считается проверенной этим fixture.

Регрессия первого открытия, потеря обработчика и восстановление сохранённого
плана проверены отдельно во внутреннем отчёте.
