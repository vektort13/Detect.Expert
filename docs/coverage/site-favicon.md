# Favicon сайта — покрытие ADR-035

Иконка собирается только для посещённой верхней HTTP(S)-страницы, разрешённой текущими consent/scope. Используется фактический browser favicon; preview/отчёт читает только локальный PNG cache и не обращается к сайту. Cache bounded: 64 domain entries, 512 KiB, 7 дней, PNG 32×32 ≤16 KiB. Source URL/query не сохраняются.

В Chromium 153 native fixture подтвердил same-origin и CORS-enabled CDN. Non-CORS CDN не декодируется в ISOLATED Image; используется встроенный глобус. Firefox 138.0.4 предоставил native data image для same-origin/CORS/non-CORS fixtures, с успешной локальной rasterization. Если native getFrame не сообщает document ID, favicon использует прежнюю private ISOLATED identity из нормализованного getAllFrames ADR-018, с ограничением 128 frames и проверкой единственного top frame / exact URL / active lifecycle до и после rasterization. Внутренние страницы/IP-hosts, отсутствие native favicon/document identity, incognito, prerender/cached и pending_deletion документы не собираются. Не посещённым сторонним ресурсам не назначается favicon через сетевой поиск.

Значок сайта не распознаёт компанию и не меняет выводы анализа. Он находится в popup/sidepanel рядом с доменом выбранного документа, в Pro текущем/записанном домене, на обложке отчёта и рядом с доменом документа/корнем карты. Печать ожидает cache state и декодирование изображений; JSON-контракт сохраняется.

37 unit cases проверяют native/normalized top-frame identity и отрицательные missing/ambiguous/oversized/error/stale cases, narrow native-data-SVG exception/negative cases, revocation/navigation/favicon races, same-document favicon updates, PNG bounds/metadata, TTL/bytes/startup pruning, concurrency, faulty DOM, shared UI read/listener и print deadlines. 2501 иконка максимально допустимого Pro-отчёта проходит bounded print gate; UI использует один storage read/listener. Native production results и final package hashes находятся в общей задаче логотипов компаний.
