# Агрегированные счётчики Shodan

Трассировка: REQ-001/005/008/010/011, ADR-009. Инструмент `scripts/shodan-antifraud-counts.mjs` запускается отдельно от расширения. Новых зависимостей и permissions нет.

По [официальной документации Shodan API](https://developer.shodan.io/api), проверенной 2026-10-09, `GET /shodan/host/count` возвращает число результатов и запрошенные агрегаты без результатов поиска; метод не расходует query credits. Инструмент не запрашивает facets и сохраняет только неотрицательный целочисленный `total`. Это число индексированных Shodan результатов по фильтру hostname, а не число сайтов, использующих антифрод, и не рейтинг распространённости продукта.

`node scripts/shodan-antifraud-counts.mjs --plan` создаёт `packages/catalog/research/antifraud-2026-10/shodan/aggregate-plan.json` без чтения ключа и сетевых запросов. План строится из валидированного `packages/catalog/data/antifraud.v1.json`: точных опубликованных browser hosts и хостов официальных сайтов. Шаблоны hostname, wildcard, IP и сигналы без связанного источника исключаются. Точный опубликованный hostname остаётся допустимым, если шаблон есть только в пути SDK: путь и его параметры не включаются в запрос Shodan. Дубликаты объединяются; опубликованные browser hosts получают приоритет перед официальными сайтами, внутри каждой группы домены сортируются. Выбирается не более 100. Официальный сайт и домен SDK различаются в provenance.

`node scripts/shodan-antifraud-counts.mjs --run --key-file <путь-внутри-проекта>` использует явно указанный файл. Поддержаны plaintext, `.env` с `SHODAN_API_KEY`/`SHODAN_KEY`, JSON с `SHODAN_API_KEY` либо `shodan.apiKey`. Без `--key-file` используется только переменная окружения `SHODAN_API_KEY`. Файл должен оставаться внутри проекта после `resolve` и `realpath`, включая junction, и занимать не более 64 KiB. Поиск файлов с ключами не выполняется.

Результат запуска — `packages/catalog/research/antifraud-2026-10/shodan/aggregate-counts.json`: hostname, принадлежность к записям каталога, публичные источники, статус, count, время формирования. Ключи, URL API с ключом, error body, facets, banners, IP, ports и CVE не выводятся и не сохраняются. Перенаправления запрещены; разрешён только HTTPS endpoint `api.shodan.io/shodan/host/count`. Между началами запросов проходит не менее секунды, общий тайм-аут запроса и чтения ответа — 10 секунд. Ответ ограничен 64 KiB и 4096 частями потока, включая пустые; пустые части не сохраняются в буфере. Ошибки 401/403 останавливают последовательность; автоматических повторов нет.

Параметр `--max-requests N` ограничивает размер плана: по умолчанию 100, допустимо 1–200, при этом выборка опубликованных доменов всегда ограничена 100. Произвольные запросы, endpoint и выходные пути через CLI не принимаются. URL и параметры ограничений находятся в `packages/catalog/data/shodan-aggregate.config.json`.

Проверка с поддельным fetch и тестовыми ключами: `node --test scripts/test/shodan-antifraud-counts.test.mjs`. Реальный запрос требует доступного ключа; успешный результат нельзя заявлять по offline-плану.
