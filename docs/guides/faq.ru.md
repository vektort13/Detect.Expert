# FAQ

[English](faq.md) · [Русский](faq.ru.md)

Короткие ответы, без воды. Если вашего вопроса нет, [напишите в Issues](https://github.com/vektort13/Detect.Expert/issues).

## Основное

### Оно есть в Chrome Web Store?

Карточка на проверке: [chromewebstore.google.com/detail/obbkkjmpgaajcggbhajpdeeadkkchbeo](https://chromewebstore.google.com/detail/obbkkjmpgaajcggbhajpdeeadkkchbeo). Пока её не опубликовали, ставьте со страницы [Releases](https://github.com/vektort13/Detect.Expert/releases).

### В каких браузерах работает?

Chrome 153+ и Firefox 128+. Именно их я и тестирую. Другие браузеры на Chromium, возможно, заработают, но обещать не буду. В окнах инкогнито расширение не работает.

### Почему в Firefox нет Firewall и Автосерфера?

Firewall только для Chrome. Автосерфер управляет своим окном через debugger API Chrome, чтобы по-настоящему прокручивать страницы и двигать указатель, а сборка для Firefox этого не поддерживает. Всё остальное есть, хотя в Browser Debug наборов данных меньше, а Antidetect не переписывает заголовки запросов.

### Почему Firefox забывает расширение после перезапуска?

Вы загрузили его как временное дополнение. Для постоянной установки нужна подпись Mozilla, у этого выпуска её пока нет.

### Что делает «Разрешить пользовательские скрипты» и зачем оно нужно?

Antidetect и свои значения API должны встать на место до того, как отработают скрипты самой страницы. Для этого я использую user scripts API Chrome, а Chrome требует, чтобы вы сами включили его на странице «Сведения» расширения. Detector, Cookies, Proxy и остальному он не нужен. В Firefox то же самое делает кнопка **Allow Custom** (Firefox 137+).

## Приватность

### Данные куда-нибудь отправляются?

Не мне и не кому-то с аналитикой. Моего сервера нет, телеметрии нет, удалённого кода нет. Наружу расширение выходит только тогда, когда вы используете функцию, которой это нужно: Cloudflare Precursor (ваш токен, на `api.cloudflare.com`), необязательные запросы геолокации (ваш ключ, выбранному провайдеру), прокси или проверка прокси и запуск автосерфера. Единственное, что оно делает само, это повторно запрашивает уже сообщённый значок сайта, без referrer. Подробности в [PRIVACY.md](../../PRIVACY.md).

### Что уходит с моего компьютера, если включить геолокацию?

Только публичный выходной IP, найденный ручной проверкой прокси, и ваш ключ, выбранному вами провайдеру (MaxMind, ipgeolocation.io, ipdata или ip-api.com). Без cookies, без referrer, без посещённых URL и никогда не частный адрес. Пока вы не включили функцию и не добавили ключ, ничего не отправляется. ip-api.com без ключа работает по обычному HTTP, поэтому для него отдельное подтверждение.

### Где хранятся данные и как их удалить?

Отчёты Detector лежат в session storage браузера и пропадают при закрытии браузера, плюс у них есть лимиты по размеру и времени. То, что вы сохраняете сами (отчёты Pro, профили Antidetect, метаданные прокси, настройки), хранится в профиле браузера на диске. У каждого инструмента своя кнопка удаления или очистки, а при удалении расширения его хранилище удаляется. Экспортированные файлы остаются там, куда вы их положили. Файлы помощника прокси и его зашифрованные профили тоже остаются, см. [README помощника](../../native/proxy/README.ru.md#удаление). Полный перечень в [docs/data-inventory.md](../data-inventory.md).

## Что он умеет и чего не умеет

### Antidetect делает меня анонимным или невидимым?

Нет, и я такого не утверждаю. Он меняет то, что выбранные API браузера и некоторые заголовки запросов сообщают о вашем браузере, используя выбранные вами значения или устройство, которое соберёт для вас кнопка Randomize. IP-адрес, TLS-отпечаток и движок браузера он не меняет. Страница может заметить обёртки, workers и серверные проверки не покрыты, а сайт, который сверяет несколько сигналов, всё равно может заметить несоответствие. Считайте это инструментом для тестов и приватности.

### Поможет ли он пройти антифрод или CAPTCHA?

Он для этого не предназначен, и я этого не обещаю. Автосерфер никогда не кликает, не вводит текст и не решает CAPTCHA. Detector тоже не оценивает сайты: распознанный сервис это не вердикт.

### «No services recognized» или «ничего не найдено». Значит, страница чистая?

Нет. Это значит, что за этот период в той части, которую расширение может наблюдать, ничего не видно. Workers, WebAssembly, CSS и серверные проверки это слепые зоны, а распознанными считаются только проверенные сигнатуры. Если страница загрузилась до включения наблюдения, её ещё и надо перезагрузить.

### Сайт может понять, что я использую расширение?

Может, по крайней мере в принципе. Расширение оборачивает API браузера, чтобы наблюдать за ними или менять их, и я это не скрываю. Никаких трюков с маскировкой и никаких обещаний «100 %».

### Сайт сломался после блокировки API. Что делать?

Так бывает: некоторым сайтам API действительно нужен. Верните строке в API Guard режим **As in preset** (или **Allow**) и перезагрузите страницу. Если был пресет Strict в Antidetect, попробуйте Balanced или Compatibility.

### Почему вкладка Cookies пустая?

Пока вы не нажмёте **Grant access** и не подтвердите запрос разрешения в браузере, она ничего не читает. После этого она показывает cookies всех хранилищ, значения скрыты.

### Почему Chrome показывает плашку отладки, пока работает Автосерфер?

Автосерфер использует debugger API Chrome в своём окне, чтобы по-настоящему прокручивать страницы и двигать указатель. Chrome показывает свою плашку всякий раз, когда это делает любое расширение. Нажмите Stop, и плашка исчезнет вместе с окном.

## Прокси

### Мне нужен помощник?

Только для SOCKS5 с паролем, HTTP/HTTPS с логином, VLESS и OpenVPN. Обычные прокси работают без него. См. [руководство по помощнику](proxy-companion.ru.md).

### Расширение не находит помощника.

Проверьте по порядку: помощник установлен для того же пользователя Windows; вы запускали `Install.ps1` с правильным ID расширения (у версии из магазина он не такой, как у распакованной сборки); вы разрешили `nativeMessaging` при сохранении профиля. Потом снова нажмите **Check companion**.

### Я удалил помощника, и в браузере пропал интернет.

Это Kill Switch: трафик через прокси блокируется, когда прокси не может работать, и так сделано нарочно. Выключите **Proxy** в расширении.

### Это VPN для всего компьютера?

Нет. Он обслуживает только трафик самого браузера. Драйвера TUN нет, системные маршруты не меняются.
