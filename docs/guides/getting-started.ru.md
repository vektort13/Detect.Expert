# Быстрый старт

[English](getting-started.md) · [Русский](getting-started.ru.md)

Первые десять минут без воды: поставить расширение, посмотреть, что страница делает с вашим браузером, и по очереди попробовать инструменты. Полный список возможностей смотрите в [README](../../README.ru.md).

## 1. Установка

Выберите пакет для своего браузера на странице [Releases](https://github.com/vektort13/Detect.Expert/releases). Точные шаги для [Chrome и Firefox](../../README.ru.md#установка) есть в README.

Два момента, которые часто пропускают:

- В Chrome откройте страницу расширения **Сведения** и включите **Разрешить пользовательские скрипты**. Без него не заработают Antidetect и свои значения в API Guard. Detector и Cookies он не нужен.
- Chrome грузит распакованное расширение прямо из его папки. Эту папку не удаляйте.

## 2. Откройте Пульт

Нажмите значок расширения и воспользуйтесь шестерёнкой во всплывающем окне (или откройте страницу настроек расширения из меню расширений браузера). Пульт это главный экран: все модули, включены ли они, и кнопка, чтобы открыть нужный. Модули в группах **Defense** и **Attack** выключены, пока вы сами их не включите. С самого начала работает только Detector.

Кнопка **Tour** в шапке каждого раздела запускает короткую экскурсию по нему. Она ничего не меняет, так что смело нажимайте. По `Ctrl K` открывается палитра команд, если проще набрать текстом.

## 3. Посмотрите, что делает страница (Detector)

1. Откройте любой сайт в обычном окне. (Режим инкогнито не поддерживается.)
2. Нажмите значок расширения. Во всплывающем окне будет хост страницы, состояние наблюдения и сводка под заголовком **What was observed**.
3. Для полной картины откройте **Detector** на Пульте и выберите вкладку из списка.

Как это читать:

- Два больших счётчика, **Active identification** и **Passive identification**, делят то, что сделала страница. Чтение canvas или запрос видеокарты через WebGL это техника, а не приговор. Один вызов ничего не доказывает, а вот набор вызовов уже может.
- **Spotted techniques** это список. Раскройте строку, чтобы увидеть подробности.
- **Recognized protection and identification services** показывает только те сервисы, которые расширение может подтвердить. «No services recognized» не значит, что их нет.
- Самое важное это пометка о покрытии. «Не обнаружено» значит «не увидел в том, что могу наблюдать». Workers, WebAssembly, CSS и серверные проверки это слепая зона.

Имейте в виду: вкладка, которая была открыта до установки расширения или до включения наблюдения, стартует «с опозданием». Перезагрузите страницу и посмотрите снова.

## 4. Управляйте тем, что узнаёт страница (API Guard)

1. Откройте **API Guard** и включите его переключателем в шапке.
2. Выберите область: **All sites** или один **Site**.
3. Найдите API (поиск есть) и выберите режим:
   - **As in preset** (как в пресете) следует общему пресету, по умолчанию это *Limited*.
   - **Allow** не трогает API, даже если пресет его блокирует.
   - **Block** не даёт API работать для страницы. Каждый API отказывает по-своему.
   - **Custom value** отдаёт значение, которое вы ввели. Это умеют только 56 из 158 API, и работает оно, пока включён Antidetect (собственный переключатель API Guard отвечает за блокировки).
4. Перезагрузите уже открытые страницы. Интерфейс сам скажет, когда это нужно («Mode saved. Reload already open pages to apply it.»).

Грабли: блокировка API может сломать сайт, которому он действительно нужен (карты, видеозвонки, оплата). Если сайт ведёт себя странно, верните строке *As in preset* и перезагрузите страницу.

## 5. Соберите виртуальное устройство (Antidetect)

Чек-лист вверху страницы Antidetect проведёт вас по шагам:

1. **Allow user scripts** в настройках расширения Chrome (в Firefox 137+ нажмите **Allow Custom**).
2. **Turn Antidetect on** переключателем в шапке.
3. **Apply a device:** откройте **Quick setup**, выберите пресет (Compatibility, Balanced или Strict), нажмите **Randomize**, чтобы получить согласованное устройство, и **Apply configuration**.

Перезагрузите страницы, которые хотите проверить. Карточка **Virtual device** показывает, что сообщается сайтам.

Чего Antidetect не меняет: ваш IP-адрес, TLS-отпечаток и движок браузера. Об этом сказано и на самой странице. Workers и серверные проверки не покрыты. Это способ тестировать и уменьшать то, что страница может узнать, а не обещание анонимности.

## 6. Добавьте прокси

1. Откройте **Proxy** и нажмите **New profile** (или **Import list**, чтобы вставить список, или **Choose .ovpn file**).
2. Для обычного SOCKS5, HTTP или HTTPS прокси без логина введите адрес и порт и сохраните.
3. Нажмите **Check visible profiles**, чтобы проверить их. В результатах скорость, признаки DNS/TLS и выходной IP.
4. Выберите профиль и нажмите **Connect**. **Kill Switch** по умолчанию включён: если прокси отказал, запросы через него блокируются, а не уходят напрямую.

Для логинов, VLESS и OpenVPN нужен помощник для Windows, см. [руководство по помощнику](proxy-companion.ru.md).

## 7. Загляните в cookies

Откройте **Cookies** и нажмите **Grant access**. Браузер спросит разрешение на cookies, и пока вы не согласитесь, ничего не читается. В списке видны атрибуты, а значения скрыты. Нажмите **Show** у строки, чтобы открыть одно значение. Здесь же можно создавать, править, удалять, импортировать и экспортировать, с предпросмотром до записи и откатом после неё.
